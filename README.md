# 异星边境 · Offworld Frontier

**唯一维护仓库：** https://github.com/terry-xu-2077/OffworldFrontier （默认 `main`）。旧仓库已停止维护，不再作为设定或创作依据。

原创写实科幻项目：**人物是情感中心，科幻是世界与行动的舞台，现实困境是塑造角色的工具。**

## 当前分镜协作方式

**导演本人写分镜，AI 反向同步剧本。** 本项目不再默认让 AI 按旧剧本独立编排导演镜头；新镜头优先遵照导演书写的画面，尚未写出的镜头不提前补齐。仅在导演提出请求时对其分镜进行审读、优化和制作转译。具体流程见 [AGENTS.md](AGENTS.md)；第一集当前以[《异星拾荒》剧本](创作/剧本/第一季/01_异星拾荒.md)为工作版本。

## 创作入口

**写剧本、分镜**：从 [编剧 × 导演分镜 Skill](skills/offworld-storyboard-director/SKILL.md) 开始。**将已写分镜转成 AI 视频提示词**：使用 [AI 视频提示词 Skill](skills/offworld-ai-video-prompt/SKILL.md)，默认 **Seedance 2.5 参考生图**：每场戏先准备一条[核心电影静帧](skills/offworld-ai-video-prompt/references/core-scene-keyframe.md)作为整场视觉母图；每个视频批次提示词开头列 **`[全局资产]`**，现有云盘素材直接写文件名，缺失资产附中文生图提示词；只有明确要求 **MiniMax H3** 时切换专用格式。按需查阅 [技能模块索引](skills/README.md)，再核对当前正典专题。用户只需在本项目对话说“帮我写脚本”，不必每次重贴技能来源。仓库 Skill 供对话时读取，不等于 ChatGPT 全局安装。



所有创作模型、代码 Agent 或编辑工具统一遵循 [AGENTS.md：通用创作与维护指南](AGENTS.md)，没有某个模型独立的一套创作规则。

**Agent 从 [设定速查索引](设定/速查索引.md) 按需查阅，不要通读整个设定目录。** 可运行 `python scripts/canon_lookup.py route "关键词"` 定位专题，`headings` 看章节，再用 `read` 只取相关段落；索引不会复制正典。

1. [导演人格维护 Skill](skills/director-persona-maintainer/SKILL.md) — 负责从导演反馈中去重、验证和更新长期判断。其 [导演人格 V3.9](skills/director-persona-maintainer/references/导演代理人格.md) 是**唯一人格正文**；[审美印象与作品偏好](skills/director-persona-maintainer/references/导演审美印象与作品偏好.md) 记录电影语言坐标及导演亲自补充的电影／剧集／游戏偏好。不是导演定稿授权。
2. [创作方向](创作/创作方向.md) — 当前唯一的叙事原则与正典规则。
3. [人物关系与冲突](创作/人物关系与冲突.md) — 八位角色的欲望、弱点与关系张力（提案）。
4. [人物生活事件实验库](创作/人物生活事件实验库.md) — 低成本可拍冲突实验（提案）。
5. [灵感池](创作/灵感池.md) — 从聊天和早期记录中筛选出的未定案技术、人物与场景灵感；**与现行设定冲突的旧内容不保留，也不自动转为正典**。
   - [影视作品灵感参考](创作/影视作品灵感参考.md) — 收录《灵笼》等10部可供比较的作品，按生态、拾荒、群像与空间叙事分类；**仅供选择性借鉴，不等于导演明确喜欢或采用其中设定**。
6. [人物设定](设定/人物设定.md) — 角色专题。
7. [世界设定](设定/世界设定.md) — 生存、经济、生态、社会与科幻机制。
8. [美术指导](设定/美术设定/美术指导文件.md) — 已有视觉资产规范。
9. [第一季分集剧本与季度总览](创作/剧本/第一季/00_季度设计与分集一览.md) — 现行18集，各集均采用现行剧本作为工作版本，后续仍可继续修改。E01以现行剧本为工作版本，E13《一箱土豆》已有导演确认的剧本版本。

**旧电影方案已退出当前创作约束**：不再有电影开场、剧情顺序、场景编号、固定登场次序、季终安排或电影版的正典优先级。历史资料可从 Git 历史恢复，当前工作以专题设定及明确确认的新决定为准。

这里不重复维护数十万字的完整设定汇编，专题文件是唯一事实来源。大型资产原件保留。
