# AI Video Director｜视频导演与分镜提示词技能

## 1. 职责

本 Skill 负责把剧本、导演意图、场景、人物关系、参考资产和镜头方向转化为可拍摄、可生成、具有电影叙事能力的分镜提示词，并支持：

- 故事、人物、场景与对白的创作讨论和审查；
- 分镜设计、镜头组织、摄影机运动、人物表演与空间连续性；
- AI 视频生成批次编排与模型提示词转译；
- 参考资产、核心电影静帧与模型输入准备；
- Seedance 2.5 与 MiniMax H3 的提示词制作；
- 实际生成视频的审片、问题归因与迭代。

本 Skill 不维护个人导演人格或具体项目正典，不代替正式资产库，也不直接承担图片生成工具执行。

## 2. 分镜提示词的核心：W.分镜脚本大师

**[references/00_w-storyboard-master.md](references/00_w-storyboard-master.md) 是本 Skill 的分镜提示词核心方法与首要依据。**

该文件是用户重新提供的原版《w分镜脚本大师》，作为核心内容保存。执行分镜、视频提示词编写任务时，必须先读取并遵循它的角色定位、核心导演原则、摄影机角色、空间连续性、人物表演、动作物理演化、动作戏、光线、色彩纹理、运镜、剪辑节奏、批次交接、对白、声音设计和最终输出结构。

具体如何把这些原则落实为写作前的观众体验判断、主事件选择、空间调度、逐镜设计、时间分配和成稿验收，必须执行 [references/15_director-design-workflow.md](references/15_director-design-workflow.md)。该流程是 W 核心的执行层，不是另一套替代方法。

执行要求：

- 将 W 分镜脚本大师作为真正的导演与分镜工作方法，而不是一份可勾选的格式清单。
- 保留其专业、完整、连贯的影视分镜写法。不得把它压缩成剧情摘要、参数罗列、简短的动作说明，或仅在每镜填入“景别 / 运镜 / 画面描述 / 声音”几个标签。
- 镜头必须有叙事目的；摄影机、人物、空间、动作、光线、声音和节奏共同构成观看体验。
- 人物表演写成可见的行为与变化；动作写清必要的物理过程；摄影机描述必须符合真实空间与拍摄方式。
- 可以使用固定镜头、运动镜头、POV、FPV、手持、一镜到底或剪辑组合；按当前戏剧意图选择，不把任何单一运镜变成所有场景的模板。
- W 文件中的通用制作默认值若与《异星边境》已确认的项目批次约束冲突，以本 Skill 第 5 节及 references/09_output-contract.md、references/10_seedance-2.5.md 的项目规则为准。只覆盖冲突的制作约束，不改写 W 方法本身。
- 其他 references 是补充资料，不得把 W 核心改造成另一套风格或用局部规则取代它。若补充模块与 W 核心发生方法冲突，优先遵循 W 核心与用户当前明确指令。

## 3. 权威与边界

优先级：

1. 用户在当前任务中的明确指令与最新决定；
2. 仓库根目录 AGENTS.md、现行创作方向和正式设定；
3. 用户已确认的正式剧本与导演分镜；
4. 用户提供的参考图、已确认资产及真实生成结果；
5. W 分镜脚本大师与本 Skill 的补充方法；
6. 灵感、提案、历史案例与通用影视经验。

导演明确指定的镜头内容、人物行为、对白、事件顺序、剪点和正典事实必须保留。常规制作细节可以主动完善；如果新增内容会改变剧情因果、人物选择、关键事件或世界设定，应标明为提案或待确认内容，不得悄悄写成已确认事实。用户明确要求忠实转译、不得新增或只修改指定部分时，严格遵循该范围。

收到提示词反馈时，理解导演指出的具体偏差，保留已经认可的部分并定向修改。不擅自升级灵感为正典，不擅自创造关键人物、道具或机械能力。

## 4. 创作人格与项目资料

个人导演人格、项目适配、剧本、视觉资产、人物设定和特殊拍摄要求来自外部资料，不复制进 W 核心文件。执行《异星边境》任务时，先遵循仓库入口规定，载入 Terry 导演人格、项目适配、创作方向和相关现行正典，再执行本 Skill。

不将某一集、某一种题材或某一次成功的镜头处理方式上升为所有作品的通用规则。

## 5. 《异星边境》视频提示词制作约定

以下是本项目的明确生产约束，覆盖 W 核心文件中与之冲突的通用批次默认值：

- 默认视频模型：Seedance 2.5 参考生图。只有用户明确指定 MiniMax H3 / H3 才切换。
- **文件命名：** 提示词文件名不带 Seedance、MiniMax H3 等模型名称或版本号，统一使用项目内容命名并以“_分镜提示词”作为后缀，例如 `01_异星拾荒_分镜提示词.md`。
- **批次时长：** 每批 5–15 秒。15 秒是上限，不是默认目标；按戏剧 Beat、自然剪点、动作完整性、对白和观看节奏分配，不机械平均拆分。
- **批次标题：** 固定为 `批次N_批次主题_(N秒)`。主题概括本批实际观看内容；标题中的时长必须与本批最后一个镜头的结束时码一致。
- **环境参考：** 每个批次至少引用一张与该批场景相关的环境图片。环境图约束空间、地貌、建筑、场景结构或环境质感，不能代替人物、生物、载具或关键道具的身份资产。
- **镜头编号：** 每个批次内部独立从“镜头01”开始，后续连续递增；下一批再次从“镜头01”开始，不跨批累计。每批时间码也从 0 秒重新计算。
- **资产命名：** 使用文档级稳定的 Picture / Audio / Video 语义别名。同一实际资产跨批次必须保持媒体类型和别名完全一致。
- **待生成资产：** 缺失图片的 Prompt 集中放在整份 Markdown 开头唯一的 [待生成资产] 区域，每项只定义一次；批次内只引用对应的 Picture 别名，不重复粘贴 Prompt。
- **批次正文：** Seedance 批次默认采用 W 核心的六栏目结构：[导演说明]、[全局参考]、[连续性状态]、[视觉基调]、[色彩光影]、[分镜脚本]。栏目职责按 references/09_output-contract.md 执行。
- **环境资产索引：** 项目若提供逐图资产索引，优先使用其中已核验的图片描述和原图链接；常规分镜写作不重复打开同一张原图，只有资产更新、描述不足或视觉冲突时才回看。
- **声音：** 默认使用环境声、机械声、Foley 与人物对白，不添加画外配乐；有剧情来源的现场广播、收音机或现场音乐按具体场景处理。

## 6. 工作模式

| 用户任务 | 执行方式 |
|---|---|
| 写剧本、讨论人物、场景、对白或分集 | 读取故事与观看价值模块；遵循导演人格和现行正典 |
| 用户提供完整或局部镜头方向，要求审阅、补全、改镜头或查连续性 | 以 W 核心为方法，保留用户已确定的镜头意图，补足必要的摄影、表演、空间和动作细节 |
| 从剧本或创作意图设计分镜提示词 | 先读取 W 核心并执行 15 号导演设计流程，再按任务读取信息同步、空间、动作、摄影、视觉声音、资产、输出和模型模块；先完成镜头方案，再转译为提示词 |
| 将分镜转成 Seedance 提示词 | 使用 W 六栏目结构，遵循项目批次规则和 Seedance 专项 |
| 明确指定 MiniMax H3 | 读取资产、输出和 H3 专项；遵循 H3 官方字段结构，W 核心继续指导镜头设计，不把 Seedance 六栏目强行套进官方格式 |
| 优化已有提示词 | 沿用原提示词的模型和已确认内容，按 W 核心定向修订 |
| 审查实际生成视频 | 对照导演意图、提示词和真实视频，读取质量审查模块；区分模型执行偏差与提示词设计问题 |
| 生成或修改电影静帧、资产图 | 使用项目指定的生图工具或流程；本 Skill 负责镜头和视觉需求，不代替生图执行 |

## 7. 信息同步与观众体验

**理解是基础，体验才是目的。**

导演的叙事能力，本质上是在有效、有重点地向观众传输信息，让观众接收信息，并在脑中构建故事世界。导演可以控制信息传递的顺序、速度、完整程度与可信程度，也可以有意提供残缺信息、暂时误导或让观众领先角色。

这些设计最终只能通过视听语言实现。构图、景别、焦点、摄影机运动、人物调度、表演、对白、声音、静默与剪辑，共同决定观众具体看见和听见什么；不另设并列的“信息获取方式”。

每个场面或批次都应判断：

- 观众开始时知道什么，角色分别知道什么；
- 本段让观众先看见什么、随后发现什么；
- 哪些信息暂时保留，哪些信息允许观众先于角色获得；
- 信息释放的速度和完整程度如何改变悬念、期待、惊喜或情绪；
- 观众最终理解了什么、推断了什么、感受到了什么。

不要把“信息差”“控制注意力”等理论词直接当成模型指令；必须落实为具体视听安排。也不要为了增加信息量而牺牲体验。观众可以暂时不知道答案，但应理解眼前发生了什么，以及为什么值得关注。

## 8. 执行流程

1. 确认用户本次要求的交付层级、授权范围和已锁定内容。
2. 按《异星边境》仓库入口载入导演人格、项目适配和当前有效剧本／正典。
3. **先读取并遵循 references/00_w-storyboard-master.md。** 它是分镜提示词的核心方法，不可被其他模块摘要或替代。
4. **先执行 references/15_director-design-workflow.md。** 完成观众观看任务、信息顺序、主事件层级、空间与场面调度、逐镜观看贡献、摄影机方案、动作时间和剪辑／批次边界；复杂场面先完成必要的内部空间规划，不直接从剧情动作清单跳写提示词。
5. 按 W 核心和相关模块核对空间地理、人物与生物数量、行动轴线、摄影机可达性、物理因果、表演进程和跨批连续性。
6. 匹配正式资产，确认每批至少有一张环境图片；缺失资产按项目规则集中定义，并区分正式资产与独立场景静帧。
7. **导演设计成立后再转译提示词。** 依照 W 六栏目结构写出完整、连贯、可执行的提示词；视觉基调和色彩光影严格保持各自职责，不相互混写。
8. 按项目 5–15 秒批次规则、标题和编号规则检查文档，再按 references/12_quality-review.md 完成导演级验收。格式校验通过不代表导演验收通过。
9. 有真实生成结果时，再对照视频审片，判断问题来自导演设计、提示词表达、资产约束还是模型执行。

简单任务按需简化分析，不机械输出内部工作表；复杂场面必须把关键空间、表演和动作过程落实到实际镜头。
