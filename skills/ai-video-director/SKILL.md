# AI Video Director｜通用视频导演技能

## 1. 职责

本 Skill 统一组织影视导演方法与 AI 视频提示词制作流程，可独立应用于不同项目，覆盖：

- 故事、人物、场景与对白的创作讨论和审查；
- 导演分镜的构图、机位、动作、表演与连续性设计；
- 多镜头视觉事件与 AI 视频生成批次编排；
- 参考资产、核心电影静帧与模型输入准备；
- Seedance 2.5 与 MiniMax H3 的专用提示词转译；
- 实际生成视频的审片、问题归因与迭代。

本 Skill 不维护个人导演人格或具体项目设定，不代替正式资产库，也不直接承担图片生成工具执行。

## 2. 权威与边界

优先级：

1. 用户在当前任务中的明确指令与最新决定；
2. 仓库根目录 AGENTS.md、现行创作方向和正式设定；
3. 用户已确认的正式剧本与导演分镜；
4. 已确认资产及真实生成结果；
5. 灵感、提案、历史案例与本 Skill 的方法建议。

**协作式导演转译。** 用户可以提供完整分镜，也可以只给出几个镜头、关键画面、动作节点、参考图、口头描述或对现有提示词的反馈；输入不要求完整。AI应主动理解这些方向，补全可执行的镜头设计与视频提示词，包括必要的镜头衔接、景别机位、运镜、动作时间轴、人物表演、空间关系、光影和声音。缺少必要镜头或制作细节时，可以提出合理补充与替代方案，不因输入不完整而机械停下来追问。

导演明确指定的镜头内容、人物行为、对白、事件顺序、剪点和正典事实必须保留。常规制作细节可以主动完善；如果新增内容会改变剧情因果、人物选择、关键事件或世界设定，应标明为提案或待确认内容，不得悄悄写成已确认事实。用户明确要求忠实转译、不得新增或只修改指定部分时，严格遵循该范围。

收到提示词反馈时，AI应理解导演指出的具体偏差，保留已经认可的部分并定向修改，不要求用户重复说明已经明确的方向。不擅自升级灵感为正典，不擅自创造人物、关键道具或机械能力。代理模拟只用于贴合导演审美与判断，不自称导演本人、不替用户定稿。

## 3. 创作人格与项目资料

项目的导演偏好、剧本、视觉资产、人物设定和特殊拍摄要求来自外部资料，不写入本技能。执行时先遵循用户本次指令，再按任务读取当前项目的有效资料，不将个别作品的处理方式上升为普遍规则。

若存在独立的导演人格或项目适配文件，应按其实际声明配合使用；本技能不预设其路径、名称或内容。无需为简单任务一次性加载全部资料。

## 4. 工作模式与调用路由

| 用户任务 | 工作模式 |
|---|---|
| 写剧本、讨论人物、场景、对白或分集 | 剧作与观看价值；按需读取 01 |
| 用户提供完整或局部镜头方向，并要求审阅、补全、改镜头或查连续性 | 协作式导演设计；读取 02–06、12 中相关模块 |
| 用户要求设计分镜或完善镜头方案 | 根据已有方向形成可执行草案；补足必要镜头与制作细节，重要剧情新增标注为提案 |
| 将分镜、关键画面或动作方向转成视频提示词 | 协作转译；保留明确约束，主动补全未指定的制作细节；默认 Seedance 2.5，读取 07–10 |
| 明确要求从现行剧本直出视频制作稿 | W 式剧本直出；读取 02、03–06、09、10；必要时提出镜头方案 |
| 明确指定 MiniMax H3 | 读取 07、09、11；严格采用 H3 官方格式 |
| 优化已有提示词 | 沿用原提示词已明确的模型；未指定时按 Seedance 2.5 |
| 审查实际生成视频 | 对照导演原意与真实视频；读取 12 |
| 生成或修改电影静帧、资产图 | 使用当前项目指定的生图工具或流程；本技能负责视觉需求与转译 |

不要因用户只要求一个镜头就展开整集制作流程；不要把剧本、分镜、图像提示词、视频提示词和成片验收混成一个交付物。

## 5. 默认制作约定

- 默认视频模型：Seedance 2.5 参考生图。只有用户明确指定 MiniMax H3 / H3 才切换。
- **提示词文件命名：** 文件名不包含 Seedance、MiniMax H3 等模型名称或版本号；按项目内容命名，可使用“`{集数}_{集名}_分镜提示词.md`”形式。模型信息写在文件内容或制作说明中，不写入文件名。
- Seedance 批次按 7–15 秒规划；15 秒是单批上限而非默认目标。先确定自然剪点、完整动作、对白与观看节奏，再在 7–15 秒内分配实际时长。
- **批次标题：** 统一使用 `批次N_批次主题_(N秒)`；主题准确概括本批观看内容，标题时长必须与分镜时码一致。
- 一批可以包含一个镜头，也可以包含多个有因果关系的镜头；一个镜头也可以包含多个动作阶段。
- 每个导演已写场景默认先建立一张核心电影静帧，作为场景级视觉母图；已有并确认的母图直接复用，不重复生成。它不是自动首帧，不锁定所有后续机位。
- 资产使用文档级稳定语义别名：Picture、Audio、Video；同一实际资产跨批次必须保持媒体类型和别名完全一致。
- 缺失图片的 Prompt 集中在整份 Markdown 开头唯一的 [待生成资产] 区域，每项只定义一次；批次只写同名 Picture。
- 用户明确指定的镜号、机位、动作、事件顺序、对白和剪点必须保留；未指定的镜头细节与必要衔接由 AI 主动补全。涉及剧情因果、人物选择或正典变化的新增内容先标注提案。
- 默认不添加画外配乐；现场广播、收音机、酒吧音乐等有剧情来源的现场音乐可以保留。
- 提示词内部分析与模型正文分离；不把版本说明、制作定位、整集介绍、工具说明和无关规则塞进模型输入。

### 信息同步与观众体验（分镜／视频提示词任务必用）

**理解是基础，体验才是目的。** 分镜和视频提示词不能只把剧本事件拆成镜头，还要设计观众如何认识事件、人物与世界，以及最终经历什么体验。

- **先明确观众认知：** 本段开始时观众已经知道什么？角色各自知道什么？本段希望观众新增理解、产生何种期待或感受？哪些答案暂时保留？
- **设计信息调度：** 决定信息的选择、顺序、速度、完整度、可信度和分配关系。可以完整揭示、局部呈现、延迟揭晓，也可以通过人物谎言、有限视角或错误推断制造有依据的误导。
- **用视听语言实现：** 构图、景别、焦点、运镜、人物调度、表演、对白、声音、音乐、静默与剪辑共同决定观众具体看见和听见什么。注意力引导属于视听语言，不另设并列的“信息获取方式”。
- **把理论转成可拍内容：** [导演说明] 可以说明观众注意和理解的先后，但模型正文必须落实为真实机位、画面主体、动作、视线、声音时机与剪辑关系，不把抽象理论术语当作镜头指令。
- **尊重有意的未知：** 观众不必知道全部真相，但应理解眼前发生了什么、为何值得关注。残缺信息与误导应有可辨认的依据；揭晓后能重新解释此前事实，而不是任意推翻事实。
- **检查体验而非信息数量：** 观众实际注意到什么、理解什么、推断什么、感受什么？场面可以创造认知、情感、感官、想象或审美体验，不要求每镜都增加剧情事实。

## 6. 核心工作流程

1. 识别用户要求的创作层级与授权范围。
2. 核对当前剧本、正式分镜、正典和真实资产。
3. 先判断观众观看价值，再决定是否保留、压缩、合并、删除或显微聚焦。
4. **先判断镜头要拍什么**：为本批区分主事件、辅助动作和背景信息，找出观众必须亲眼看清的动作节点与视觉高潮。
5. 建立必要的空间关系、主体调度和运动轴线；正在发生的追逐、对峙、群体活动及其参与者不能因机位转向局部动作而无故消失。区分幕后空间规划与银幕实际需要展示的空间。
6. 将关键动作拆成可见的时间阶段，检查受力、接触、人物反应及开始／结束状态；按戏剧权重分配时间。
7. **先设计镜头再写提示词**：逐镜确定独立观看贡献、机位高度与距离、构图、主体尺度、运动和剪辑节奏；删掉无意义重复观察。
8. 规划批次与自然剪点，检查关键事件的起势、关键发生和结果是否得到兑现；如跨批，明确事件交接而不凭空重置。
9. 设计光影、材质反馈和声音同步，匹配实际资产并区分身份、空间、首帧、尾帧及运镜参考。
10. 按模型输出规范组装可直接执行的提示词，不把幕后分析塞进模型正文。
11. 交付前进行导演级镜头预审、物理连续性与格式检查；有真实生成结果时再做结果验收。

简单镜头不强制填写所有分析项。复杂动作、追逐、机械破坏、群像调度和空间转换必须把关键过程落实到可见画面。

### 导演级镜头门槛

- **场面整体优先**：先确定人物在做什么、谁在与谁互动、危险或追逐如何持续，再考虑其中某个机械动作如何拍。单个动作再精彩，也不能把场景里尚在行动的主体挤出叙事。
- **物理细节按需**：跳跃前的压缩或承重变化可在现有运动中清楚带过，帮助起跳成立；它是条件性的动作细节，不是要求另设蓄力镜头、专门批次或延长时长的硬指标。
- **情绪爆发按需**：仅当已有剧本／导演指示明确要求怒吼、崩溃等强烈情绪爆发时，安排与该表演相称的准备和反应；不主动为日常表演添加前摇。
- **剧情铺垫归剧本**：故事中的“先抑后扬”、冲突蓄积与叙事结构属于剧本创作，不把它们作为本视频导演执行的强制规则。
- **空间可信不等于总览镜头越多越好**：观众已认清地形后，按当前场面的动作、人物、距离和结果选择观察位置；远景、俯拍、近景都以新增观看信息为准。
- **每镜必须有观看贡献**：镜头能否让观众读到前镜没有的动作、力度、判断、关系或结果？两个高位远景重复观看同一轨迹，通常需要调整其中一个的职责，而不是仅换焦段。
- **主事件必须有兑现**：按自然剪点决定是否跨批，不能为了凑默认时长把重要结果无意切走；已有导演剪点优先，跨批时交接阶段和状态必须精确。
- **镜头质量不是格式合规**：每批写完要检查“如果真的这样拍，会好看、好懂、情绪有变化吗？”，不把通过栏目与时码检查当作验收通过。

上述判断是导演方法，不是固定“必须低机位、必须切三镜、必须在一批完成全部动作”的镜头模板。
