# 资产引用、参考职责与连续性

## 一、先核对资产，再写提示词

优先核对当前项目的正式视觉资产索引。当前索引为每张图片提供了原图直链、实际画面描述和稳定语义别名。**正常写分镜与视频提示词时，以索引中的逐图描述作为视觉依据即可，不必每次重新打开同一张图片。**只有图片新增、替换或更新，索引描述不足以回答当前镜头的具体细节，需要确认未记录的特殊结构，或图片与已确认设定发生视觉冲突时，才重新打开原图并更新索引。真实文件名用于幕后核验；视频提示词使用稳定语义别名。

必须区分：
- 文件存在；
- 已实际打开并看过图片；
- 已上传到视频生成平台；
- 已在工作流或节点中绑定；
- 模型实际使用并生成出符合预期的结果。

这些是不同证据层级。不能把索引文件名当作已上传资源，也不能声称已经参考了没有实际看过的图片。

素材被替换或更新时，必须重新核对当前来源中的文件标识及版本状态，重新查看新图并同步更新索引中的链接、描述和版本状态，不沿用失效的引用。

### 视觉主体覆盖检查

写完场面调度后，逐一核对所有在镜头中具有明确身份或承担动作的视觉主体：主要人物、独特生物、载具、关键道具和特殊机械。优先使用当前正式视觉资产索引中已有的 Picture 资产；只有确实缺少、且会影响主体身份或结构连续性的可复用资产，才在文档开头定义待生成 Prompt。不得用某一镜头的静帧、场景关键帧或临时构图图替代正式资产引用。普通、非识别性的背景元素可以由环境图和文字描述共同承担。

- 新出现或已有正式造型的独特生物，不能只写在画面描述里而漏掉自身资产引用。
- 环境图不能替代生物、人物或关键道具的身份参考；群体图也不能自动覆盖其中每一种独立变体。
- 多主体动作必须在镜头正文里交代数量、角色类别、相对位置与动作关系；资产标签本身不代表这些主体已经进入画面。
- 每个批次的[全局参考]至少引用一张正式资产索引中的环境图片。优先选择与本批实际地点最匹配的现有环境资产；同一环境图可以跨多个批次复用，不必为每批另造一张图。
- 若没有完全对应的环境图，选择现有资产中最接近的地形、空间或材质参考，并在文字中说明适用范围；不要因此生成单镜头静帧来填补。
- 若用户刚提供新图，先判断它是否为正式资产、临时参考或待上传素材；没有稳定可用的绑定来源时，不伪造云盘链接或声称节点已能读取。

## 二、参考资产职责

| 类型 | 主要用途 | 必须说明 |
|---|---|---|
| 人物图 | 身份、面容、发型、体态、服装 | 哪些身份特征需要保持 |
| 载具/机械图 | 外形、结构、比例、部件连接 | 哪些结构、状态和功能已确认 |
| 场景图 | 地形、空间、道路、出入口、材质 | 是空间布局参考还是综合色/材质参考 |
| 道具图 | 尺寸、材质、结构、颜色、开合和磨损 | 哪些识别特征不能改变 |
| 生物图 | 数量、身体结构、变体、行为能力 | 个体差异和已确认能力 |
| 音频 | 声线、口音、语速、语气或环境声 | 继承声音质感，不自动照搬样本台词 |
| 视频 | 运镜、动作、节奏或连续性 | 明确只借鉴哪一部分，不默认复制构图、角色或场景 |

角色、载具和关键道具通常需要实际原图作为身份锚点；环境图优先提炼地形、材质、色彩和光照为文字，避免把原图构图强加给新机位。只有精确空间布局确实重要时，才把环境图作为空间参考。

## 三、类型化资产标签

标签格式固定：

~~~text
<Picture 资产名称>：用途与参考内容描述
<Audio 资产名称>：用途与参考内容描述
<Video 资产名称>：用途与参考内容描述
~~~

规则：

1. 类型固定使用 Picture、Audio、Video，大小写一致。
2. 名称使用简短、稳定、可读的语义别名，不写文件名、扩展名、路径或平台编号。**严禁纯数字资产名**，不设例外；即使数字是正典中已确认的载具编号、角色编号或专名，也必须改用有明确语义的名称（例如将“866”命名为“蚂蚱载具”），数字编号只放在资产描述中。
3. 别名作用域是整份 MD 文档，不是单个批次。
4. 同一实际资产跨批次必须使用完全相同的媒体类型和别名；不同实际资产不得共用别名。
5. 同一主体的不同素材若作用不同，应使用彼此可区分的稳定别名。
6. 每个标签独占一行，从行首开始，使用中文冒号，后面简洁说明用途。
7. 只列本批真正使用的资产，不为完整感堆入无关素材。
8. 标签是制作侧引用，不代表已上传、已绑定或模型已成功读取。

TerryDirector 节点按“媒体类型 + 别名”跨批次匹配和同步绑定。用途说明可以因批次不同而变化，匹配键不变。

## 四、文档级图片 Prompt：正式资产与独立场景静帧分开管理

文档开头唯一的 [待生成资产] 区域用于集中保存需要单独生成的图片 Prompt，但其中的 Prompt 分为两种用途，不能混为一谈：

1. **正式可复用资产 Prompt**：正式资产库确实缺少、且后续多个镜头或批次需要复用的角色、生物、载具、道具、设施或环境资产。生成并确认后，才登记到视觉资产索引，并由实际使用它的批次通过 Picture 标签引用。
2. **独立场景静帧 Prompt**：用户明确要求制作的核心电影静帧、场景视觉母图或特定镜头静帧。它们是独立的场景制作素材，不是正式视觉资产，不进入视觉资产索引，不要求被任何批次 Picture 标签引用，也不得自动加入批次[全局参考]。即使这些静帧用于统一场景视觉，也只在文档级静帧规划区单独管理。

正式资产优先复用现有图片；独立场景静帧是否制作，以用户明确提出的制作需求为准。不得因为某个场景缺少静帧，就把它升级成正式资产或强行绑定到批次。

~~~text
[待生成资产]
<Prompt 资产名称>：完整中文自然语言生图提示词
~~~

强制规则：

- 整份 MD 最多一个 [待生成资产] 区域，位于第一批之前。
- 每张图片只定义一次 Prompt；同一张图不得在多个位置重复写生图正文。
- 正式可复用资产 Prompt 的名称必须与后续实际使用它的 Picture 名称完全相同；只在确实使用该资产的批次中写 Picture 引用。
- 独立场景静帧 Prompt 保留独立名称，不要求与任何批次 Picture 同名，也不要求在批次中建立 Picture 引用。
- 每个批次只写本批真正使用的正式资产 Picture 引用，不重复 Prompt，不写“同上”替代引用。
- 节点提取文档级 Prompt 后，将其作为独立图片生成任务处理；不得仅因 Prompt 存在，就自动创建批次 Picture、自动绑定到批次或将其加入[全局参考]。
- 正式资产 Prompt 若没有被任何批次使用，需检查是否为孤立定义；独立场景静帧 Prompt 可以没有任何批次引用。
- 正式资产生成并确认后，按资产规则更新索引并保留实际使用它的批次 Picture；独立场景静帧生成后，保留其 Prompt 和场景静帧规划，除非用户明确要求删除。
- 正式资产已存在、只是尚未上传平台时，只写对应媒体标签并注明“待上传绑定”，不要新增正式资产 Prompt。
- 当前规则只扩展到图片 Prompt，不自行创建音频或视频生成任务。

标签不得使用 XML 闭合标签、嵌套或属性。不要把 H3 官方数字编号当成语义别名。

## 五、静帧、首帧与正式资产的边界

- **正式视觉资产**：可跨镜头、跨批次重复使用，并登记在当前视觉资产索引中的人物、生物、载具、道具、设施和环境图片。环境图负责提供地形、空间、材质与综合色参考，不负责锁定新镜头的机位。
- **独立场景静帧／核心电影静帧／场景视觉母图**：用户明确要求制作时，可以作为文档级图片 Prompt 保留，并在独立的场景静帧规划区记录视觉目的与生成状态。它们服务于某一场景或特定镜头，不是正式视觉资产，不登记到视觉资产索引，不放入任何批次[全局参考]，也不写成批次 Picture 标签。
- **单镜头关键帧／视频首帧**：服务于某一个具体镜头或某次生成任务，不是可复用资产。默认不创建；用户明确要求时作为独立镜头制作素材处理，不得因此加入正式资产库或批次资产引用。
- **尾帧**：只有上一镜真实生成并实际提取后，才可作为后续镜头的连续性输入；不能提前虚构尾帧。
- **身份参考**：约束人物或物体外形，不自动锁定姿势和构图。
- **空间参考**：约束地形、建筑、道路和空间关系，不自动成为视频首帧。
- **运镜参考视频**：只继承明确指定的摄影机路径或节奏。

镜头需要特定机位、动作瞬间或画面构图时，应把这些要求写进[分镜脚本]，由镜头文字指导生成。用户明确要求的场景静帧可以另行保留为独立 Prompt，但不得伪装成正式资产或自动进入批次参考。

## 六、连续性状态账本

只追踪会影响当前镜头或后续镜头的状态：

- 人物位置、朝向、衣物、伤痕和知识状态；
- 道具 ID、数量、持有人、开合和损坏状态；
- 载具位置、方向、运行和机械损伤；
- 生物数量、分布和行为状态；
- 空间位置、出入画方向和行动轴线；
- 灯光方向、天气、时间和环境变化；
- 尚未结束的动作及其起始阶段。

复杂任务可在内部使用：

| 镜号 | 事件前 | 主要可见动作 | 事件后 | 摄影机/轴线 | 依赖与风险 |
|---|---|---|---|---|---|

正典事实、工作推测和未知事实必须区分。计划状态不是实际验证状态。

## 七、资产缺口与补图

正式视觉资产只有在确实缺失、且后续需要反复引用时才补图。先检查索引中是否已有可用图片，优先复用现有资产；不要为每个批次、每场戏或每个镜头重复造正式资产，也不要为每块碎石或普通背景自动创建资产。

正式资产的缺图提示词应说明可复用用途、主体与环境关系、需要的视图、尺度、结构、材质、光线及正典边界。角色、载具、关键道具和生物优先考虑可复用设定图；确有必要时可建立可跨镜头复用的环境空间资产图。

如果用户明确要求核心电影静帧、场景视觉母图或特定镜头静帧，则按独立场景制作任务保留文档级 Prompt 与对应场景规划。它们不代表正式资产，不替代现有资产，不进入视觉资产索引，也不自动进入批次[全局参考]。需要的具体机位、构图和动作状态仍应在静帧 Prompt 或[分镜脚本]中明确表达。

实际生成或修改图片时，遵循当前项目指定的生图流程，读取正式原图并真实调用图像生成工具。只提供提示词时，不声称图片已经生成。

## 八、H3 的数字编号

制作侧的语义标签与 H3 官方数字标签分开：
- 制作侧：Picture、Audio、Video 类型加文档级稳定语义别名；
- H3 正式输入：Picture 1、Audio 1、Video 1 等。

只有真实素材完成映射后，才能按当前批次实际输入顺序分配 H3 数字编号。中文命名标签和 Prompt 不得放进 H3 官方字段。
