# 异星边境｜导演人格维护 Skill

**定位：** 从真实的导演反馈中改进未来的创作判断，避免“讨论一次 → 加一条规则 → 人格无限膨胀”。这是 GitHub 仓库内的项目级 Skill，不等于 ChatGPT 已全局安装或能够自动持续运行。

## 三个职责分明的文件

- [导演代理人格](references/导演代理人格.md)：**唯一长期导演判断正文**。按需给剧作、分镜、审稿使用；不在其他位置复制一份。
- [导演审美模型与作品证据](references/导演审美印象与作品偏好.md)：**以跨作品审美模型为核心，个人作品名单为证据**。重点是提高预测导演取舍的准确性，不逐部建立膨胀的影评卡；未明确的喜欢原因不作事实判断。
- [编剧 × 导演分镜 Skill](../offworld-storyboard-director/SKILL.md)：专门负责创作、镜头连续性、剧本反向同步与制作转译。本 Skill 只更新创作判断，不代替它。

## 什么时候加载

- **一般写稿和审稿：** 读取人格正文；如果涉及摄影风格、作品参照和“像哪个导演”，再读审美文件。无需每次启动更新循环。
- **导演反馈并要求更新人格：** 读取人格与相关反馈；有风格、偏好或作品内容再读审美文件。
- **导演说喜欢某部电影／剧集／游戏：** 先判断这些作品是否强化、否定或修正了审美模型，再紧凑地记录为证据；**不以作品数量或逐部点评作为主要成果**。除非证明跨场景决策规律发生变化，否则导演人格正文不动。
- **只是某集一个镜头的修改：** 更新对应分镜或剧本（需授权）；若无法提炼跨情境的判断，维护结果为 `NOOP`。

## 更新算法（轻量、可审查）

1. **捕获并分级信号。** A＝导演本人明确表达，B＝多次具体选择归纳，C＝AI推测。写清限定条件。用户喜欢某个导演风格类比，不等于喜欢该导演所有作品。
2. **分类与归属。** 镜头／剧情／角色事实归分镜、剧本或人物世界设定；作品喜好作为审美模型的支持或反例，优先更新**跨作品判断维度**，只留紧凑名单用于核对；真正改变跨场景创作选择的规则才进入人格正文。
3. **检索旧原则及反例。** 与现有内容比较：是否已有相同规则？是否只是一集特例？新旧偏好是否冲突？优先改现有段落，不追加时间线流水账。
4. **选择操作。** `ADD`＝新增真正的长期决策机制；`UPDATE`＝修订并合并旧规则；`DELETE`＝移除过时或被证伪的规则；`NOOP`＝已涵盖、仅一次性事实或证据不足。优先考虑 `UPDATE`／`NOOP`。
5. **小规模回归评估。** 用过去的真实争议检查新规则是否有帮助：E01 老手行动和地缝；E09 生活群像独立价值；E11 杰西卡的私利和真情；E12 技术劳动与对话分工；E14 主角真实离开又折返。测试应问“现在会作何判断及为何”，不能把正确答案直接写在提示题里。没有真正跑的测试注明“未运行”，不宣称通过。
6. **对文本做减法。** 人格全文建议约 6,000–10,000 字符、原则上不超过12,000字符。超限优先去重、替换、压缩案例；不要通过制造多个平行人格文件掩盖膨胀。审美偏好也保留摘要和代表条目，超量合并。
7. **在授权范围内写入并报告。** 只有导演明确要求更新／创建才提交仓库。告知 `ADD/UPDATE/DELETE/NOOP`、修改的文件、原因、检查结果；Git 历史承担版本日志，不在正文里另建流水账。

## 导演风格匹配的原则

按**镜头／场景、分集、整季**三个层次匹配**导演或剧集主创**：摄影空间与物理动作、生态和工业可信性、人物欲望与关系积累、幽默节奏与长线叙事可分别寻找参考。先选择本次真正要解决的问题，再挑一主一辅的参照；未必是 Terry 亲自确认喜欢该创作者的风格。不同段落允许不同语言并融为《异星边境》自己的风格，不能用名导标签代替判断，也不能照搬镜头或剧情。

**作品证据不等于作品影评。** 导演明确给出的喜欢点才记为确认事实；若只说作品名，分析剧情结构、镜头、群像等可能的吸引点时，应标为待验证假说。**一份能指导未来取舍的审美模型，比一百条逐片点评更重要。**

## 维护成功的判据

- 新规则能提升**不同场景**下的判断，而不是重复这次的镜号或虫群数量。
- 导演明确决定、AI建议与尚未确认的推测不混淆。
- 人格、审美偏好、角色正典、正式分镜各自只有一个权威入口。
- 未经请求不写仓库、没测试不称已验证，更新后文件不过度膨胀。

**报告可以很短：** 本次采用了哪种操作、为什么、改了哪里、有哪些仍未确认的偏好。
