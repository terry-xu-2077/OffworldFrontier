# 导演审美模型｜风格坐标与作品证据

> **2026-10-26 重构为判断模型优先。** 作品名单是证据，不是目标；目的在于让 AI 更准确地预测导演对镜头、人物和叙事的取舍。导演及剧集主创只是跨层次的创作语言参照，不代表导演已确认喜欢这些创作者的所有作品。
>
> **证据分层：** A＝导演亲口确认喜欢的特定作品／桥段／手法；B＝多次创作选择后归纳出的印象；C＝AI提出的风格类比。C 不能写成 A。

## 一、审美判断模型（B：多媒介共性＋实际创作反馈）

**核心印象：喜欢值得探索的、自己能运转的世界，也在乎值得相处的人，以及行动真实带来的后果。** 不把导演归类为“只喜欢冷峻硬科幻”。以下是用于预测创作选择的六个维度，**不是每集必须完成的六项配额**。

| 维度 | 作品与已知导演选择提示的线索 | 在《异星边境》里如何判断 |
| --- | --- | --- |
| **世界独立运转** | 《西部世界》《辐射》《银翼杀手》两部、《赛博朋克2077》；导演要求遗迹、生态与工业设施可信 | 世界不只服务主角，经济、岗位、虫群、旧公司遗存应有自己的行动与规则 |
| **探索、发现与建设的乐趣** | 《无主之地》1–2、《异星探险家》《异星工厂》《我的世界》 | 探索新空间是否令人好奇？劳动、采集、建造能否产生可见的生活变化？**不照搬游戏任务循环** |
| **选择、因果与长期积累** | 《绝命毒师》《风骚律师》《漫长的季节》提供候选线索；导演反对无铺垫的牺牲与草率的心理转变 | 角色根据经验与利益行动，决定改变后续关系；大转变需要真实经历，不靠解释 |
| **群像、温度与相处时间** | 《请回答1988》《漫长的季节》《机器人总动员》《海贼王》真人版；导演认可基地居民有自主生活 | 普通人的日常是否值得看？人物是不是只有主角出现时才存在？不强制煽情 |
| **动作刺激与可读的物理逻辑** | 明确喜欢《使命召唤》《战地》真实的战争场面、《孤胆枪手》的密集虫战；E01要求高速驾驶与合理地缝 | 动势、体重、惯性、地形和专业能力必须成立；不要靠角色降智制造刺激 |
| **鲜明个性与调性弹性** | 《爱，死亡和机器人》《两杆大烟枪》《让子弹飞》《头号玩家》《哈尔的移动城堡》提供候选参照 | 允许冒险、黑色幽默、奇思、安静与温暖在不同场景各自有效，不能全剧一个节奏 |

**证据谨慎：** 列出的电影／剧集仅证明用户确实喜欢，不证明右列每项是他明确指定的原因。作品常见评价与我们的类比只是待验证假说。导演最新明确反馈优先于模型。

### 使用模型的方式

先识别这场戏想带给观众的体验，再选择最重要的一两项维度。E01追逐中优先维护老手行动、动作连续性与地形可读性；E06生活戏则不必为了“科幻主线”硬塞危险。整季可以逐渐积累建设、物资、情感与生存压力，单集仍可以独立有趣。

真正的进步不是记住更多片名，而是遇到两个都能拍的方案时，能**提前预测哪个更符合导演当下的目标及其条件**，事后用导演真实反馈纠偏。

## 二、从镜头到整季：导演与剧集主创的风格坐标

**用途是找到创作判断的参照，不是找一位导演让《异星边境》全面模仿。** 以前的五位主要用于E01运镜和视觉风格；现在纳入全季设定与分集，把参照扩展为**摄影与世界质感／人物与长线叙事／对白与幽默节奏**三个层次。

**证据边界：** 「作品关联」表示 Terry 明确喜欢该创作者的一部相关作品，**并非**确认喜欢其全部作品或每种手法；「旧有类比」表示此前讨论中认可过这种导演语言匹配方式。**E01分镜与E06剧本正式确认，其余E02—E05、E07—E14仍是待审提案**，不能把下面的应用示例当成已定稿镜头。

### A｜摄影、动作与异星世界（镜头／场面）

| --- | --- | --- |

| **乔治·米勒**（旧有类比） | 运动轴线、追逐者速度差、地形与机械受力共同决定动作节拍 | E01的866逃亡与飞跃断缝、E10墙外短途追查。**不把整部剧变成连续载具大战** |
| **詹姆斯·卡梅隆**（旧有类比） | 生物生态、工业工具和危险环境之间的因果；由操作和行为展示规则 | E01虫群采集与返巢、E03矿井结构、E07覆膜林捕食与逃离。**不擅自给生命加智慧或把对白写成科普** |
| **阿方索·卡隆**（旧有类比） | 沉浸的移动观察、镜头经过同一空间内同时发生的多种生活 | E02穿过热闹的基地、E06露台与街机交叉、E13酒吧群像。**自由FPV不等于驾驶POV，也非一镜到底配额** |

| **克里斯托弗·诺兰**（《星际穿越》） | 宏大天象、季节与时间压力，最后应落在人与人之间可理解的情感选择 | 环带行星与长夜的整季时间背景、E12能源结果、E14特瑞驶离后折返。**不强制复杂时间谜题** |

### B｜人物关系、世界系统与长线叙事（分集／整季）

| 参考导演／主创体系 | 可借鉴的具体判断 | 适用的现有剧情与限制 |
| --- | --- | --- |
| **文斯·吉利根／彼得·古尔德**（《绝命毒师》《风骚律师》主创） | 小决定带来连锁后果；日常职业、谈判和物件逐渐暴露人物性格与利益 | E08救人牺牲物资、E11杰西卡考虑机会却拒绝无凭空头船位、E14通过主动折返完成归属选择，而非办理居民身份。**不套犯罪升级或强制伏笔回收** |
| **乔纳森·诺兰／丽莎·乔伊**（《西部世界》主创） | 一个看似完整的局部社会背后有更大的公司体系、身份秩序与信息落差 | 旧公司撤离后的聚落、残存权限与E14外部探测悬念。**只能借层级感，不能把每场对话写成谜语** |

| **申源浩**（《请回答1988》导演） | 邻里群像、共同空间、平常玩笑与反复相处形成真正的归属感 | E02食堂、E04第一次酒吧小聚、E06街机与露台、E13熟悉后的聚会。**不靠轮流煽情或角色独白** |
| **宫崎骏**（《哈尔的移动城堡》） | 奇异机械结构也能成为有人居住、需要维护和彼此照顾的「家」 | E05会搬迁的生活街、基地废旧生活仓、E06温室与露台。**借生活的想象力，不改变本项目的写实电影美术** |
| **安德鲁·斯坦顿**（《机器人总动员》） | 通过物件、目光与动作建立机器陪伴和关系，不靠解释型台词确认情感 | E04残机小七与特瑞、E06小小的土豆实验、E14床头牌与归属。**不让小七越过现行残机能力边界** |

### C｜多人物节奏、黑色幽默与生活趣味（局部调性）

| 参考导演 | 可借鉴的具体判断 | 适用的现有场景与限制 |
| --- | --- | --- |
| **盖·里奇**（《两杆大烟枪》） | 性格鲜明的小人物在交易、误会、物件流转中形成轻快的连锁戏剧 | E02卡币小插曲、E05旧转运站交易、E11买不起所有补给的讨价还价。**不为炫技增加无谓骗局与巧合** |
| **姜文**（《让子弹飞》） | 对话中的立场、利益和权力关系有反击与幽默，但每句都有清楚对象 | 杰西卡与马克讨价、E13酒吧对旧公司的不同记忆。**不让所有角色变成机关枪金句或无意谜语台词** |

### 使用方法：不是「像谁」，而是「解决什么」

- **先定层级：** 需要拍空间时选摄影与物理参考；需要把一集写得有趣时选生活／戏剧参考；需要保证整季积累时选关系与社会系统参考。每次通常只选**一主一辅**，不给所有导演平均配额。
- **允许跨层组合：** E05《移动的家》可同时参考**斯科特的工业可信性 + 宫崎骏的居住趣味**；E07《绿洲采集》可参考**卡梅隆的生态行为 + 塔可夫斯基的环境观察**；E13《封沙之日》可参考**申源浩的群像相处 + 辛爽的旧时代记忆**。这些只是审稿比拟，不是追加镜头指令。
- **最终仍要回到导演实际选择。** 作品与风格参照只有在帮助解决**画面如何拍、人物为何行动、观众为何愿意追下去**时才有价值。若与导演最新描述或正典冲突，直接舍弃类比，不能用名导权威替它辩护。

## 三、《异星边境》的游戏创作起源（A：导演明确自述）

《异星边境》起始于导演**早期写过的一个独立游戏设想**，其设定与现今项目存在许多相似点，但当年远没有今天如此详细、严谨。导演没有展开早期游戏的具体设计，因此**不可擅自还原、补写或重新启用旧游戏设定**；当前剧集仍以仓库正式设定和剧本为准。**导演没有放弃未来将这套设定做成独立游戏的想法**，但尚无确定开发计划。不能把当前剧集改写成游戏任务结构，也不能把未来游戏视为已经立项。

## 五、待验证的整体审美推断

**B｜较强线索：** 你可以同时享受浩瀚的陌生世界与细小的人际关系；喜欢把环境探索、具体劳动、专业动作和日常生活拍得有重量。你明确喜欢的战争真实感，与希望虫群拥有独立生态，并不冲突；它们适用于不同场景。

**C｜仍待导演反馈：** 结合《绝命毒师》《风骚律师》《请回答1988》《漫长的季节》这些剧集，导演可能同样看重**时间如何积累关系、人物选择如何留下后果、表面平凡的人怎样变得可牵挂**。这更能解释为何此前他坚持有温度的基地群像、自然对白和可信的角色转变；但不能说他喜欢这些剧的每一项主题或摄影方式。

**C｜跨媒介假说：** 《异星边境》可能同时具有“探索世界／建设生活／认识伙伴／承受选择后果”的多种吸引力，而非仅是硬科幻冒险。**不是写作公式**：不得规定每集都要寻宝、打虫、升级、煽情或反转。

> 人格文件保留通用的导演判断；本文件承载审美模型和精简证据。新增喜欢的作品优先用于反证、强化或修正上面的维度，而不是再增加一张长作品卡。

## 六、长期维护

1. **标题不等于风格理解。** 喜欢某部作品，只证明喜欢某些元素，不能推断喜欢该作者全部作品、每一段剧情或同题材的一切。
2. **收集时追问具体吸引点。** 例如是影像运动、世界气质、人物关系、摄影机立场、配乐音效或游戏中的发现感；缺少时保持未确认。
3. **有反例允许更新。** “喜欢世界，但不喜欢叙事节奏”可以同时成立，不强行归类为绝对喜欢或讨厌。
4. **以预测力而不是藏品数衡量质量。** 有新作品优先更新对应维度，作品证据维持紧凑的组列；Git保存历史。只有稳定判断真正变化才更新 [导演人格正文](导演代理人格.md)，否则执行 NOOP。
