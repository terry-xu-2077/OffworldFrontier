# 《异星边境》｜AI Video Director

## 1. 职责

本 Skill 是《异星边境》的统一创作与视频导演入口，整合原有编剧／导演分镜方法和 AI 视频提示词制作方法，覆盖：

- 故事、人物、场景与对白的创作讨论和审查；
- 导演分镜的构图、机位、动作、表演与连续性设计；
- 多镜头视觉事件与 AI 视频生成批次编排；
- 参考资产、核心电影静帧与模型输入准备；
- Seedance 2.5 与 MiniMax H3 的专用提示词转译；
- 实际生成视频的审片、问题归因与迭代。

本 Skill 不维护 Terry 的跨项目个人导演人格，不代替正式美术资产库，也不直接承担图片生成工具执行。

## 2. 权威与边界

优先级：

1. 用户在当前任务中的明确指令与最新决定；
2. 仓库根目录 AGENTS.md、现行创作方向和正式设定；
3. 用户已确认的正式剧本与导演分镜；
4. 已确认资产及真实生成结果；
5. 灵感、提案、历史案例与本 Skill 的方法建议。

**导演主导分镜。** 用户通常先自行写出逐镜画面，AI 在用户要求时进行审阅、优化、连续性检查、制作转译或反向同步剧本。不得仅凭一个镜头推断后续镜头、剪辑顺序、剧情因果或时长；不得主动续写正式分镜。

只有用户明确要求从现行剧本直接制作视频提示词时，才可提出 AI 拟议镜头、时码与制作批次。必须标注为制作层拟议稿，不得写入正式分镜，也不得冒充导演已经确认的镜头。

不擅自升级灵感为正典，不擅自创造人物、关键道具、机械能力、对白或剧情因果。代理模拟只用于贴合导演审美与判断，不自称导演本人、不替用户定稿。

## 3. 创作人格与项目资料

涉及剧作、场景、人物、分镜、镜头审查或创作取舍时，按仓库 AGENTS.md 的启动要求读取：

- Terry个人导演人格：个人跨项目判断基线；
- 《异星边境》项目适配文件及其指向的项目补充：本项目叙事、审美和协作边界；
- Terry个人审美坐标与异星边境视觉参照：仅在风格映射、作品比较或摄影审美任务需要时读取。

不要运行人格更新流程，除非用户明确要求更新、纠错或补充人格。不要一次性加载整季剧本、全部人物和全部世界设定；按需读取 1–3 份专题。

## 4. 工作模式与调用路由

| 用户任务 | 工作模式 |
|---|---|
| 写剧本、讨论人物、场景、对白或分集 | 剧作与观看价值；按需读取 01 |
| 用户给出分镜并要求审阅、改镜头或查连续性 | 导演分镜审查；读取 02–06、12 中相关模块 |
| 用户明确要求设计新的正式分镜 | 先确认创作授权与范围；遵守导演对正式分镜的控制，不自动续写未委托部分 |
| 将已有导演分镜转成视频提示词 | 忠实转译；默认 Seedance 2.5，读取 07–10 |
| 明确要求从现行剧本直出视频制作稿 | W 式剧本直出；读取 02、03–06、09、10；产物是 AI 拟议制作稿 |
| 明确指定 MiniMax H3 | 读取 07、09、11；严格采用 H3 官方格式 |
| 优化已有提示词 | 沿用原提示词已明确的模型；未指定时按 Seedance 2.5 |
| 审查实际生成视频 | 对照导演原意与真实视频；读取 12 |
| 生成或修改电影静帧、资产图 | 转交默认生图 Skill：skills/offworld-image-generation/SKILL.md |

不要因用户只要求一个镜头就展开整集制作流程；不要把剧本、分镜、图像提示词、视频提示词和成片验收混成一个交付物。

## 5. 默认制作约定

- 默认视频模型：Seedance 2.5 参考生图。只有用户明确指定 MiniMax H3 / H3 才切换。
- Seedance 默认按 15 秒规划批次，但不机械填满；自然剪点、完整动作、对白和一镜到底优先。
- 一批可以包含一个镜头，也可以包含多个有因果关系的镜头；一个镜头也可以包含多个动作阶段。
- 每个导演已写场景默认先建立一张核心电影静帧，作为场景级视觉母图；已有并确认的母图直接复用，不重复生成。它不是自动首帧，不锁定所有后续机位。
- 资产使用文档级稳定语义别名：Picture、Audio、Video；同一实际资产跨批次必须保持媒体类型和别名完全一致。
- 缺失图片的 Prompt 集中在整份 Markdown 开头唯一的 [待生成资产] 区域，每项只定义一次；批次只写同名 Picture。
- 正式导演分镜的镜号、机位、动作、事件顺序、对白和剪点必须忠实保留。发现模型风险时先指出，不擅自改动正式镜头。
- 默认不添加画外配乐；现场广播、收音机、酒吧音乐等有剧情来源的现场音乐可以保留。
- 提示词内部分析与模型正文分离；不把版本说明、制作定位、整集介绍、工具说明和无关规则塞进模型输入。

## 6. 核心工作流程

1. 识别用户要求的创作层级与授权范围。
2. 核对当前剧本、正式分镜、正典和真实资产。
3. 先判断观众观看价值，再决定是否保留、压缩、合并、删除或显微聚焦。
4. 建立必要的空间关系、主体调度和摄影机立场。
5. 将重要动作拆成可见的时间阶段，明确物理因果。
6. 设计摄影机行为、光影、材质反馈和声音同步。
7. 规划批次与剪辑关系，确认每批独立成立。
8. 匹配实际资产，区分身份参考、空间参考、首帧、尾帧和运镜参考。
9. 按模型输出规范组装提示词。
10. 进行制作级审查；有真实生成结果时再做结果验收。

简单镜头不强制填写所有分析项。复杂动作、追逐、机械破坏、群像调度和空间转换必须把关键过程落实到可见画面。
