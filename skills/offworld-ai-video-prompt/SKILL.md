# 《异星边境》｜AI 视频提示词制作 Skill

> **默认模型：Seedance 2.5。只有导演明确说“H3 / MiniMax H3”才切换。**
> **默认工作：导演分镜 → 模型生成提示词；不是剧本 → AI 自动设计新分镜。**

本 Skill 整合导演此前使用的《W-分镜脚本大师》、本仓库 [编剧 × 导演分镜](../offworld-storyboard-director/SKILL.md) 的摄影／连续性／制作模块，以及 Seedance 2.5、MiniMax H3 官方生成规范。它是**制作层**，不创建另一份导演人格、故事正典或资产库。仓库级 SKILL.md 需被执行者实际读取，不等于自动安装到任何客户端。

## 1. 调用路由

| 用户的要求 | 进入的流程 |
|---|---|
| “转视频提示词”“按这几镜生成提示词”“写生成批次”“生成这一段”但未指定模型 | **Seedance 2.5**，读取 [Seedance 专项](references/seedance-2.5.md) |
| 明确说“用 H3 / MiniMax H3” | **MiniMax H3**，读取 [H3 专项](references/minimax-h3.md) |
| 要写／改剧本、设计新的导演镜头、审查戏剧效果 | 返回 [分镜与剧作 Skill](../offworld-storyboard-director/SKILL.md)；不擅用提示词转译取代导演工作 |
| 只说“优化这段提示词” | 沿用这段提示词已明确的模型；没有给出模型则按 Seedance 2.5 处理 |
| 同时要求双模型版本 | 分别输出两份可复制的提示词，不把两种模型的字段混在一起 |

仅因镜头太长、参考图太多、难以生成，不能自行将默认模型改成 H3。任何模型版本或参数限制随实际服务入口变化时，先核实再写；用户当前指定的后端优先。

## 2. 读取链：轻量但真实

1. **导演输入**：本轮用户描述／`创作/分镜/第一季/` 中对应的现行导演分镜；必要时查对应`创作/剧本/第一季/` 获取明确对白和戏剧因果。**镜头安排、运动、人物行为、顺序、镜号不得凭技术便利擅改**。若只收到一镜，处理这一镜，不补写下一镜。
2. **创作与摄影**：`AGENTS.md`、[摄影](../offworld-storyboard-director/references/cinematography.md)、[连续性](../offworld-storyboard-director/references/continuity.md)、[制作](../offworld-storyboard-director/references/production.md)。出现重大创作争议时再读 [导演代理人格](../director-persona-maintainer/references/导演代理人格.md)，不把“转译提示词”变成漫长审稿。
3. **视觉身份与正典**：[Google Drive 视觉资产索引](../../设定/美术设定/Google%20Drive视觉资产索引.md)，按需阅读人物／场景／生物／机械等1–3个相关专题，**实际打开对应原始资产图**。外形、颜色、部件、衣物、比例须随已核验图片，物理机制与人物行为须随文字设定。无法打开时标记**待核验**并说明，不假称已看图；绝不把参考图里的自动生成文字视为正式公司铭牌。
4. **模型专项**：默认 [Seedance](references/seedance-2.5.md)；明确指定 H3 才读 [H3](references/minimax-h3.md)。需要同一镜示范时可看 [E01 转译示例](references/e01-examples.md)。

只按当前任务加载必要文件，不通读全部十四集或照抄整份资产索引。

## 3. 导演意图在模型提示词前就锁定

从导演分镜提炼**不对用户重复罗列的轻量制作卡**：
- **观众体验**：这镜让观众看到、理解、期待或感到什么？动作是否展示角色的能力、关系和处境？
- **不可改变**：镜号／镜头切点、空间方位、视线、景别、FPV或车载POV区别、已有光源、表演节奏、台词原文、道具状态。
- **模型输入**：可用的身份图、场景图、首帧、上一镜**真实尾帧**、参考视频、音频；分别指定“锁定帧”“外形参考”“运镜参考”“声线参考”等用途。
- **自由细节**：镜头未指定但符合正典的可见纹理、少量环境反应、自然声音；不得凭空发明关键道具、旁支剧情、台词或镜头。
- **风险**：多人同时动作、镜头跨轴、复杂机械结构变化、手部交接、错置首帧、连续对白、模型无法一次兑现的多事件。

提示词原则：**先锁身份、空间与动作，再写表演、摄影、光和声音**；少用抽象风格词和禁令堆砌，多用肯定式的可见过程、起止状态。不要逐镜强加 ARRI 机身、品牌镜头、固定35mm、运动手持或胶片参数；只有有益于摄影语义时才写，尊重导演原稿的固定／跟拍／FPV／主观视角。真人写实、工业重量、自然表演为默认基调，但不把所有场景都拍成摇晃的动作片。

## 4. 拆分是制作任务，不是重剪导演分镜

- **Seedance 2.5：单次4–30秒**（可延长；具体入口可能不同）。**根据已经写好的镜头与戏剧节拍**确定批次，支持一镜一批，也支持多镜头合成一批。不给每批硬塞30秒。首选在明确的事件／景别／场面边界切分。
- **MiniMax H3：单次4–15秒**（以当时后端实际参数为准），模型专用时码和字段见专项参考。
- 原导演分镜可能只有2、3秒：可在一个生成批次中明确**保留多个原定切点**，或生成较长素材再由剪辑取段；不为满足单次时长把2秒镜头当成可直接生成的2秒API请求。不保证模型对切点的逐帧精度。
- 原定镜头长于上限时，**优先拆同一镜头的自然动作阶段**，沿用原镜号并加`A/B`批次尾缀，承接实际尾帧；若会影响运镜或表演设计，应在备注中指出取舍，而非偷改导演镜头。
- 并不是所有跨镜剪切都适合“尾帧续接”。**同一机位、同一动作、同一时空**可考虑延长／连续首帧；反打、机位跳转、时间跳跃用身份／空间参考加独立新构图，不要把上一镜尾帧强塞为新机位首帧。
- 默认只转译用户要求的镜头范围。需要全片列表时才计划完整批次，不额外生成未写镜头。

## 5. 连续性：模型输入与制作记录分开

跨批次**只追踪会影响下一镜的状态**：人物身份、衣物脏污/伤口、相对站位、左右朝向、道具ID/持有人/数量、设备开关与损坏阶段、灯光方向、时间与空间、未结束动作、环境和现场声。优先引用真实看过的片段／尾帧；没有生成素材时写“规划状态”，不能标“实际验证”。

**关键图片规则：** 若**有已提供的上一镜画面／真实尾帧**，且确有连续性需要，在 Seedance `[全局参考]` 中明确标注“图1：上一镜的画面／尾帧；用于……”。**若不是同一连续运镜**，图1只用于角色、道具、损伤、光线与空间状态参考；另给当前镜头的构图锚点。未上传的“图1”不得虚构，不可将参考资产图和上一镜尾帧混同。H3 的`<Picture 1>`只在其实际承担首帧／末帧等角色时使用，Ref2VA 中身份参考和帧锚点有不同标签。

**第一季重要防回退示例**：866是单人载具；FPV穿越机不等于驾驶舱POV；小七当前是不能自行移动的残机头部；E01遗迹返巢裂隙和后方施工道路断缝是两处不同地形；特瑞是经验丰富的拾荒老手，不为制造假紧张停下倒车再助跑。涉及这些元素的镜头必须回到原导演分镜及专题确认细节。

## 6. 影视化而非“AI炫技感”

- **动作与物理**：指定可见起点→受力/接触→推进→终点，重心、惯性、轮胎/机械腿地面反馈、衣料和扬尘随情况出现；只写与本镜主动作有关的细节，不把简单拿起物件变成冗长分解演示。
- **表演与潜台词**：用可观察的目光、停顿、转身、呼吸、手上动作来表达角色想法；并非每次都要夸张眉眼微表情。人物可以边走边说，保持行为连续，听者有真实反应。
- **镜头角色**：固定镜头、跟随、主观参与、窥视、FPV等随导演意图而定。镜头要在真实空间中有路可走；尊重180度轴线、视线匹配、声源与出口方向。允许经过门框遮挡、慢半拍追焦等有功能的真实偶然性，但不默认制造随机晃动。
- **色彩与世界**：真实材质、自然皮肤和工作痕迹、合理光源、工业沉重感；不预设全片霓虹、橙青、极端浅景深、慢动作、过度Bloom、完美棚拍皮肤。
- **声音**：优先人物原台词、同期环境声、机械声、脚步、衣物、风声等**有因的现场音**；**默认不生成人为画外配乐，音乐在后期统一处理**。场景内收音机、酒吧乐声等有剧情依据的**现场音乐**可保留，明确声源。台词原文保持不变，清楚谁说话、口气和听者反应，中文自然口语与口型，不擅加旁白／解释。
- **镜头目的**：不要加入“技术操作分解、反复确认、旁观者无意义提问”等只有流程没有观看收益的内容。技能做的是忠实转译；若原稿本身有这个问题，用简短制作风险说明，不未经许可改稿。

## 7. 默认交付方式

**用户仅要求一镜**：直接输出**一份可复制的模型提示词**；参考映射与持续状态仅写必要项。不展示冗长分析或技术报告。

**多镜／整场拆分**：按导演镜号给出精简**批次安排**（镜号范围、时长、生成模式、所需资产、依赖关系），然后逐批交付可复制提示词。批次名称在提示词外，防止模型把制作编号拍成可见文字。每个批次独立成立，不依赖模型阅读上一条聊天。中文 Seedance 默认采用`[导演说明]→[全局参考]→[连续性状态（有需要才写）]→[视觉与光影]→[分镜脚本（镜号/时间/动作/对白/现场声）]`；结构可按单镜复杂度压缩，不强制20/20/10/50字数配比，详见 [Seedance](references/seedance-2.5.md)。

**明确 H3**：使用其模型特定的英文段落和精确字段名，**绝不把 Seedance 的中文大标题冒充 H3 官方格式**；原文中文对白仍保留中文并标注`<d>[Chinese]…</d>`。详见 [H3](references/minimax-h3.md)。

**生成后验收**：比较**真正生成素材**与原镜的镜头目的、身份外观、空间尺度、动作逻辑、表演、声画、切点和前后状态。报告“已观察问题／推测原因／最小重生成调整”；不能凭提示词宣称模型已实现。验收仅针对收到并能够实际观看的素材，不自动创建新正典。

## 8. 权威与出处

- 导演上传：《W-分镜脚本大师》（会话原始资料；包含戏剧意图、真实手持/偶然性、表演、物理动作、光影、声音与连续性）。它原先偏向 Seedance 与长批次，但“镜头必须有观看价值”等原则保留；**固定电影机品牌、全场手持、过多微表情与无条件拆分不设为强制**。
- 官方：[ByteDance Seedance 2.5 产品](https://seed.bytedance.com/zh/seedance2_5)与[2026-07-31发布说明](https://seed.bytedance.com/zh/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)；具体入口参考其服务商说明，**不将某平台素材数量配额推定为所有平台通用**。
- 官方：[MiniMax H3 Prompt Writing](https://github.com/MiniMax-AI/MiniMax-H3/tree/main/skills/h3-prompt-writing)（官方完整说明与模式格式）。本仓库不复制其整份规范，使用时按版本核对。
