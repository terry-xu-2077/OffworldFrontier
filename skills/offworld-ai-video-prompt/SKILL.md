# 《异星边境》｜AI 视频提示词制作 Skill

> **默认模型：Seedance 2.5；默认生成方式：参考生图。** 只有导演明确说“H3 / MiniMax H3”才切换模型。
> **默认工作：先整理云盘资产文件名 → 对缺图给出中文生图提示词 → 为每场戏写一条核心电影静帧生图提示词 → 转译导演现有分镜。** 不代写新镜头。
> **双层输出硬规则：每场戏的制作包先交 `[核心电影静帧]`（场景级视觉母图）；每个独立 Seedance 视频批次的可复制提示词始终以 `[全局资产]` 开头。** 已有素材只写确切文件名，缺失重要素材附 Nano Banana／GPT 中文自然语言生图提示词。

本 Skill 整合导演此前使用的《W-分镜脚本大师》、本仓库 [编剧 × 导演分镜](../offworld-storyboard-director/SKILL.md) 的摄影／连续性／制作模块，以及 Seedance 2.5、MiniMax H3 官方生成规范。它是**制作层**，不创建另一份导演人格、故事正典或资产库。仓库级 SKILL.md 需被执行者实际读取，不等于自动安装到任何客户端。

## 1. 调用路由

| 用户的要求 | 进入的流程 |
|---|---|
| “转视频提示词”“按这几镜生成提示词”“写生成批次”“生成这一段”但未指定模型 | **Seedance 2.5 参考生图**；若本场尚无母图，先读 [核心电影静帧](references/core-scene-keyframe.md)，再读 [全局资产及缺图规则](references/asset-preparation.md) 和 [Seedance 专项](references/seedance-2.5.md) |
| 明确说“用 H3 / MiniMax H3” | **MiniMax H3**，读取 [H3 专项](references/minimax-h3.md) |
| 要写／改剧本、设计新的导演镜头、审查戏剧效果 | 返回 [分镜与剧作 Skill](../offworld-storyboard-director/SKILL.md)；不擅用提示词转译取代导演工作 |
| 只说“优化这段提示词” | 沿用这段提示词已明确的模型；没有给出模型则按 Seedance 2.5 处理 |
| 同时要求双模型版本 | 分别输出两份可复制的提示词，不把两种模型的字段混在一起 |

仅因镜头太长、参考图太多、难以生成，不能自行将默认模型改成 H3。任何模型版本或参数限制随实际服务入口变化时，先核实再写；用户当前指定的后端优先。

## 2. 读取链：轻量但真实

1. **导演输入**：本轮用户描述／`创作/分镜/第一季/` 中对应的现行导演分镜；必要时查对应`创作/剧本/第一季/` 获取明确对白和戏剧因果。**镜头安排、运动、人物行为、顺序、镜号不得凭技术便利擅改**。若只收到一镜，处理这一镜，不补写下一镜。
2. **创作与摄影**：`AGENTS.md`、[摄影](../offworld-storyboard-director/references/cinematography.md)、[连续性](../offworld-storyboard-director/references/continuity.md)、[制作](../offworld-storyboard-director/references/production.md)。出现重大创作争议时再读 [导演代理人格](../director-persona-maintainer/references/导演代理人格.md)，不把“转译提示词”变成漫长审稿。
3. **视觉身份与资产匹配**：先读 [Google Drive 视觉资产索引](../../设定/美术设定/Google%20Drive视觉资产索引.md)，必要时查 Drive 实际目录确认最新文件名，并读 [全局资产与缺图规则](references/asset-preparation.md)。**仅在 `[全局资产]` 列文件名不需重写外观描述**；但当任务实际要生成核心电影静帧/关键帧图片，必须执行 [默认生图 Skill](../offworld-image-generation/SKILL.md)：实际读取角色/载具/关键道具的原始图片作为身份参考，配合反推中文结构描述；环境基调从正式环境原图反推成文字，需要精确空间时再单独用环境图锁定布局。并按需读1–3份人物／场景／生物／机械专题。无法打开时标明依据索引或待核验，不假称已看图或已绑定；图中自动生成文字不是正典。
4. **场景视觉锚点与模型专项**：如果该场戏尚无已确认母图，读取 [核心电影静帧](references/core-scene-keyframe.md) 并提供一条场景级母图中文生图提示词；默认 [Seedance 2.5 参考生图](references/seedance-2.5.md)，明确指定 H3 才读 [H3](references/minimax-h3.md)。需要示范时可看 [E01 场景级母图与批次示例](references/e01-examples.md)。

只按当前任务加载必要文件，不通读全部十四集或照抄整份资产索引。

## 3. [全局资产]：必须排在视频提示词最前

**本 Skill 的默认输入是“参考生图”，不是纯文生视频。** 每个生成批次的第一节固定为 `[全局资产]`：将本批真正用到的角色、载具、场景、道具、生物和（如有）上一镜尾帧集中列出。**已有 Google Drive 文件只写真实文件名（含扩展名）及简短用途**，不附网址，不重复外观长描述，不假设文件已经上传到模型。

- **有资产**：例如 `- 特瑞角色：00_特瑞_Terry.jpg`、`- 866载具：蚂蚱载具.jpg`、`- 荒原材质：荒星地貌.jpg`。只从仓库资产索引或实际 Drive 目录查到的文件中选取，不把未确认文件名写成已存在。
- **缺资产**：写 `- 待生成资产｜XX：`，下一行直接给 `生图提示词：……`，用**一段中文自然语言**描述 Nano Banana／GPT 能生成的具体单图、多角度设定图或镜头首帧。约束正典、场面构图、空间尺度、光影与材质，优先有利于后续视频一致性，避免堆叠无效修辞。导演生成后，**以实际新文件名替换整条占位**，不用重写镜头内容；具体原则见 [资产准备](references/asset-preparation.md)。
- **上一镜尾帧**：参考生图也能使用真实前镜图片，但须区分**只继承身份／道具／方向**与**直接以它作为首帧继续相同动作**。已交付且确有该图片时按实际名称引用；未生成的写“上一镜尾帧：待上一镜制作后提取”，**不假设图1已经上传**。跨切点更换机位时不强制首帧接续，可另外补一张新镜头首帧。
- **不制作多余资产**：背景可由已有场景图和文字充分确定时，不必给每个角落补图；仅补**影响角色身份、特殊结构、空间稳定性或关键构图**的缺失资产。
- **H3 格式例外**：导演明确使用 MiniMax H3 时，仍先给 `[全局资产]` **作为提示词外部准备清单**；真正送入 H3 的提示词保持官方对齐指令与三字段／Ref2VA 六字段在最前，不能把中文资产标题塞入 H3 官方字段中。

带有“待生成资产”的结果是**制作草稿**：等图片生成、替换文件名并实际上传到视频工具后，才是一份资源绑定齐全的执行输入。

## 4. 核心电影静帧：一场戏先建立视觉母图

**每个已写出的场景／一段戏默认提供一条独立的「核心电影静帧生图提示词」**，输出名为 `[核心电影静帧]`。它引用现有角色、载具、道具和环境文件名，缺少关键参考素材就补一段中文自然语言生图提示词，再另外给出**核心电影静帧本身的**中文自然语言生图提示词。成图是**场景级视觉母图**，统一光线、综合色、空间透视、材质与人物/环境叙事关系，不是海报或一串分镜，也不必是场景第一镜的首帧。

- **先看观看价值**：选取能代表该场主要人物行为、戏剧关系与视觉气质的一个静态瞬间。明确摄影机立场与真实可达机位，决定性的前／中／远景和负空间、光源方向、人物尺度与动作阶段；不强制每张填满三层、添加旋转运镜或写死摄影机品牌。
- **一场只需一条**：已经提供过的母图优先复用，不重复创作；只有导演认可该场发生明显时空、主光源或视觉性质变化时才考虑新母图。以导演原场景结构为准。
- **参考 Cinema DNA**：按 [cinema-dna-21x9x3 3.1.1](https://github.com/dacnay816y62-hub/cinema-dna-21x9x3/blob/main/SKILL.md) 的单帧构图、观看立场、物理空间、参考图角色及光线连续性方法写作；**不强制三联／九宫格，不把其默认2.39:1误称严格21:9**，实际画幅尊重导演指定。
- **母图不是视频镜头首帧**：场景母图只规定视觉基调。各视频镜头保留原导演摄影机位置、景别和动作，参考母图时不强制变成母图机位；只有导演明确选它做首帧且画面与动作兼容时才锁定首帧。
- **先生成再引用**：母图尚未实际生成时只写“核心电影静帧：待导演生成后回填”，不编造已存在的文件或“图1”；导演生成并核对后在后续视频批次的 `[全局资产]` 中按其**真实文件名**引用。
- **分层结构**：每场戏制作包可先展示 `[核心电影静帧]`，**每个视频批次独立的模型输入块仍以 `[全局资产]` 起头**。这样不破坏现有的批次模板与 Seedance 素材匹配规则；H3 的官方格式保持独立。
- **专项细则及可复制模板**：见 [核心电影静帧规范](references/core-scene-keyframe.md)。此处不重复维护一套冗长的摄影技巧正文。

## 5. 导演意图在模型提示词前就锁定

从导演分镜提炼**不对用户重复罗列的轻量制作卡**：
- **观众体验**：这镜让观众看到、理解、期待或感到什么？动作是否展示角色的能力、关系和处境？
- **不可改变**：镜号／镜头切点、空间方位、视线、景别、FPV或车载POV区别、已有光源、表演节奏、台词原文、道具状态。
- **模型输入**：可用的身份图、场景图、首帧、上一镜**真实尾帧**、参考视频、音频；分别指定“锁定帧”“外形参考”“运镜参考”“声线参考”等用途。
- **自由细节**：镜头未指定但符合正典的可见纹理、少量环境反应、自然声音；不得凭空发明关键道具、旁支剧情、台词或镜头。
- **风险**：多人同时动作、镜头跨轴、复杂机械结构变化、手部交接、错置首帧、连续对白、模型无法一次兑现的多事件。

提示词原则：**先锁身份、空间与动作，再写表演、摄影、光和声音**；少用抽象风格词和禁令堆砌，多用肯定式的可见过程、起止状态。不要逐镜强加 ARRI 机身、品牌镜头、固定35mm、运动手持或胶片参数；只有有益于摄影语义时才写，尊重导演原稿的固定／跟拍／FPV／主观视角。真人写实、工业重量、自然表演为默认基调，但不把所有场景都拍成摇晃的动作片。

## 6. 拆分是制作任务，不是重剪导演分镜

- **Seedance 2.5：单次4–30秒**（可延长；具体入口可能不同）。**根据已经写好的镜头与戏剧节拍**确定批次，支持一镜一批，也支持多镜头合成一批。不给每批硬塞30秒。首选在明确的事件／景别／场面边界切分。
- **MiniMax H3：单次4–15秒**（以当时后端实际参数为准），模型专用时码和字段见专项参考。
- 原导演分镜可能只有2、3秒：可在一个生成批次中明确**保留多个原定切点**，或生成较长素材再由剪辑取段；不为满足单次时长把2秒镜头当成可直接生成的2秒API请求。不保证模型对切点的逐帧精度。
- 原定镜头长于上限时，**优先拆同一镜头的自然动作阶段**，沿用原镜号并加`A/B`批次尾缀，承接实际尾帧；若会影响运镜或表演设计，应在备注中指出取舍，而非偷改导演镜头。
- 并不是所有跨镜剪切都适合“尾帧续接”。**同一机位、同一动作、同一时空**可考虑延长／连续首帧；反打、机位跳转、时间跳跃用身份／空间参考加独立新构图，不要把上一镜尾帧强塞为新机位首帧。
- 默认只转译用户要求的镜头范围。需要全片列表时才计划完整批次，不额外生成未写镜头。

## 7. 连续性：模型输入与制作记录分开

跨批次**只追踪会影响下一镜的状态**：人物身份、衣物脏污/伤口、相对站位、左右朝向、道具ID/持有人/数量、设备开关与损坏阶段、灯光方向、时间与空间、未结束动作、环境和现场声。优先引用真实看过的片段／尾帧；没有生成素材时写“规划状态”，不能标“实际验证”。

**关键图片规则：** 在最前面的 `[全局资产]` 中引用已提供的上一镜真实尾帧（按实际文件名或平台已有引用名）。**同一连续动作**可从该尾帧继续；**切换新机位**时只将它作为人物、道具、损伤、光线或方位参考，当前镜头另建正确构图。未生成的尾帧只标“待上一镜制作后提取”，不可虚构“图1”。H3 的 `<Picture 1>` 只有在确实对应模型资产标签时才使用，Ref2VA 的主体与画面锚点有不同引用角色。

**第一季重要防回退示例**：866是单人载具；FPV穿越机不等于驾驶舱POV；小七当前是不能自行移动的残机头部；E01遗迹返巢裂隙和后方施工道路断缝是两处不同地形；特瑞是经验丰富的拾荒老手，不为制造假紧张停下倒车再助跑。涉及这些元素的镜头必须回到现行剧本及专题确认细节。

## 8. 影视化而非“AI炫技感”

- **动作与物理**：指定可见起点→受力/接触→推进→终点，重心、惯性、轮胎/机械腿地面反馈、衣料和扬尘随情况出现；只写与本镜主动作有关的细节，不把简单拿起物件变成冗长分解演示。
- **表演与潜台词**：用可观察的目光、停顿、转身、呼吸、手上动作来表达角色想法；并非每次都要夸张眉眼微表情。人物可以边走边说，保持行为连续，听者有真实反应。
- **镜头角色**：固定镜头、跟随、主观参与、窥视、FPV等随导演意图而定。镜头要在真实空间中有路可走；尊重180度轴线、视线匹配、声源与出口方向。允许经过门框遮挡、慢半拍追焦等有功能的真实偶然性，但不默认制造随机晃动。
- **色彩与世界**：真实材质、自然皮肤和工作痕迹、合理光源、工业沉重感；不预设全片霓虹、橙青、极端浅景深、慢动作、过度Bloom、完美棚拍皮肤。
- **声音**：优先人物原台词、同期环境声、机械声、脚步、衣物、风声等**有因的现场音**；**默认不生成人为画外配乐，音乐在后期统一处理**。场景内收音机、酒吧乐声等有剧情依据的**现场音乐**可保留，明确声源。台词原文保持不变，清楚谁说话、口气和听者反应，中文自然口语与口型，不擅加旁白／解释。
- **镜头目的**：不要加入“技术操作分解、反复确认、旁观者无意义提问”等只有流程没有观看收益的内容。技能做的是忠实转译；若原稿本身有这个问题，用简短制作风险说明，不未经许可改稿。

## 9. 默认交付方式

**用户仅要求一镜**：如果该场戏已提供过核心电影静帧，复用其真实文件名；如果还没有，为这个场景先补**一条** `[核心电影静帧]`。然后本镜 Seedance 视频提示词仍从 `[全局资产]` 开头（已有文件名 + 缺图中文生图提示词），连续状态只写必要项，不展开无关审稿。

**多镜／整场拆分**：**先每场戏交一次 `[核心电影静帧]`**（含资产引用和中文母图提示词），再按导演镜号给出精简**批次安排**（镜号范围、时长、生成模式、所需资产、依赖关系），逐批交付可复制提示词。批次名称在提示词外，防止模型把制作编号拍成可见文字。每个批次独立成立，不依赖模型阅读上一条聊天。中文 Seedance 默认采用**`[全局资产]`（永远最前）→`[导演说明]`→`[连续性状态]`（有需要才写）→`[视觉与光影]`→`[分镜脚本]`→`[声音]`**；结构可按单镜复杂度压缩，不强制20/20/10/50字数配比，详见 [Seedance](references/seedance-2.5.md)。

**明确 H3**：若本场没有母图仍先交场景级 `[核心电影静帧]`，再单独列出 `[全局资产]` 用于制作准备，随后另起完整的官方 H3 纯提示词块，使用其模型特定的英文段落和精确字段名，**绝不把 Seedance 的中文大标题冒充 H3 官方格式**；原文中文对白仍保留中文并标注`<d>[Chinese]…</d>`。详见 [H3](references/minimax-h3.md)。

**生成后验收**：比较**真正生成素材**与原镜的镜头目的、身份外观、空间尺度、动作逻辑、表演、声画、切点和前后状态。报告“已观察问题／推测原因／最小重生成调整”；不能凭提示词宣称模型已实现。验收仅针对收到并能够实际观看的素材，不自动创建新正典。
