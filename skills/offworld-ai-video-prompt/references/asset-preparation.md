# 全局资产与缺失资产补图｜跨模型制作约定

## 目标与默认工作流

**先查资产、再写视频提示词。** 在当前导演镜头需要的资产里，优先使用《异星边境》Google Drive 的现有文件；没有的关键人物、场景、道具、生物、载具或镜头画面，给出可直接用于 **Nano Banana／GPT 自然语言生图** 的一段**中文提示词**，供导演自行生成，随后把占位文字替换成文件名。

**所有独立视频提示词块在开头先有 `[全局资产]`。** 但**场景级制作包**在视频批次之前，应先提供该场的 `[核心电影静帧]`（已有正式母图则引用，不反复生成）。两者分工见 [核心电影静帧专项](core-scene-keyframe.md)。 对默认 Seedance 2.5，直接放在可复制的视频提示词最前；对明确指定 H3 的任务，`[全局资产]` 作为**独立的制作清单**写在其官方格式视频提示词外面，官方 H3 字段与首帧指令不得被插入额外自定义字段。

## 1. 找资产：名称必须来自证据

1. 优先查询仓库 [Google Drive 视觉资产索引](../../../设定/美术设定/Google%20Drive视觉资产索引.md)，其顶端提供 [资产库根目录](https://drive.google.com/drive/folders/1BYxT36wsuk6xPgZ-Y48q_YiAn6OVeKM6)。需要确认索引时效或名称时，可访问 Drive 根目录及其人物、载具、道具、生物、环境、LOGO 子目录，以**真实文件名（含扩展名）**为准。
2. `[全局资产]` 中已有素材**只写文件名**，可以用短角色/场景名明确用途（例：`- 866载具：蚂蚱载具.jpg`）。**不贴云盘 URL、不搬运整套外观描述、不虚构 @ 标签或图1编号。**
3. 同名不同格式须保留准确扩展名，例如 `00_特瑞_Terry.jpg` 是多角度造型卡，`00_特瑞_Terry.png` 是脸部参考。镜头无需脸部特写时不用重复列全部素材。
4. 对**仅列文件名**，已核对索引或 Drive 文件列表就可确认文件名称；若要凭视觉属性描述外形、构图、材质或让它成为实际生图依据，仍需打开对应原图并核对正典。**文件存在不代表已上传视频模型。** 工具不可访问时如实告知所依据索引版本，不能声称实时看过画面。
5. 先检查整个目录及跨分类可能的文件，不应只因某一子目录里没有，就认定整个资产库缺失。

## 2. 缺图才补图，区分不同用途

只有镜头**真正需要视觉锁定**、又找不到合适的正式资产时，才写缺失资产占位。禁止为每把椅子、每块碎石自动创建补图清单。常见：
- **基础资产设定图**：新角色、机械、生物、道具，通常优先清晰外观/合理角度/比例；如果模型需要固定外观，给一张易复用的设定图，不只拍氛围。
- **场景空间资产图**：未建档的菌伞峡谷、矿洞支线等，展示通道、出入口、尺度、主光方向与真实空间关系；画面要能约束后续多镜构图。**这张基础环境设定图不同于场景级「核心电影静帧」**：环境图侧重可复用空间事实，电影母图则使用真实人物/载具/动作阶段拍成一张具有戏剧信息的单帧。
- **镜头首帧／关键帧图**：确需锁住机位、景别、人物站位、视线、动作阶段和可见物体状态时生成；不是把设定图当成首帧。
- **上一镜真实尾帧**：这是**前一次视频生成/导出的实际图像**，不是某张独立设定图。**尚未生成时标注“上一镜尾帧：待上一镜制作后提取”**，不能把凭空生的图片伪称“上一镜真实尾帧”；确实需要为下一镜预先构图，可另补“下一镜独立首帧图”。

## 3. 缺失资产的中文自然语言提示词写法

写成**可单独复制给 Nano Banana / GPT 生图的一段连贯中文自然语言**，具体、可见、可执行，不用英语标签、Midjourney 参数、过度罗列“高质量/8K/电影级”等空词，也不堆一长串否定提示。

一段合格的补图提示词在自然语言中明确：
1. **这是什么资产、给哪个镜头/场景用、输出单张图或多角度设定图**；
2. **主体与环境的实体关系**：尺寸对照、正典造型与材质、关节/接口/结构、环境中的地形与通路（按需）；
3. **构图或视图**：景别、相机位置与拍向、主体在画面的位置、前中后景；若要作为视频首帧，必须写画面中动作**已经到哪一步**；
4. **真实光照与材质**：光源方向、旧化痕迹、粉尘、表面反射、工业重量、影视写实质感；
5. **与已有资产的一致性**：可以说“以已提供的某张现有参考图作为外观/材质依据”，但该图片是否真正输入生图平台仍取决于导演；**不得用文字幻想出未核验图像中的具体构造**；
6. **留白与限制**：不擅加未确定的新设备能力、角色、公司 LOGO 或可读铭文，不把单张环境参考图升格为新的世界设定。

语气示意（**不是项目正式资产**）：`请生成一张用于《异星边境》连续镜头的旧矿井侧巷场景参考图。摄影机位于……，画面中……，……`。如果是机械设定图，将“镜头场景”替换成“独立资产多视角结构图”；如果是首帧，就固定镜头所见的**具体瞬间**。

## 4. 全局资产占位结构与回填

```text
[全局资产]
- 特瑞角色：00_特瑞_Terry.jpg
- 特瑞脸部：00_特瑞_Terry.png
- 866载具：蚂蚱载具.jpg
- 本场核心电影静帧：待导演生成后回填（母图真正生成时写实际文件名）
- 上一镜尾帧：待上一镜制作后提取（如果确有承接且尚无视频；不是已上传图片）
- 待生成资产｜XX场景参考图：
  生图提示词：请生成一张……（完整自然语言中文段落；导演生成后把此条替换成：XX场景参考图.jpg）
```

**回填示例**：`- 待生成资产｜XX场景参考图：生图提示词：……` → `- XX场景参考图：XX场景参考图.jpg`。新文件名必须来自导演实际交付，不能提前替导演命名并声称文件已存在。

如果导演一轮只要“资产预检”，可以只交付 `[全局资产]` 与缺图提示词，不强制续写视频镜头；如果导演要视频提示词，则连同镜头转译一起交付。**带待生成资产占位的文本是制作草稿，等缺失图片生成并在实际模型上传后再执行视频生成**。

## 5. 同一镜续接 vs 切新镜

- 真正连续的动作、相机路径：可用上一镜实际尾帧或源视频，明确“用其当前姿态接着做什么”；上一帧是参考生图模式的一种参考输入，不意味着摄影机必须锁在原来的机位。
- 从 FPV 切驾驶 POV、反打、固定远景或跨越时间：上一镜可作为**身份/状态/方向参考**，但当前画面必须有**新的构图**；不要误把前镜尾帧当成新的首帧锁定图。
- 参考图/尾帧未实际提供时，仅在全局清单标注计划来源；不能自填 `图1`、`@图1` 或官方 H3 `<Picture 1>` 占位当成真实绑定。

## 6. 资产预检

- 资产名是否与索引或实际 Drive 列表**完全一致**，含符号与扩展名？
- 是否仅列与此批镜头相关的素材，而非所有41张？
- 有缺失资产时是否提供可**直接生图**的具体中文自然语言提示词？是否区分基础资产和镜头首帧？
- 上一镜尾帧是否**真实存在**？如果没有，是否标注为计划而非伪造？
- 所有现有文件名只是资源清单，没写成“模型已经引用”或“图像已经验证”？
- 生图提示词是否尊重现有视觉资产、导演原稿、世界设定与物理连续性？
