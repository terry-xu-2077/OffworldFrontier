# 剧本直出 Seedance 视频批次｜自足格式规范

## 使用条件和授权边界

仅当导演明确提出「直接按剧本写视频提示词」「测试从剧本生成提示词」或等效指令时启动。可为拍摄/AI生成设计**临时镜头、机位、时间段与批次**，但它们属于制作提议，**不是导演已确认的正式逐镜分镜**；不得写入创作/分镜、不得反向覆盖剧本、不得把生成秒数确认为成片片长。如果导演已经提供该段逐镜分镜，仍然忠实转译，不擅改原镜。

**本规范独立可执行，不必读取任何过去的提示词成品、示范批次或其他AI生成结果。** 导演认可的旧稿可以额外用于口味对照，但不能成为生成所需输入。

## 先做什么

1. 读取目标剧本、当前连续性、必要的角色/地点/道具设定以及Google Drive视觉资产索引；本模式会提出摄影方案，须遵循AGENTS.md和导演代理人格的观看价值判断。
2. 按剧本原顺序列出本集的剧情节拍、人物、道具流向及原文对白，再为每场选择镜头。可以补摄影调度，不得自行补关键剧情、人物身份、独立事件、道具新能力或改角色对白。
3. 每场决定一个观众体验（陌生的巨墙、由风声走到人声、矿井尺度、维修受挫、食堂幽默等），让镜头空间和人的行为达成，而不是把技术操作拍成纪录流程。
4. 对话逐字保留。长对话可跨批次，通过原文口播、反应与行动分配时间；不能为了套短时长而概括、替换、吞句。如只测部分场次，明确范围，不宣称已经覆盖全剧。
5. 每批约1–4镜、8–24秒为常见但非强制，实际平台单任务上限优先；每镜以批次内0秒为起点，时间连续，最后秒数等于批次总时长；超过一批就拆。独立批次每份可复制，不用「同上」。
6. 每场先配一条核心电影静帧的中文单图提示词或引用导演已确认的实际母图。母图只是空间/光色母本，不自动是每镜首帧；还没出图的仅写制作占位。

## 逐批稳定格式（七栏目必须齐全）

每个视频批次的模型提示词必须按下列顺序，使用下述栏目**精确名称**。

【1】[全局资产]：按实际资产库索引列本批真实文件名（包括扩展名），每个只列一句用途，缺图给「待生成资产｜名称：生图提示词：……」。未知上传映射**不用**假定 <Picture 1> 或 @图1 已绑定；平台确实上传后可另外写图号映射。

【2】[导演说明]：具体说明本批观众体验、镜头关系和节拍，而非每批复制一段全剧口号。

【3】[全局参考]：用本批已列的资产名称写清哪张锁人物、哪张锁机械/空间/道具。与[全局资产]不重复粘贴外观说明；真实上传前只叫「拟用参考」。

【4】[连续性状态]：人物位置、持有物、载具损坏、时间段、前批的关键状态或声画承接。每批写成独立可读，不省略此栏。

【5】[视觉基调]：真人实景电影质感、可信旧工业重量和自然表演；可以以ARRI Alexa Mini LF与Signature Prime为摄影意向，但镜头运动、镜头焦距随场面目的改变，不机械要求所有镜头高速飞行。

【6】[色彩光影]：描述该场确实存在的天光、实用灯、阴影、空气与材质反射（外墙日暮、双闸探灯、室内暖灯、温室水汽等），防止全片每场同一色彩描述。

【7】[分镜脚本]：每镜用以下**原样四字段**，包括镜头号与批次内起止秒：
镜头01｜[0–5.0s]
景别 / 焦段：…… / ……mm
运镜 / 视角：摄影机具体位置，运动路径、取景方向和结束方式。
画面描述：可见人物/物体，起始状态→发生的物理动作或表演→结束可见状态；如有台词，标出角色和剧本**原文**，给足说话时长。
声音 / Foley：现场环境音Amb、动作声Foley、说话者或广播的声源与距离；无画外配乐。

【格式边界】批次编号、制作注释、验收结论和场景母图放在各独立提示词**外面**。每批从[全局资产]真正开始；完整剧集文件的标题、索引不算模型输入。如有两镜，镜头02从镜头01结尾秒数继续。声画J-Cut/L-Cut可写入当镜，不自动添加背景配乐。

## 影像强度与生活戏平衡

- 每镜有明确的**观看目标**与可拍起止，典型镜头的画面描述自然展开到70–200汉字左右，简单镜头可更短；不因字数重复形容词。机械重量、人物动作、衣物、风、矿尘、光线只写与本镜相关的物理反馈。
- 外部运动镜可用强FPV；门口对峙、温室、维修、食堂应按观看立场灵活采用固定、带呼吸的手持、低位观察、跟晚半拍的重新找构图。空间真实，转焦允许自然误差；不要每镜都360度环绕。
- 对白、环境声与Foley逐镜对应，不把一批所有声音挤到结尾；扩音器与近距离说话有空间差，闸门打开的人声有可辨的声画变化。
- 角色可以边做事边说，重要对白完整自然，至少给出口唇动作、被回应者或对话互动的镜头时间；不能把三句长对白安排在3秒内。
- 面部、服装、载具和建筑使用真实资产。资产索引证明文件名但不等于实际已看图或视频平台已上传。若没有造型原图，写「据当前索引及文字设定」。
- 剧本内容写进视频批次不等于导演同意这套镜号或时码；不把临时镜头放进创作/分镜。

## 静态验收清单

1. 覆盖全部剧本场次、每个关键行动与结果；没覆盖的如实列明。对白文字保真，台词归属准确。
2. 每批依次包含七栏目，所有镜头具有编号时间、焦段、运镜、画面描述与声音/Foley；每批内部时段连续不超出所标批次时长。
3. 每批可独立复制，具体资产列真实文件名、必要缺图写完整生图提示，不引用不存在的尾帧、不把未上传的图标作已绑定。
4. 角色动机、跨集道具、机械故障、地理位置、日期/天气状态与现行正典相符。
5. 电影风格统一但各场摄影节拍有变化；观众能同时体验陌生世界的奇观与普通人的日常，而非技术说明会。
6. 未真实生成视频之前，只能称「文本静态测试通过」，不可宣称画面/音色/模型时码已成功复现。
