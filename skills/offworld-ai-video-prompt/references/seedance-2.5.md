# Seedance 2.5｜默认中文视频提示词规范

**适用：没有指定模型，或明确指定 Seedance 2.5。** 不生成 H3 的 `integrated_multimodal_description` 等字段。这里的结构是《异星边境》项目的**建议组织格式**，不是声称 Seedance 官方强制解析`[导演说明]`等标题。

## 1. 能力与时长

- ByteDance Seed 官方（2026-07-31）发布：**单次最长30秒**，多轮延长、改进多镜头叙事、支持多模态参考与编辑。[官网](https://seed.bytedance.com/zh/seedance2_5)｜[发布说明](https://seed.bytedance.com/zh/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)。
- BytePlus ModelArk 和 Runway 的公开入口文档以**4–30秒**为单次时间范围（某些编辑任务直接继承原视频时长）；“自动时长”与具体可选尺寸、参考文件数量等**取决于实际使用的平台和模式**。官方架构能力不等于所有渠道当前界面都开放。[BytePlus 文档](https://docs.byteplus.com/en/docs/modelark/seedance-2-5)｜[Runway使用指南](https://help.runwayml.com/hc/en-us/articles/53542207042323-Creating-with-Seedance-2-5)。
- 提示词写**导演希望的实际叙事时长**，例如11秒；不用满额30秒。多镜头批次保持导演剪辑顺序，给每镜**批次内起止秒**（“镜头1｜0–5s”等），**切点为制作目标而非逐帧保证**。
- 2秒镜头若单独不足可选下限，和同场下一个已写镜头组成同一任务，分别保留原定镜号／切点；或生成较长素材供剪辑截取。不新编镜头填时长。

## 2. 制作模式选取

| 模式 | 条件与提示词重点 |
|---|---|
| 文本生成 | 没有具体帧输入；建立真实空间、人物和动作，交代首末构图 |
| 多模态参考生成 | 人物/载具/场景/声音各有素材；标注每个资产的唯一用途，不能把参考图说成自动固定首帧 |
| 首帧／首尾帧 | 明确帧锁定，动作**从首帧已有阶段继续**，到末帧落位；不要从“还没拿到杯子”重新演已经握住杯子的动作 |
| 视频延长 | 仅在**确实同一时空/镜头或导演明确要连续衔接**时延长；继承真实尾帧里的姿态、运动和声场 |
| 视频编辑 | 给出**要保留的部分+要改的部分**，精确对象和范围，尽量修局部，不额外改造导演已经通过的镜头 |

**资产名的绑定规则：** 可以用“图1/图2/视频1/音频1”作为**制作映射示意**，但最后编号必须与用户实际上传或所用平台标签一致；平台若用`@引用`，才将名称改写成该平台真实支持的`@文件名`。不自动编造可用资源编号或声线参考。仅凭仓库索引知道某资产存在，不等于当前生成工具已加载它。

## 3. 提示词的分镜粒度

- **镜头内物理动作**：现有状态 → 核心动作 → 变化结果。速度、重量、惯性、衣料、尘土只在可见且相关时补充。
- **摄影**：固定、平移、摇摄、推轨、拉焦、FPV、POV等是不同动作；明确主体、相机的相对位置、方向、幅度和结束方式。不要用“镜头快速绕着主体飞行”替换固定中景。
- **表演**：动作中的表情转变胜过情绪形容词；自然说话，在动作里插入看与被看，不为口型强迫角色停止工作面对镜头。
- **空间**：位置、前后景、出入口、光线方向、机械尺寸、角色手里的物品在切镜后保持一致。
- **群像**：本镜一个清晰主行为，其他人在空间里自然工作，避免每个人同时执行独立精密动作。高负荷的多段物理事件如造成模型冲突，应**标注“建议独立生成/拆任务”**，而不是偷偷删掉导演指定行为。
- **对话和声音**：保留台词原字，注明谁说、说话时动作、声线和听者反应；环境底噪、机械声、脚步声、碰撞声随动作同步。默认**没有画外配乐**；若场景存在被人物听到的音乐，写明声源（例如收音机）。

## 4. 可复制模板（按需要删掉空项）

> 批次名、实际文件映射和技术备注应放提示词外面；下面是**模型可读提示词**，可按一镜/多镜动态压缩。

`
[导演说明]
本段时长X秒。核心戏剧感受：……。本段承接……，在……时结束。摄影机是……（固定观察/低空自由FPV/真正驾驶舱主观……），镜头的节奏……。

[全局参考]
图1：……（如有真实上一镜尾帧，说明它是“上一镜尾帧”；作用仅为身份/运动连续性或确实锁定首帧）。
图2：……（人物外貌/衣物）。
图3：……（866造型/场景布局/生物形态）。
视频1：……（仅借用镜头运动；或者“直接延长此视频”，不可混淆）。
音频1：……（若实际提供，声线/现场声参考）。
只列本批实际上传或确实可用的素材，不存在就省略该行。

[连续性状态]
从上一镜的……状态开始，……仍在左侧/右侧，……被……握持；……保持已受损/关闭/点亮的状态。若无必要省略。

[视觉与光影]
写实真人电影感，……场景的真实可见材质。光从……方向进入，……形成相应阴影；摄影运动与光线配合……。不要机械列全套机身/镜头品牌。

[分镜脚本]
镜头XX｜0–Xs：起始构图和镜位……。人物……，动作由……发展至……。摄影机……。同期听见……。若有对白，人物在……动作中说：“原文台词。”听者……。

镜头XY｜Xs–Ys：（仅当导演该批确实有第二镜）在……切镜；沿用……空间关系，主体……；声音……延续/改变。

[声音]
环境声……；关键动作声……；对话采用自然中文口型，声线……。画外配乐：无。
`

**单镜简版**优先：当镜头很简单时，只写“参考用途 → 首帧 → 动作与镜头 → 末帧 → 同期音/对白”。不要让多级标题喧宾夺主。

## 5. 跨镜图1与真实视频

- **同一动作延续**：图1若确实为上一镜尾帧，写“图1为上一镜末帧，本段0秒从其可见状态连续动作开始”，实际设为首帧/延长源时依对应模式执行。
- **新机位/剪切反打**：写“图1仅供人物服装、伤口、道具和空间状态参考；本镜从新的侧前方构图开始”，不可强制上一画面本身充当当前新机位的首帧。
- **仅有上一条文字**：说明“上一镜状态依据分镜规划，缺少实际尾帧”；不捏造“图1”。
- **导演已规定固定镜位或切点**：不凭长镜头模型能力改成炫技一镜到底。

## 6. Seedance 2.5 专项验收

在真实生成片段中核查：
1. 主体人物／服装／机械外形是否跟资产相符，FPV/POV/固定镜位是否按要求；
2. 原镜头的动作、事件顺序与对白是否完整，且没有模型擅加桥段；
3. 地形、视线、道具、受损状态是否连续，追逐路线是否可理解；
4. 剪点与节奏是否能在后期实际实现（不要求生成恰好逐帧剪切）；
5. 声画是否对应、对白是否准确、有没有无意加入配乐；
6. 如失败，局部精简动作／减少并发主体／提高参考约束或改为分批，不随便重写原导演镜头。
