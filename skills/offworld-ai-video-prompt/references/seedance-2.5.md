# Seedance 2.5｜默认中文视频提示词规范

**适用：没有指定模型，或明确指定 Seedance 2.5。** **原有导演逐镜转译的参考生图模式**：可用角色、场景、道具、载具等参考图，也可引用上一镜实际帧作为连续性依据。**导演逐镜转译时，每场戏的制作包按需先交一次 `[核心电影静帧]`（参照现有资产、缺失素材补图、中文母图生图提示词），再进入视频生成批次；**原有逐镜转译模式的独立视频提示词块从 `[全局资产]` 开始；明确剧本直出则从 `[导演说明]` 开始**，已有云盘资产只写文件名，没有的关键资产在该节给出 Nano Banana／GPT 中文自然语言生图提示词。** 不生成 H3 的 `integrated_multimodal_description` 等字段；本项目的中文标题用于组织制作信息，不宣称 Seedance 官方强制解析这些标题。资产匹配和缺图规则见 [资产准备](asset-preparation.md)。

## 1. 能力与时长

- ByteDance Seed 官方（2026-07-31）发布：**单次最长30秒**，多轮延长、改进多镜头叙事、支持多模态参考与编辑。[官网](https://seed.bytedance.com/zh/seedance2_5)｜[发布说明](https://seed.bytedance.com/zh/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)。
- BytePlus ModelArk 和 Runway 的公开入口文档以**4–30秒**为单次时间范围（某些编辑任务直接继承原视频时长）；“自动时长”与具体可选尺寸、参考文件数量等**取决于实际使用的平台和模式**。官方架构能力不等于所有渠道当前界面都开放。[BytePlus 文档](https://docs.byteplus.com/en/docs/modelark/seedance-2-5)｜[Runway使用指南](https://help.runwayml.com/hc/en-us/articles/53542207042323-Creating-with-Seedance-2-5)。
- 提示词写**导演希望的实际叙事时长**，例如11秒；不用满额30秒。多镜头批次保持导演剪辑顺序，给每镜**批次内起止秒**（“镜头1｜0–5s”等），**切点为制作目标而非逐帧保证**。
- 2秒镜头若单独不足可选下限，和同场下一个已写镜头组成同一任务，分别保留原定镜号／切点；或生成较长素材供剪辑截取。不新编镜头填时长。

## 2. 生成模式与资产绑定

原有导演逐镜转译模式默认以**参考生图**来准备，即使该镜尚未有所有图片，也先完成 `[全局资产]` 清单与必要的缺图提示词，待导演补图后即可回填。**参考生图可引用上一帧**，但“参考上一帧”与“把上一帧锁为新片段首帧”不是同一个要求。

| 制作情况 | 如何处理 |
|---|---|
| 有角色／载具／场景／道具图片 | 参考生图；文件名写入 `[全局资产]`，声明角色身份、场景布局、外形或材质参考用途 |
| 缺关键画面资产 | 在 `[全局资产]` 中写 `待生成资产` + 中文 Nano Banana／GPT 生图提示词，等待用户生好后把条目替换为文件名 |
| 有上一镜真实尾帧且仅借用状态 | 放在 `[全局资产]`，只约束外观、脏污、道具、空间方位、光线；当前镜仍独立构图 |
| 有上一镜真实尾帧且镜头动作连续 | 引用同一尾帧并描述动作从该帧已有状态继续；在平台支持时使用对应首帧或延长操作 |
| 有明确首帧／首尾帧锚点 | 把实际图像设为对应帧，并写清物理动作路径；首帧不复位重演 |
| 没有可用参考图片 | 先按当前导演画面判断需补哪些关键图，优先生成；用户明确允许不用参考时才退回纯文本方式 |
| 视频编辑 | 精准指定原视频要保留什么、要改变什么；不自主扩展镜头和剧情 |

**引用规则**：现有云盘素材在 `[全局资产]` **只写准确文件名**，不用云盘链接、不附带大段资产外观；同名不同扩展名分别引用。模型平台确实支持 `@文件名` 或 `图1` 时，可在真正上传素材后进行对应绑定，**不预先编造已生效的引用标签**。只有文件名清单，不代表模型已经加载图片。

## 3. 提示词的分镜粒度

- **镜头内物理动作**：现有状态 → 核心动作 → 变化结果。速度、重量、惯性、衣料、尘土只在可见且相关时补充。
- **摄影**：固定、平移、摇摄、推轨、拉焦、FPV、POV等是不同动作；明确主体、相机的相对位置、方向、幅度和结束方式。不要用“镜头快速绕着主体飞行”替换固定中景。
- **表演**：动作中的表情转变胜过情绪形容词；自然说话，在动作里插入看与被看，不为口型强迫角色停止工作面对镜头。
- **空间**：位置、前后景、出入口、光线方向、机械尺寸、角色手里的物品在切镜后保持一致。
- **群像**：本镜一个清晰主行为，其他人在空间里自然工作，避免每个人同时执行独立精密动作。高负荷的多段物理事件如造成模型冲突，应**标注“建议独立生成/拆任务”**，而不是偷偷删掉导演指定行为。
- **对话和声音**：保留台词原字，注明谁说、说话时动作、声线和听者反应；环境底噪、机械声、脚步声、碰撞声随动作同步。默认**没有画外配乐**；若场景存在被人物听到的音乐，写明声源（例如收音机）。

### 模型稳定性：人物特写和仪表/小道具特写独立构图

导演E01实测表明：短镜头里既需要清晰看见人物面部反应，又需要看清仪表上的低能量告警，要求同镜「眼睛→仪表→眼睛」拉焦不能稳定执行。**需要读清两条信息时，拆成两个独立镜头**，分别写景别焦段、明确主清晰目标、镜头起止时码，并用警示音和车内环境音跨镜连接；若同一批的镜头切换仍不稳定，可拆开生成，后期剪辑。此约束不禁止单一目标自然追焦，也不要求把所有正常同框都拆镜。已存在导演确认分镜时只提出建议，未经许可不改镜号。详见 [W式剧本直出规范](script-to-video-batch.md)。

## 4. 默认可复制模板（供已写导演逐镜分镜转译；剧本直出优先W规范）

**W式缺图原位要求：** 剧本直出每批的 `[全局参考]` 如缺少本批必要的关键资产图，必须同批写 `- 待生成资产｜名称` 与下一行 `生图提示词：完整可直接生图的中文段落`；不能以“未核实、见附录、待补图”代替。若多个批次需要同一缺图，分别自足写完整占位，等导演生成并确认后再逐处替换文件名。既有真实云盘图但仅未上传平台，不属于待生成资产。

**剧本直出模式补充（导演明确授权时）：** 本文件下列通用模板保持适用于逐镜转译与局部请求；但当用户从**仅有剧本**要求独立写整集视频提示词时，必须优先执行 [W 导演语言剧本直出六栏目规范](script-to-video-batch.md)。制作附件保留资产与必要母图，**真正可复制的视频批次从 `[导演说明]` 开头**，依次是 `[全局参考] → [连续性状态] → [视觉基调] → [色彩光影] → [分镜脚本]`；每镜必有编号时码、景别/焦段、运镜/视角、画面描述、声音/Foley。**不需要任何历史样例文件作为输入**；W 式先决定摄影机立场、人物表演的可见演化、光线叙事与声音节奏，不将输出写作正式导演分镜。

**场景级前置步骤：** 本场尚无有效视觉母图时，**先交一次**独立的 `[核心电影静帧]`（现成素材文件名 + 缺失资产补图 + 一段独立、具体、可生图的中文母图提示词），详见 [核心电影静帧专项](core-scene-keyframe.md)。母图的任务是统一全场视觉逻辑，不强制每镜沿用同一摄影机位，不要求它是场景首帧。**相同场景的后续批次不重复生成母图**。

> **下面是逐批可复制的视频提示词，第一行依旧是 `[全局资产]`。** 批次名、总时长和导演镜号范围可先放提示词块外供制作管理；**块内资产文件名来自当前镜头可确认的 Drive 目录或索引**，这里只演示栏目写法，不把未知文件名冒充真实文件。

```text
[全局资产]
- 主要角色参考：〈实际云盘文件名，含扩展名〉
- 载具参考：〈实际云盘文件名，含扩展名〉
- 场景材质/布局参考：〈实际云盘文件名，含扩展名〉
- 本场核心电影静帧：〈导演实际生成并上传的母图文件名；未生成时写“待生成后回填”，不得假造〉
- 上一镜尾帧：〈若真实存在，填写实际图片名；否则标注待上一镜制作后提取，或不需要则省略〉
- 待生成资产｜〈缺少的场景／人物／道具／镜头首帧〉：
  生图提示词：请生成一张用于《异星边境》……的……参考图。摄影机位于……，画面前景……中景……远景……，主体呈现……的可信尺度、材质和使用痕迹。光线从……进入，保留……已确认的场景特征与角色状态。用于……镜头的……构图／……造型参考。（缺图项才填写）

[导演说明]
本段时长X秒，核心戏剧意图……。保留原导演的……机位、切点和动作节奏。

[连续性状态]
仅当必要：上一镜……；本镜继承的角色站位、衣服脏污、道具持有、机械损伤、光线方向等……。独立机位不冒充连续同一镜头。

[视觉与光影]
真人写实电影感，按已有资产锁定人物、机械与场景实体外观；拍摄……角度，光源来自……；质感与现场环境……

[分镜脚本]
镜头XX｜0–Xs：从……构图开始，人物……，动作由……发展至……。摄影机……。同期听见……。如有对白，某人在……动作中说：“原文台词”，对方……。

镜头XY｜Xs–Ys：仅在导演已写下一镜时继续，按原机位与时间点切镜，延续必要的空间、人物与声音状态。

[声音]
环境声……；关键动作声……；若有对白，保留原文并自然表演。画外配乐：无。
```

**替换说明**：导演用香蕉／GPT 生成缺图后，把 `- 待生成资产｜… 生图提示词：…` **替换为** `- 场景参考：新上传的实际文件名.jpg`。必须用真实结果文件名，不能在补图前假造。未补齐缺图的文本属于制作准备稿，不宣称资源已引用成功。

**单镜简版**的独立视频提示词依然以 `[全局资产]` 开头；如果本场此前尚无母图，先提供一次场景级 `[核心电影静帧]`。其余栏目可简化为“导演意图→起点→动作与摄影→末帧→现场声”；不强制空栏目。完整场景例子见 [E01 转译](e01-examples.md)。

## 5. 跨镜图1与真实视频

- **同一动作延续**：实际提供了上一镜尾帧时，在 `[全局资产]` 用真实文件名写“上一镜尾帧：……”，视频正文写“本段从该帧可见的动作阶段接着发展”；首帧锁定或延长能力由实际平台设置决定。
- **新机位/剪切反打**：如有实际前镜尾帧，则说明它仅供人物服装、伤口、道具、光线与空间状态参考；本镜按导演新的机位拍摄，有必要时另列缺失“本镜首帧图”的生图提示词，不强迫将旧机位锁为首帧。
- **仅有上一条文字或上一镜尚未生成**：在 `[全局资产]` 写“上一镜尾帧：待上一镜制作后提取”，作为计划依赖；不捏造“图1”或假图。若本镜需要新的准确构图，可单独补“当前镜头首帧”生图提示词。
- **导演已规定固定镜位或切点**：不凭长镜头模型能力改成炫技一镜到底。

## 6. Seedance 2.5 专项验收

在真实生成片段中核查：
1. 主体人物／服装／机械外形是否跟资产相符，FPV/POV/固定镜位是否按要求；
2. 原镜头的动作、事件顺序与对白是否完整，且没有模型擅加桥段；
3. 地形、视线、道具、受损状态是否连续，追逐路线是否可理解；
4. 剪点与节奏是否能在后期实际实现（不要求生成恰好逐帧剪切）；
5. 声画是否对应、对白是否准确、有没有无意加入配乐；
6. 如失败，局部精简动作／减少并发主体／提高参考约束或改为分批，不随便重写原导演镜头。
