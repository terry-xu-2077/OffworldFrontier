# Seedance 2.5｜默认中文视频提示词规范

**适用：没有指定模型，或明确指定 Seedance 2.5。** **原有导演逐镜转译的参考生图模式**：可用角色、场景、道具、载具等参考图，也可引用上一镜实际帧作为连续性依据。**导演逐镜转译时，每场戏的制作包按需先交一次 `[核心电影静帧]`，再进入视频生成批次；**原有逐镜转译模式的独立视频提示词块从 `[全局资产]` 开始；明确剧本直出则从 `[导演说明]` 开始**。两种模式的批次资产栏目统一使用 `<Picture 名称>`、`<Audio 名称>`、`<Video 名称>` 类型化引用；所有缺失图片的 `<Prompt 名称>` 集中在整份 MD 开头唯一的 `[待生成资产]` 区域，每项只定义一次，由 TerryDirector 节点跨文档关联。** 不生成 H3 的 `integrated_multimodal_description` 等字段；本项目的中文标题用于组织制作信息，不宣称 Seedance 官方强制解析这些标题。资产匹配和缺图规则见 [资产准备](asset-preparation.md)。

## 1. 能力与时长

> **项目默认：Seedance生成任务以15秒为标准批次。** 公开平台支持的4–30秒是可用范围，并不表示必须用30秒。先保证镜头动作与节奏完整，再让单批从0到15秒，特殊例外另注原因。



- ByteDance Seed 官方（2026-07-31）发布：**单次最长30秒**，多轮延长、改进多镜头叙事、支持多模态参考与编辑。[官网](https://seed.bytedance.com/zh/seedance2_5)｜[发布说明](https://seed.bytedance.com/zh/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)。
- BytePlus ModelArk 和 Runway 的公开入口文档以**4–30秒**为单次时间范围（某些编辑任务直接继承原视频时长）；“自动时长”与具体可选尺寸、参考文件数量等**取决于实际使用的平台和模式**。官方架构能力不等于所有渠道当前界面都开放。[BytePlus 文档](https://docs.byteplus.com/en/docs/modelark/seedance-2-5)｜[Runway使用指南](https://help.runwayml.com/hc/en-us/articles/53542207042323-Creating-with-Seedance-2-5)。
- **本项目默认生成批次15秒**，先围绕自然镜头剪点编排一镜或多镜，再给出该批次内从0秒开始的连续时码；**不是用30秒上限做默认长度**。15秒容纳不了完整的导演确认长镜、对白或关键动作时，可按实际生成入口与自然剪点标明合理例外，不把一镜到底硬切，也不通过塞入无意义动作凑时长。切点是制作目标而非模型逐帧保证。
- 2秒镜头若单独不足可选下限，和同场下一个已写镜头组成同一任务，分别保留原定镜号／切点；或生成较长素材供剪辑截取。不新编镜头填时长。

## 2. 生成模式与资产绑定

原有导演逐镜转译模式默认以**参考生图**来准备，即使该镜尚未有所有图片，也先完成 `[全局资产]` 类型化引用，并在整份 MD 开头的 `[待生成资产]` 中集中定义必要的 `<Prompt>`。批次内只使用 `<Picture>`、`<Audio>`、`<Video>` 声明；**参考上一帧**与**把上一帧锁为新片段首帧**不是同一个要求。

| 制作情况 | 如何处理 |
|---|---|
| 有角色／载具／场景／道具图片 | 使用 `<Picture 名称>`，描述角色身份、场景布局、外形或材质参考用途 |
| 有音色／环境声样本 | 使用 `<Audio 名称>`，说明它用于音色、语速、语气或声场参考 |
| 有运镜／动作／源视频参考 | 使用 `<Video 名称>`，明确只继承运镜、动作或连续性中的哪一部分 |
| 缺关键图片资产 | 在 MD 开头唯一的 `[待生成资产]` 中定义一次 `<Prompt 名称>`；每个使用该图片的批次只写同名 `<Picture 名称>` |
| 有上一镜真实尾帧且仅借用状态 | 将实际提取的图片声明为 `<Picture 上一镜尾帧>`，只约束外观、脏污、道具、空间方位、光线；当前镜仍独立构图 |
| 有上一镜真实尾帧且镜头动作连续 | 将实际尾帧声明为 `<Picture 上一镜尾帧>`，并描述动作从该帧已有状态继续；在平台支持时使用对应首帧或延长操作 |
| 有明确首帧／首尾帧锚点 | 把实际图像设为对应帧，并写清物理动作路径；首帧不复位重演 |
| 没有可用参考图片 | 先按当前导演画面判断需补哪些关键图，优先生成；用户明确允许不用参考时才退回纯文本方式 |
| 视频编辑 | 精准指定原视频要保留什么、要改变什么；不自主扩展镜头和剧情 |

**引用规则**：`[全局资产]` 只输出类型化命名标签和简短用途描述，不输出文件路径、扩展名或平台数字编号。真实文件名用于幕后核验；标签名称作为整份 MD 文档范围内的语义别名，由本地节点包绑定到实际素材。同一实际资产被多个批次引用时，所有批次必须使用完全相同的媒体类型和别名，供节点跨批次匹配及同步绑定；不同实际资产不得共用别名。缺失图片的 `<Prompt>` 只在文档开头唯一的 `[待生成资产]` 中定义一次；各批次仅声明同名 `<Picture>`。节点先提取文档级 Prompt，再关联各批次 Picture，并从所有视频模型正文中剥离 Prompt。标签不代表素材已经上传或绑定。

### 户外及非密封驾驶位：风作用到人物和衣装

Seedance提示词默认检查空气流动的**可见物理反应**。未密封驾驶位高速行驶时，车速形成持续相对迎面气流，暴露的碎发和未固定衣角/兜帽披覆外沿向背风侧扬起、颤动，转弯、遮挡和减速会改变幅度；户外缓行或静立时，微风只让少量碎发和衣摆间歇轻动并自然回落。服装重量、固定扣和身体姿势要可信，不能让整套工装像旗帜一样抽打。若戴密闭头盔或兜帽完全遮住头发，不得生成穿透装备的飘发，可改表现布料边缘、尘粒、植株和风声。远景重点交代同向的尘尾/植被，不强行表现发丝；近景和中景应给出具体可见的风反馈。**无需因此增加剧情动作、剪镜或超过默认15秒**。

### 飞行FPV / 穿越机跟车：默认赛车式动态一镜到底

导演指定「飞行FPV」「穿越机跟拍」「赛车式FPV」时，默认**单架独立穿越机在一次连续飞行中多角度、多距离、多景别追踪车辆**，不锁死车后同一距离和构图。每个这类镜头应明确**起点→2–4个由飞行路线串起的主要动作阶段→终点**，可使用加速逼近、侧面超越、斜前倒飞、低空掠地、沿弯道外抛回收、避障后重新咬住主体、顺坡抬升拉开等；只选符合本镜时间长度与空间道路的动作。透视与景别变化由**真实相对位移**带来，不用无因的硬切或极速变焦。允许飞行惯性、轻微侧倾、遮挡、找构图的半拍延迟，必须保持主体路线、轴线与真实飞行可达性。

**模型稳定性处理：** 在一个9秒镜头里优先给2–3个清楚的飞行阶段，不堆满全部招式；若一次连续路线难以实现，先删次要回绕，保留最关键的超越与回收，而不是默认退回固定车后跟拍。**一镜到底允许围绕同一主体连续变景别**，但不能用同镜里的焦点游移去替代人物脸与仪表两次必须读清的信息特写。固定观察式FPV、车载POV及导演明确镜位为例外。详见 [W式穿越机FPV规则](script-to-video-batch.md#穿越机赛车式fpv默认一镜到底运动语法)。

## 3. 提示词的分镜粒度

- **镜头内物理动作**：现有状态 → 核心动作 → 变化结果。速度、重量、惯性、衣料、尘土只在可见且相关时补充。
- **摄影**：固定、平移、摇摄、推轨、拉焦、FPV、POV等是不同动作；明确主体、相机的相对位置、方向、幅度和结束方式。不要用“镜头快速绕着主体飞行”替换固定中景。
- **表演**：动作中的表情转变胜过情绪形容词；自然说话，在动作里插入看与被看，不为口型强迫角色停止工作面对镜头。
- **空间**：位置、前后景、出入口、光线方向、机械尺寸、角色手里的物品在切镜后保持一致。
- **群像**：本镜一个清晰主行为，其他人在空间里自然工作，避免每个人同时执行独立精密动作。高负荷的多段物理事件如造成模型冲突，应**标注“建议独立生成/拆任务”**，而不是偷偷删掉导演指定行为。
- **对话和声音**：保留台词原字，注明谁说、说话时动作、声线和听者反应；环境底噪、机械声、脚步声、碰撞声随动作同步。默认**没有画外配乐**；若场景存在被人物听到的音乐，写明声源（例如收音机）。

### 模型稳定性：人物特写和仪表/小道具特写独立构图

导演E01实测表明：短镜头里既需要清晰看见人物面部反应，又需要看清仪表上的低能量告警，要求同镜「眼睛→仪表→眼睛」拉焦不能稳定执行。**需要读清两条信息时，拆成两个独立镜头**，分别写景别焦段、明确主清晰目标、镜头起止时码，并用警示音和车内环境音跨镜连接；若同一批的镜头切换仍不稳定，可拆开生成，后期剪辑。此约束不禁止单一目标自然追焦，也不要求把所有正常同框都拆镜。已存在导演确认分镜时只提出建议，未经许可不改镜号。详见 [W式剧本直出规范](script-to-video-batch.md)。

## 4. 默认可复制模板（供已写导演逐镜分镜转译；剧本直出优先W规范）

**W式缺图规则：** 剧本直出时，缺失图片的完整 `<Prompt 名称>` 统一放在整份 MD 开头唯一的 `[待生成资产]` 区域，每张图片只定义一次。每个实际使用该图片的批次，在 `[全局参考]` 中只写同名 `<Picture 名称>：用途描述`；不能以“未核实、见附录、待补图”代替明确引用。图片生成并导入后，只删除文档开头对应的 `<Prompt>` 定义，所有批次中的 `<Picture>` 保留并绑定。既有真实云盘图但仅未上传平台，不属于待生成资产。

**剧本直出模式补充（导演明确授权时）：** 本文件下列通用模板保持适用于逐镜转译与局部请求；但当用户从**仅有剧本**要求独立写整集视频提示词时，必须优先执行 [W 导演语言剧本直出六栏目规范](script-to-video-batch.md)。制作附件保留资产与必要母图，**真正可复制的视频批次从 `[导演说明]` 开头**，依次是 `[全局参考] → [连续性状态] → [视觉基调] → [色彩光影] → [分镜脚本]`；每镜必有编号时码、景别/焦段、运镜/视角、画面描述、声音/Foley。**不需要任何历史样例文件作为输入**；W 式先决定摄影机立场、人物表演的可见演化、光线叙事与声音节奏，不将输出写作正式导演分镜。

**场景级前置步骤：** 本场尚无有效视觉母图时，**先交一次**独立的 `[核心电影静帧]`（现成素材文件名 + 缺失资产补图 + 一段独立、具体、可生图的中文母图提示词），详见 [核心电影静帧专项](core-scene-keyframe.md)。母图的任务是统一全场视觉逻辑，不强制每镜沿用同一摄影机位，不要求它是场景首帧。**相同场景的后续批次不重复生成母图**。

## 5. 跨镜图1与真实视频

- **同一动作延续**：实际提供了上一镜尾帧时，在 `[全局资产]` 声明 `<Picture 上一镜尾帧>` 并说明它是连续动作首帧；视频正文写“本段从该帧可见的动作阶段接着发展”；首帧锁定或延长能力由实际平台设置决定。
- **新机位/剪切反打**：如有实际前镜尾帧，则说明它仅供人物服装、伤口、道具、光线与空间状态参考；本镜按导演新的机位拍摄，有必要时另列缺失“本镜首帧图”的生图提示词，不强迫将旧机位锁为首帧。
- **仅有上一条文字或上一镜尚未生成**：只在连续性说明中写“上一镜尾帧：待上一镜制作后提取”，不创建 `<Picture>` 引用，也不捏造“图1”或假图。若本镜需要新的准确构图，在文档开头 `[待生成资产]` 中定义一次 `<Prompt 当前镜头首帧>`，并在本批 `[全局资产]` 中写同名 `<Picture 当前镜头首帧>`。
- **导演已规定固定镜位或切点**：不凭长镜头模型能力改成炫技一镜到底。

## 6. Seedance 2.5 专项验收

在真实生成片段中核查：
1. 主体人物／服装／机械外形是否跟资产相符，FPV/POV/固定镜位是否按要求；
2. 原镜头的动作、事件顺序与对白是否完整，且没有模型擅加桥段；
3. 地形、视线、道具、受损状态是否连续，追逐路线是否可理解；
4. 剪点与节奏是否能在后期实际实现（不要求生成恰好逐帧剪切）；
5. 声画是否对应、对白是否准确、有没有无意加入配乐；
6. 如失败，局部精简动作／减少并发主体／提高参考约束或改为分批，不随便重写原导演镜头。
