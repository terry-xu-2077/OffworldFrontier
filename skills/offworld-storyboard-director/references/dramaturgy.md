# 编剧参考：人物、场景、对白与剧集

主要参考：screenwriting-skills 的 sw-workflow、sw-premise-theme、sw-character-conflict、sw-scene-craft、sw-dialogue、sw-story-structure、sw-chinese-series-practice 等。以下为针对《异星边境》的原创整合方法；深入工作时可按用户意图访问上游的完整 SKILL.md。

## 创作起点不是概念

先找人能共情的现实处境、不可回避的选择和改变关系的行动。科幻设定的作用是加大人物选择的代价、强化不平等或改变人如何谋生，而非提供一串奇观。每条社会议题应落实为：某个具体角色要做什么、谁受影响、他怎样付出代价。避免角色互相宣读作者的观点。

## 角色动力

- 外在目标：本场具体想取得的物品、承诺、信息、自由或机会。
- 内在需求：人物坚持的错误信念、恐惧或尚未具备的能力。
- 可选策略：请求、隐瞒、交换、试探、示弱、欺骗、冒险，不同角色使用不同的动作方式。
- 对抗力量：可以是人、制度、环境、资源短缺或自身习性，并非每场必须有恶人。
- 人物弧光：用行动与选择逐步显现，不应一句感悟后突然变脸。

## 第一关：这一场值不值得拍

**先判断观众体验，再判断剧情功能和技术正确性。** 问：观众看这段，会体验到什么——悬念、惊险、好奇、奇观、情感、笑声、日常趣味、角色变化，还是一件事终于成功的满足？**若删掉它，观众会失去什么？** 没有独立观看价值的技术步骤，不因「逻辑上必须发生」就值得逐段拍出来。

**诊断结果必须可以取舍：** 保留（体验成立）、压缩（交代一次关键操作与结果足够）、合并（把必要信息融入更好看的戏）、删除（仅重复或机械衔接）、显微聚焦（已积累强烈期待的关键过程）。**技术流程默认是幕后因果约束，不是主要观看内容；例外是观众已对结果有强烈期待，过程中的变化会拉扯或兑现期待——不论是危险、选择、试错、惊奇还是终于成功的满足。** 例如悬念集中于「终于能不能稳定供电」时，连续试验的阻碍和跨过关键门槛值得细拍；但井下救援的重复位置汇报、门锁诊断和回路说明，通常应让位给救人的动作、风险与关系。

不要把标准误解为「每场必须推进主线」。有趣的闲谈、生态观察和安静日常也可以凭**实际的观看体验**成立；物理规则仍需准确，但不必全部演给观众看。

**跨集诊断同时检查：** 核心角色在危机前有没有被观众认识、戏中是否主动发挥能力；主角的外在行动目标与内在关系有没有推进；科研和劳动成果是否改变居民真实生活；悬念是否先让观众认出「异常是什么」再留下未解答案。顺序调整须重新校验材料与人物动机何时成立。以上是诊断角度，**不是每集必须完成的配额**。

## 场景工作单（动笔前简填）

1. 进入场景前：人物处于什么处境，已经知道什么？
2. 即时目标：谁想让谁做什么？
3. 抵抗/限制：为什么不容易？
4. 行动节拍：提出→碰壁→改变策略→意外反应。
5. 价值变化：开场与收场的信任、安全、权力、希望、信息有何变化？
6. 可拍动作：争执是否具体作用于正在做的劳动、道具与空间？
7. 离场余味：观众带着什么情感或疑问进入下一场？

不必每场都有强转折，但应有可辨认的叙事、情感或观察价值。允许铺垫、留白、反高潮、群像结构，不以单一经典写作模型机械否决。

## 对白

- 每句台词都可拆成「表面字句 / 想让对方做什么 / 不愿明说什么」。
- **逐句内审五个维度（不是五项必达指标）：人物 → 塑造 → 世界 → 问法 → 回应。** 人物：以其性格、经历、当前关系与处境，真会说这句话吗？塑造：说法、语气、保留、玩笑或沉默能让观众更认识他吗？世界：是否有自然机会带出职业、生活习惯、过往或价值观（**没有也无妨，禁止每句硬塞世界观**）？问法：这句一定要问吗，还是编剧为了得到设定答案才让角色开口？回应：对方听到后会接住、回避、误解、尴尬、被打动，或以行动／沉默改变这场交流吗？**整轮交谈应该产生人物间的反应链，而非作者自问自答。**
- 情绪来源是行动中受阻而非台词标签。给角色不同句长、习惯语汇、打断方式与回避方法。
- 把关键情报揉进协商、怀疑、争取和误解中；减少专门给观众解释设定的对白。
- 可用「遮去角色名测试」检查角色口吻是否分明；不能靠喊口头禅维持辨识度。
- 对 AI 演员测试，若用户要求约五秒对白，优先开口即说，控制语句长度与表演空间；不把这条试镜规则强加给所有完整剧本。

## 长线与分集

**一集可以承担剧情功能，但不能只剩功能。** 先问观众为什么要看、看完会记住什么，再问它为后续贡献了什么。检验方式：**暂时拿掉这一集输送的道具、线索、物资或伏笔，仍有值得观看的奇观、人物选择、生活趣味、情绪或冲突吗？** 若没有，就从已有场景里重找观看价值或考虑合并，**不要硬加事故、虫潮、反转与煽情**来应付测试。分集主问题、态度变化与关系再定义，比固定三幕配额重要；旧电影版总长与篇章约束不复活。

如果当前任务只是某一场戏，不要求用户重新跑完整策划流程。只有长期写作需要维护精简的创作决策日志，并由用户要求时写回正式设定。
