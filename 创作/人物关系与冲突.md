# 人物关系与冲突（创作提案）

> 这是用于试写的关系与戏剧压力表，**不是定稿事件**。事实以人物专题为准。

| 人物 | 当下愿望 | 需要测试的内在矛盾 |
|---|---|---|
| 特瑞 | 用自己的本事取得去处和认可 | 越怕被丢下，越逞强、接下做不到的事 |
| 莺 | 救人并延续研究 | 保护眼前生命与保护长期研究成果可能冲突 |
| 徐世嵘 | 避免基地重复旧灾难 | 藏起信息能保护人，也可能让人不再信任他 |
| 维克托 | 让旧机器继续保护人 | 技术自尊碰上材料、电力和不可修复的现实 |
| 马克 | 守住库存，让所有人活到下次补给 | 对集体负责时会不得不拒绝眼前需要帮助的人 |
| 杰西卡 | 获得自由流动权，建立渠道 | 一心想走，却亲手创造了让人愿意留下的地方 |
| 凯恩 | 把安保本领用来保护人 | 熟悉的封锁规则仍可能伤害无权者 |
| 小七 | 有限播报与陪伴 | 能给出回应，却无法替任何人行动或做决定 |

## 关系重点

- **特瑞 / 维克托**：交易式教学与共同修车；承认、代价、冲动和可靠性。
- **特瑞 / 徐世嵘**：身体直觉与程序裁决；隐瞒与冒进都可能伤人。
- **特瑞 / 莺**：先承认彼此能力，再有情感依赖；莺也有独立的欲望。
- **马克 / 杰西卡**：守底线与争取机会，不固定成双人斗嘴组合。
- **徐世嵘 / 凯恩**：曾服务同一套旧秩序，对责任与信任有不同旧伤。
- **特瑞 / 小七**：怕无人回应的人与一台不能移动、偶尔接错话的机器。

## 生活戏方向

让关系落在一顿饭、一块滤芯、一台难修的车、被占用的床位、一句迟来的道歉上，而不要求每场都推进大阴谋。**可理解的现实困境是检验人物性格的压力，不是必须得到道德结论的考题。**
