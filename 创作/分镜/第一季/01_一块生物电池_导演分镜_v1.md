## 一、全片摄影设计

### 三个情绪阶段

| 时间 | 段落 | 摄影与情感方向 |
| --- | --- | --- |
| 0:00—0:58 | 发现与逃生 | 狭窄机位 → 速度与危险 → 跃过地缝 |
| 0:58—1:43 | 孤独的荒原 | 亲近人物 → 空旷环境 → 发现希望 |
| 1:43—2:45 | 陌生的家园 | 工业空间 → 人声回应 → 仍未打开的门 |

第十集摄影的核心是人在共同空间中作出选择，第一集则是**少年独自在陌生荒星求生**。观众应记住特瑞很能干、很爱说话，但无人回应时其实会不安。

### 空间、摄影轴线与美术边界

- **装卸站位于高处，采集队从下方岩缝经过，866 停在通往荒原的下坡一侧。** 逃生路线从装卸站沿碎岩坡延伸至断裂地缝；护卫驱赶干扰采集路线的载具，而非不受限制地追猎特瑞。
- 追逐段建议以 **866 向画面右侧逃离**为主要银幕运动方向。跨过地缝后先以建立镜明确两岸关系，才允许自然调整摄影轴线。
- 荒星主色：冷灰紫矿岩、粉紫薄雾、克制的自然日照。普通地表空气可呼吸，特瑞默认露出面部。
- 866 是具有轮胎、机械腿、液压机构与折叠翼的旧式改装蚂蚱型载具，可短距跃障，**不是悬浮飞船、也不能无代价飞行**。
- 生物电池里的光是极细淡蓝活体微光；琥珀状态点亮只代表局部活性反应，**不代表已经充电或能输出车辆所需电力**。
- 全集不默认加入背景音乐。以风、机械、工具、脚步、甲壳、扬声器与安静本身构成声音层次。

## 二、逐镜头导演分镜

### 第一段｜发现与逃生（0:00—0:58）

#### 镜 01｜不该还活着的电池｜0:00—0:03｜3 秒
- **戏剧功能：** 开场 3 秒展示第一重悬念：报废设备中竟有一块内部仍然活动的电池。
- **画面与调度：** 报废检修舱里，一只戴半指手套的手撬开锈死的锁扣，拽出厚合金电池盒。熄灭的琥珀电量窗旁，一缕淡蓝光丝在观察孔里蜷动，残损铭牌露出 **BIO-CELL**。
- **摄影：** 贴近检修舱内部的低机位特写。电池抽出后现场光落到观察孔上；先让观众看见异常，再听特瑞的反应。
- **对白：** 特瑞（低声）：“生物电池？真有这东西啊……”
- **声音：** 撬杆摩擦、锁扣崩开、金属盒在导轨上刮过的干涩声。
- **连续性：** 此时尚未注液，电池琥珀电量窗原本熄灭，微光来自观察孔内的活体结构。

#### 镜 02｜试着激活｜0:03—0:06｜3 秒
- **功能：** 特瑞展现动手天性，也让他因主动尝试而更珍视这块发现。
- **画面：** 取出旧生物密封胶用的营养活化液，向密封注液口挤入一滴。光丝短暂收拢后舒展，一颗琥珀指示点亮起。
- **摄影：** 电池和手处于同一固定近景；不把细微反应拍成爆炸或闪电般的能量释放。
- **对白：** 特瑞：“哟，还活着呢！”
- **声音：** 液滴与设备触点的细小声音。
- **连续性：** 仅恢复局部生物活动，不能据此视为供电成功。

#### 镜 03｜危险就在脚下｜0:06—0:08｜2 秒
- **功能：** 第二重悬念突然出现，但因果要具体。
- **画面：** 特瑞腰间金属扣撞响设备支架。斜下方岩缝中背着淡蓝黏质囊的采集个体伏低，两只厚甲护卫挡到前方，前肢敲击岩面。
- **摄影：** 从设备结构边缘向下俯看。护卫正在保护采集队，不能摆出专对镜头恐吓的怪兽姿态。
- **声音：** 清脆金属撞击转为低沉连续的岩面震动。
- **连续性：** 护卫因金属撞击、震动与采集路线受侵扰而戒备，**不因生物电池的微光被召唤**。落地后普通能量匣输出不稳但尚未彻底耗尽，866 仍可缓慢驶往聚落外闸。

#### 镜 04｜赶紧上车｜0:08—0:10｜2 秒
- **功能：** 让威胁立刻推着人物行动。
- **画面：** 从 866 驾驶舱一侧望向坡上：特瑞迅速把电池放入软垫工具袋，冲下坡坐进驾驶位；驾驶台普通能量匣的红色低电量灯在前景闪烁。
- **摄影：** 固定机位，让人物快速闯入画面；借前后景展示驾驶舱和坡上装卸站的关系。
- **声音：** 快速脚步、舱体碰撞、启动电机吃力的转动。
- **连续性：** 生物电池进入特瑞工具袋；车靠原有普通能量匣供电。

#### 镜 05｜866 冲出废站｜0:10—0:16｜6 秒
- **功能：** 交代载具独特性与机械隐患。
- **画面：** 866 从装卸站侧面冲入旧维护路。前轮碾过碎石，后腿液压机构压缩回弹，车身受力震颤。
- **摄影：** 路边低位广角中全景，镜头近乎固定，866 横穿画面；让观众看清轮胎、机械腿与液压结构。
- **对白：** 特瑞：“别挑这时候掉链子啊！我说你呢，866！”
- **声音：** 电机吃力的高频声、轮胎磨砾、后腿金属撞击。
- **连续性：** 866 朝画面右侧逃离；后腿早有不稳定迹象。

#### 镜 06｜护卫逼近｜0:16—0:23｜7 秒
- **功能：** 让观众理解威胁的生态动机。
- **画面：** 从稍高的路侧看，866 在前方逃离，厚甲护卫从岩缝采集队一侧逼近，把它向维护路外侧驱赶；背囊的小型采集个体开始沿岩缝回撤。
- **摄影：** 较宽空间构图，尽量同时见到 **载具、护卫、采集队**，保持位置关系。
- **声音：** 866 机械撞击和护卫甲壳、前肢敲地的不同节奏。
- **连续性：** 护卫始终以采集路线为防御中心，不进行无限远追击。

#### 镜 07｜他看懂了｜0:23—0:31｜8 秒
- **功能：** 展示特瑞的荒星经验与观察能力，而不是单纯会开快车。
- **画面：** 车内斜侧中近景。特瑞回头，看见护卫一直没有离开采集个体的回撤线路。他迅速扭回视线，把转向杆朝外侧扳，绕开返巢裂口。
- **摄影：** 人物近景接一处明确视线反打，再回到动作；不用台词直说“它们是在保护同伴”。
- **声音：** 急促呼吸、转向连杆卡顿、碎石击打舱壳。
- **剪辑：** 视线所指的护卫位置必须和镜 06 延续一致。

#### 镜 08｜前面没路了｜0:31—0:40｜9 秒
- **功能：** 将外部威胁转化为可计算的跃障困境。
- **画面：** 866 前方是一道横断旧维护路的地缝。载具逼近，最后一格红色电量灯忽明忽暗，后腿紧固扣弹飞。
- **摄影：** 低位前侧三分之四全景同时建立裂口宽度、对岸落点和车体位置，再插一处非常短的故障细节。
- **声音：** 金属扣崩开、警示蜂鸣、液压压力声。
- **连续性：** 地缝宽度必须符合 866 的有限短距机械跃障能力。跳跃方向与下一镜保持同轴。

#### 镜 09｜最后一次跳跃｜0:40—0:50｜10 秒
- **功能：** 第一集最重要的身体性冒险高潮。
- **画面：** 特瑞看准对岸岩面，压下跳跃杆。866 后腿压缩蓄力、从裂口前缘跃起、落向对岸，落地时车身重重下沉，液压机构撞到极限。仪表红灯短暂熄灭后闪回并开始乱闪；用一个极短插入看见检修盖缝冒白烟、端子边缘焦黑，再回到车身余震。
- **摄影：** 在裂缝侧面一处稳定地点尽量完整呈现“压缩—起跳—落地”。必要时补特瑞握杆的短插入，但主要动作不能被切碎到难以辨认。
- **对白：** 特瑞（对车，低声）：“就这一下，成不成？”
- **声音：** 蓄压、瞬间弹射、短暂风声、重砸落地；随后是继电器断续跳响与轻微电气噼啪声，落地声之后留极短听觉空白。
- **连续性：** 落地冲击加剧后腿损坏，普通能量匣端子焦黑、输出失稳；红灯短暂熄灭后闪回并不规则闪烁，检修盖缝冒白烟。车辆仍靠剩余电量间歇输出，得以缓慢驶向聚落；无飞行能力，无无损超级跳跃。

#### 镜 10｜它们没有追过来｜0:50—0:58｜8 秒
- **功能：** 完成追逐因果，建立荒星的生态秩序。
- **画面：** 866 在对岸碎石上颠簸着滑出一段，仪表红灯仍不规则闪烁，车辆靠剩余电量勉强维持运转。特瑞回头；隔着地缝，护卫停住并返回背囊采集队。
- **摄影：** 对岸中远景，明确两岸距离；同时见到停止追击的护卫与保护对象。
- **声音：** 866 电机降成疲弱低鸣，护卫敲地声逐渐远离；不加胜利音乐。
- **叙事结果：** 观众意识到这些生物并非为攻击人类而生。

### 第二段｜裂缝另一侧，第一次真正安静下来（0:58—1:43）

#### 镜 11｜先确认那块电池｜0:58—1:07｜9 秒
- **功能：** 让惊险之后的第一次关切落在意外发现上，显出特瑞的好奇心。
- **画面：** 866 停在较平缓的碎岩地上。特瑞靠着驾驶位喘气，没有先检查坏腿，而是摸向胸前软垫袋。微弱光丝仍在观察孔中活动，他稍稍松口气。
- **摄影：** 驾驶舱外侧稳定中近景，和前段运动形成反差。
- **声音：** 电机逐渐降速、人物呼吸、金属冷却。
- **连续性：** 稀有样机始终在随身工具袋中。

#### 镜 12｜活着，却不能救车｜1:07—1:17｜10 秒
- **功能：** 建立令人期待但无法立即解决的科技悬念。
- **画面：** 特瑞掀开 866 普通电池舱，对比粗大的双排插头与生物电池细密封闭式接口，略一比对便发现不兼容。他没有硬塞。观察孔还有活体微光，输出标记没有反应。
- **摄影：** 从人物肩侧近景同时看到双手和两种接口，以实际尺寸差异说明问题。
- **对白：** 特瑞：“活是活过来了……你倒是给我点电啊。”
- **声音：** 电池盖铰链、接口轻碰、轻轻的无奈鼻息。
- **连续性：** 生物电池没有被接上 866；它和标准能量匣完全不是同一种东西。

#### 镜 13｜把车临时修到能走｜1:17—1:29｜12 秒
- **功能：** 让人物凭技能解决现实小问题，但不抹掉代价。
- **画面：** 把生物电池用布包好收回软袋。特瑞检查后腿：护板歪斜、铰链松动。他卸下一块旧扣件，临时扎紧松脱位置。866 勉强再次起步，每挪几步都伴随金属异响。
- **摄影：** 车体局部中景让手和损坏结构同框；切稍宽固定机位展示临时修复后的运动状态。
- **声音：** 工具与扣件实音、重新运转却不均匀的机械节奏。
- **连续性：** 是临时紧固而非彻底修好，普通能量匣还剩少量电；**真正完全停机发生在聚落外闸**。

#### 镜 14｜有灯，就有人吧｜1:29—1:43｜14 秒
- **功能：** 第一集的情绪中心：从惊险转入孤独，再让远方出现微弱希望。
- **画面：** 特瑞习惯性抬头，像想和谁说句话，四周却无人回应。他张了张嘴，又沉默。前景是一块半埋的旧路牌，残存“风塔维护线”和箭头；远处粉紫薄雾里出现巨大风塔轮廓及塔底零星暖光。
- **摄影：** 先用远景把特瑞与坏车压成荒原中的小小存在，留出几秒真实的空旷。再从路牌附近建立路标与远方风塔的空间指向。风塔第一眼应像**不确定的希望**，不是宏大英雄建筑。
- **对白：** 特瑞：“有灯就有人吧？最好还有人会修车。”
- **声音：** 以风声为主，远处还没有人声；他几乎是在说给自己听。
- **剪辑：** 可省略沿旧维护线的一段缓慢行驶，形成午后到傍晚的时间推进。

### 第三段｜风塔下的陌生人（1:43—2:45）

#### 镜 15｜一处还活着的聚落｜1:43—1:56｜13 秒
- **功能：** 首次展示人类仍在这里生活，随后让最后一格电耗尽。
- **画面：** 傍晚 866 沿维护路缓慢进入风塔下方。巨型叶轮仍有一片慢慢转动；近处有晾晒滤布、修补围栏、临时接线、维修棚的暖灯。866 停在外闸前，普通电量灯最后一格熄灭。特瑞两次扳启动杆，只有一声空响。
- **摄影：** 固定全景同时容纳大型工业遗迹与小小生活痕迹，再切驾驶舱中景见人物和仪表。
- **声音：** 风塔轴承、滤布拍击、最后的电机空转。
- **连续性：** 原有普通能量匣至此外闸才彻底耗尽。

#### 镜 16｜有人在门里面｜1:56—2:07｜11 秒
- **功能：** 第一次出现真正回应特瑞的人声。
- **画面：** 特瑞跳下车，看一眼坏腿，抬头看厚重的外闸。门一侧在画面里占据很大比例，他在门外显得很小。旧扬声器突然传来声音，他立刻回头。
- **摄影：** 门外中远景，不急着揭示门里的人。声音比露脸更重要。
- **对白：** 门内声音：“小伙子，别再折腾了。你这车再跳一下，腿都得飞出去。”
- **声音：** 老扬声器带有限的频响和轻微噪声，但对白必须清晰；荒原风声始终在场。

#### 镜 17｜我可以拿东西换｜2:07—2:19｜12 秒
- **功能：** 通过动作体现特瑞的外向、求生经验，以及想得到回应的急切。
- **画面：** 特瑞立即靠近观察窗下方，解开腰包，把工业扣件和旧陶瓷接头倒在掌心，举向门边摄像头，动作急促。
- **摄影：** 从门旁观察设备的一侧看特瑞中近景。他面对门内陌生人，不对观众说话。
- **对白：** 特瑞：“那你们这儿有能用的电池吗？能换！我带了零件，还能帮你们干活呢。”
- **声音：** 零件相碰、衣袋翻动、门内很轻的笑声。
- **连续性：** 他展示的是普通搜来的工业零件，**没有向门内交出生物电池**。

#### 镜 18｜先换一块普通电池吧｜2:19—2:31｜12 秒
- **功能：** 让第一集落回人物最具体的目标。
- **画面：** 扬声器再次响起，特瑞举着旧零件，听到问题后低头看身后停机的 866，表情收敛，把零件慢慢攥回手心。
- **摄影：** 侧面中景让特瑞、厚门、坏掉的 866 处于同一空间；不必反复切车的特写。
- **对白：** 门内声音：“你究竟想换什么？” 特瑞：“先换一块普通电池吧。至少让我那车还能走。”
- **声音：** 扬声器底噪、短暂安静。
- **连续性：** 他明确要的是标准普通电池，不是为罕见生物电池寻找通用充电器。

#### 镜 19｜门还没有打开｜2:31—2:45｜14 秒
- **功能：** 微弱希望与悬念并存；和开场生物电池形成首尾视觉呼应。
- **画面：** 门内维修灯亮起，灯光照在外闸旁。特瑞抬头看那点暖光，收拾零件，下意识按住胸前软袋。最后回到袋口内的电池观察孔：大半被布挡着，只有极细淡蓝光丝缓缓蜷动。外闸仍然关着。
- **摄影：** 外闸与人物的较宽构图，暖光从阴影中出现；随后切极近的观察孔特写，与镜 01 相呼应。
- **声音：** 维修灯继电器吸合、零件轻碰、稀薄风声。
- **结束：** 微光蜷动后直接切黑。
- **下一集牵引：** 特瑞只想换块标准普通电池，不知道聚落里那块备用电池还有更紧迫的用途。

## 三、三个最重要的电影化判断

### 1. 不是普通的怪兽追车

镜 06、07、10 必须构成清楚因果：**护卫驱赶 → 特瑞看懂并绕行 → 护卫回到采集队**。环境中的生命具有自己的生态秩序，不能拍成专为主角提供动作场面的怪物。

### 2. 最空旷的画面应该留给特瑞

镜 14 是本集最值得认真设计的一幅构图：一个刚刚脱险的少年，独自坐在快没电的老机器里，习惯性想讲话却无人回应。特瑞在第十集愿意留下来，与别人共同承担责任的情感基础应从这里开始积累。

### 3. 第一集不急着让所有主角登场

门内只有一个尚未露面的人声。特瑞此时不用立刻认识全部居民；只需确认终于有人听到了他的话。**一个声音的回应**比大量人物介绍更有效。

## 四、制作前的硬性检查

| 检查项 | 必须保持 |
| --- | --- |
| **电池** | 生物电池仅恢复微弱活体活动；866 全程靠原有普通能量匣供电，落地后端子焦黑、输出不稳，外闸前才彻底停机 |
| **866** | 短距机械跃障，落地后腿损坏；没有垂直起飞、长期飞行或无损连续跳跃 |
| **虫群** | 采集队位于岩缝通道，护卫短追、驱赶并回撤；不是被生物电池召唤 |
| **特瑞** | 聪明、嘴硬、善动手，也怕无人回应；不是全程惊叫或纯粹惊慌 |
| **环境** | 冷灰紫荒原与粉紫薄雾；风塔既有旧工业尺度，也有居民生活痕迹 |
| **终场** | 866 到外闸完全停机；样机仍在特瑞身上；外闸未正式放行 |

### 仍需制作验证的风险

- **前 10 秒：** 撬取、注液、活体反应、惊动采集队、奔向车内的信息较密；需要验证动作是否能读懂，必要时允许分镜节奏微调。
- **镜 09：** 起跳—落地动作必须有物理重量、持续时长和真实障碍尺度，不能以瞬间跳切掩盖动力逻辑。
- **镜 14：** 要留出真正的无人回应和空镜时间，这是本集人物建立的核心，不能被压缩成普通找路镜头。
- **镜 16—18：** 门内对话须朗读测试；声音首次出现的位置和两人问答应有自然呼吸。
- **时间码：** 19 个主镜头单元合计为 **2:45** 的预排时长，**不代表演员、视频生成或剪辑已验收**。每镜内部独立插入画面如需另行计时，须调整，不得悄悄超过总时长。
- **参考资产：** 生成静帧前需查验实际角色、866、风塔及地表采集队的素材文件；不得仅凭失效资产路径称已核对形象。
