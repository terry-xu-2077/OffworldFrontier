## 一、这季真正讲什么

**特瑞原本只想修好866离开；他先得到进门的许可，再凭行动获得信任，后来发现这里的人愿意给他一张桌子、一份工作、一张床和一个吵吵闹闹的伙伴。等866真的能走，他选择继续生活在这里。**

科幻奇观让观众想认识荒星，生活细节让人想认识居民。技术严格符合来源、能源与物理限制，但镜头前不让人靠理解系统流程才看懂情绪。角色允许开玩笑、出错、沉默，不靠每集一次事故推动关系。

季末并非旧公司阴谋完结：救命的药实实在在到手，有人因此付出了真正能离开的机会；世嵘自愿公开责任；特瑞提交自己的公共身份申请，但不能因为被系统登记才算成为这里的人。最后一个镜头从基地的灯火升上天，旧公司的轨道探测器缓慢转向这颗星——地上的灯很小，但还没灭；天上的系统已经看见了，为第二季留口。

## 三、主要人物的生活与选择

- **特瑞：** 从孤独驾驶者到临时入门的外人，再到被邀同桌、得到床位、小七和修车伙伴。E09主动承受失联后的安静，E11开场拥有离开能力，E12不是因机器坏、被拒离境或突发事故而被迫留下。他可以继续喜欢冒险，留下是主动选择而不是永不离开。
- **维克托：** 先嫌弃破车，后来通过零件、劳动、借工具、共同维修建立默契。E11开场把真的能上路的866交回特瑞手里；E12再把熟悉的工具放回他的位置。
- **徐世嵘：** E03把通讯麦交给特瑞，但由自己承担救援命令；E04先借小七处理真实事故记录，再因信任赠送；E11以全名签收，E12主动走公共线路提交旧案，不靠旧公司终端自动泄密。
- **莺：** E06的旧土豆样本与露台夜聊只显露若有若无的互相在意，不推动确立恋爱；她更首先是有独立热情的生态研究者。E02、E06与E12有独立的好奇与研究瞬间；E08在两位病人互相推让时由她按病情做决定，并承担菌料报废的代价。
- **马克：** 不止读库存表，认真估价、为人记饭、关心玛塔姨，同时守住资源账；E05的生活喜剧与E08递水不是「立刻原谅损失」；E08迟迟不松口，是因为答应过玛塔姨。
- **凯恩：** E02审批外来者，E07迟疑后亲手转开外闸救人。
- **杰西卡：** 她是真的想离开，也拥有一张真实的船票；E10为补给冒险，E11老船长当面核实后忍痛把它签掉。她没有因此被道德教育成永远不想走。
- **小七：** 残机仅头部，E04因真实任务转交特瑞。E09主动关语音是特瑞的选择，不是机器替他完成成长；平日仍以吐槽、播报与有限接口功能陪伴。

- **孩子：** 本季只有一个孩子——矿工乙的孩子，十岁左右，见第05集，也可出现在第06集楼下的投币街机旁；其他日常镜头与情节不安排孩子。

## 五、世界规则与连续性边界

- 特瑞感知的是岩体、地层、虫群的**自然低频**；不能隔着钢板读出门锁授权或设备维修报告。
- 虫群有生态动机：E01 护卫赶走侵入采集路线的震动载具，越过地缝后回撤；浅层棘岩爬子会受热管、湿痕、扰动等生态条件吸引，但本季不安排这场骚扰。不把虫群写成受曜晶核心召唤的追兵。
- **普通工业电池 ≠ 生物电池 ≠ 曜晶核心。** 普通能量匣为 866、矿车和矿业设施提供标准能源；极罕见的生物电池含密封微型活体，基地大多数居民只是听说过，未见过、未用过。E01 的轻敲只触发微弱生命反应，不代表能直接充电或供电；生物电池与普通能量匣接口不兼容。这一技术也不等于曜晶核心。
- **曜晶矿源 ≠ 曜晶核心装置。** 稳定曜晶体柔和自发光，可作样本与临时标记；不直接释放可用电，也不会自行制造大规模重力异常。
- E07 的**进风粗滤网**、E08 的**医疗精滤芯**、温室的**精密防尘预滤组件**是三类不同物件；温室组件仅作为旧医疗滤芯的短时前级预滤，不能替代医疗精滤功能。E11 交易来的两只新医疗滤芯不能自动抹去 E08 已损失的温室菌料。
- 圆子是实体代币，E05 两枚硬币在“被卡住→取出归还→再次投入→人工确认已收”之间流转，屏幕没有让硬币表面自动浮出文字。
- 徐世嵘靠旧权限卡签字满足**本次货运签收担保**，不必先交全体住户名单就能领药；旧公司随后额外索要的资料仍有追索风险。他经杰西卡通信台的公共中继线路（不经过旧公司货运系统）提交旧案证据，特瑞本人经同一线路递交公共身份申请，均不代表已获得正式身份。公司的设备清查与公共部门的身份审查是不同程序。
- 小七无行动能力。玛塔姨是旧闸控人员，不是深井采矿工。旧核心和与重力异常有关的生命体可留待后续故事，不必为“季终奇观”强行启动。

### 运矿运输统一规则

**主井只有一台大型磁悬浮电梯。** 日常矿车使用可充电、可更换的标准能量匣驱动车轴旁的电机，沿横巷矿轨低速自行行驶。矿工用有线控制柄操纵车辆；完整轨道可按标记点缓慢自动通行，损坏轨道与岔口需要人手动确认。到了井口，接轨对齐后矿车靠自身动力驶入电梯，拉下驻车制动、扣牢车轮；矿工站在安全区同舱升井，到地表后再把矿车开上地磅。采矿机和维修设备也能使用同一电梯，没有单独运矿货梯。牵引耗电且电机会保护停机；遇到断轨，靠车载小型电动绞盘或检修牵引缆回收矿物，不能凭空越过断轨，也不让矿工长距离推满载重车。E03 是矿车遇断轨停机后翻进支巷；E09 特瑞带充过电的空矿车下去，在安全位置停稳，用绞盘只拖回一袋矿石。

### 抽象词与含糊简称的处理

| 容易造成误解的说法 | 具体所指 / 剧本应怎样表达 |
|---|---|
| “重量”“交易重量”“补重量” | 为了换药、滤芯还缺的**普通矿石**；可写“矿车里那三袋矿石”“再挖一车矿” |
| “交易矿”“补矿” | 准备拿去跟游商交换物资的矿石；人物谈实物时直接说“矿石”“那几袋矿” |
| “交易窗口”“换货机会” | **下一艘游商船抵达的时间**，错过就得等下一船 |
| “本地账”“工分出不了账” | 马克的手写劳动记录、配给簿；正式系统不承认特瑞的身份，无法自动发配给条 |
| “留痕”“旧权限留痕” | 徐世嵘刷旧权限卡后，终端记录了他的卡号和操作时间 |
| “终端唤醒”“旧系统醒了” | 原本停用的旧公司计费盒重新亮灯、尝试联网或锁住出餐机构；动作描写先给具体变化 |
| “资产核验”“待核验” | 旧公司正在**重新核对主井设备归属与人员名单**；屏幕字段可保留正式说法，人物说清后果 |
| “回传”“报回外环” | 旧设备通过数据线把编号、记录或位置发给旧公司的系统 |
| “货运预留”“船位担保” | 游商暂时答应留药和船上座位，尚未真正交货或取得登船资格 |
| “责任主体”“接收资格” | 需要一位旧系统承认身份、愿意签字承担责任的人，药箱才会放行 |
| “接驳” | 矿井里指**横巷轨道接上电梯舱短轨**；货运场景则指**飞船停靠和货物交付平台**，不能混淆 |

这些用语不是全剧禁词：专业人员在工作时可以使用简称，系统界面也可以保留正式术语；关键是同一场戏里观众应知道它具体指的是什么、发生了什么。人物有意隐瞒、卖关子时的含糊表达，仍可保留。

### 剧本物件与画面可执行性（本季执行原则）

- **先画得出来，再写术语。** 第一次出现陌生道具，应以一两个可见特征交代它的外形和位置，说明是谁碰了哪个部件、发生了什么变化；以后可沿用简称。正常易懂的物件不必重复解释。
- **状态信息使用琥珀色点阵 LED。** 主井平台、外闸和货物交收台的旧设备状态屏，统一为厚金属框内的低分辨率琥珀色点阵 LED 屏；短字、数字逐行点亮，允许灯点缺损。**不使用机场或火车站式机械翻牌装置。** 井深、波形、档案等细项留给绿色磷光诊断屏。
- **控制机构与信息屏分开。** 开门、锁止、供电、收货和紧急停止由手轮、实体按钮、机械锁扣或电气插头触发；屏幕只反馈信息，不能用“屏幕唤醒”“权限回写”等抽象句替代可见的操作与结果。
- **一次只传达关键状态。** 观众需要看懂的是“药箱没放行”“旧公司在重新查人”，不是记住全部数据库字段。正式术语可以存在于设备细项和设定文档，角色日常台词尽量用生活语言解释后果。
- **道具流向与空间必须连续。** 包括 E01 生物电池和 866 原有普通能量匣不可混用、E01 末次跳跃落地冲击（定稿只呈现红色报警与后腿外撇）、E03 拆检才发现原匣端子发黑并隔离待检、E04—E10 后腿排期维修（不单独成场）、E11 开场另用翻修慢充普通电匣重新上路、E03 矿车为何停机侧翻、E07 双闸传递仓怎样用、E08 两类滤芯是否互换、E09 断轨前绞盘拖矿与绕行支线返程、E11 舱位权益注销后签收才放药，以及旧公司名单要求不构成放货条件。

## 六、改写后的拍摄与剪辑判断

本季 E01 正式剧本／导演分镜及 E06 已定稿剧本以外的文本，仍是**可继续进入分镜阶段的剧情提案**。E06 剧本定稿不意味着逐镜分镜已完成；时间区间是表演与剪辑参考而不是硬性秒表。分镜时优先检验：开场无需字幕解说能否让观众进入；E09 失联后主动关闭小七语音是否留出沉默表演；E11 开场修车与货台交收能否不显拥挤；E11 的支付、签收与 E12 的公共中继申请能否用少量清楚的动作串起而不挤压情绪；矿袋、滤芯、普通电匣、船票凭单、床牌能否跨集跟踪；同样的维修棚与食堂空间能否用重复构图呈现关系变化。

**画幅由实际发行平台和导演决定。** 荒原追逐、巨型风塔与主井纵深既可以横幅电影化表现，也可以重新设计竖屏构图；本文件不再替导演预设 9:16。
