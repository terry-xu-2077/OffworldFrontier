## 一、第一季是什么故事

特瑞从荒原进入一座旧矿井聚落，开始认识这颗星球上不同的生命与人群。他逐渐参与矿井救援、风塔维修、远行、生态观察、技术试验和共同防卫，也在夜里拥有一张刻着自己名字的床。

**风塔不是主角。** 居民在几个月内为一个共同的未来做准备：**风汛**约一个月有相对稳定的强风，可让修好的主风塔集中发电；紧随其后的**封沙月**约一个月，矿尘沙暴让主塔必须收桨停机、太阳能几乎失效；再后是昼短夜长、持续数月的**长夜季**，居民要依靠储能、有限常规供电和精打细算的物资继续生活。这个目标像舞台背景，既给日常时间压力，也不能让每集都变成寻零件。

观众的观看乐趣不止是物资紧张：**异星生态奇观、其他人类聚落、共同冒险与防卫、能实际看到的建设成果、科技实验、群像喜剧，以及特瑞与莺的微妙关系**，都有独立空间。只要拿掉风塔仍然值得看，这件事才有资格独立成集。

## 二、暂排14集：每集的独立看点

|---|---|---|---|
| **01** | 一块生物电池 | **正式剧本及分镜** | 异星荒原、地下采集路线、废运输舰，866损坏与生物电池登场 |
| **02** | 门外的人 | 剧本提案 | 高墙、双闸与热闹食堂；《两枚圆子》卡币成为居民生活插曲，特瑞边吃边听矿工谈风汛和风塔 |
| **03** | 井下救援 | 剧本提案 | 三矿工陷于接轨桥险情，四只浅层岩甲虫从受震裂隙进入，徐世嵘指挥、特瑞辅助判断 |
| **04** | 没有名字的床位 | 剧本提案 | 第一次跟维修队上风塔、小七先借后赠；结尾特瑞轻拨手工床位牌 |
| **05** | 移动的家 | 剧本提案 | 旧转运站会迁移的生活街、杰西卡熟悉的外部社会、维克托换到需改装的旧备件 |
| **06** | 一箱土豆 | **正式剧本V1.0** | VTX旧冷封箱、莺的种植实验、露台对话和街机生活 |
| **07** | 绿洲会关门 | 剧本提案 | 特瑞与莺的绿洲采样，覆膜林闭合、采集虫被岩壳卷膜捕食、两人配合逃离 |
| **08** | 门外的灯 | **合并提案** | 凯恩开闸救伊德里斯和阿坤，玛塔姨与阿坤互让新医疗滤芯，莺损失温室菌料帮助病人 |
| **09** | 一个人的黑暗 | 剧本提案 | 特瑞重返事故矿道回收一袋矿石、旧卷闸异常落下，他独自借标记、气流与低频找到绕行路 |

| **11** | 一张船票 | **两集合并提案** | 杰西卡通过醒巢石话题拒绝出售井下位置、用旧维护号叫船；补给船到港，她用唯一真票补足药与滤芯 |
| **12** | 风汛 | 剧本提案 | 居民数月修复的主风塔终于稳定并网；一个月蓄能期以群像生活跨时间表现，末尾开始停机迎接沙墙 |
| **13** | 封沙月 | 剧本提案 | 巨大沙墙、储能与限电生活、棘岩爬子钻入外墙热缆管廊；玛塔姨送出补过角的枕布 |
| **14** | 用自己的名字签 | 季终提案 | 长夜初临，特瑞有能力离开却自愿返回；徐世嵘具名提交旧案、特瑞自己申请身份、土豆生出一小点绿；轨道探测器只在全季最后一镜出现 |

**14集是目前相对舒展、各集看点不重复的结构，并不意味着制作必须拍满14集。** 后段有两次一集内时间跳跃：E11叫船到抵港相隔数日，E12蓄能、E13封沙各跨约一个月。

## 三、为什么这次只再砍两集

| 内容 | 当前判断 | 后续还能怎样压缩 |
|---|---|---|
| E03《井下救援》与E04《没有名字的床位》 | **不合并**。前者是矿井生死危险，后者是工程世界＋获得小七与床位；合并会让床位牌成为救援奖励 | 压缩重复的物资登记和救援后解释即可，保留E04最后的轻拨 |
| E07《绿洲会关门》 | **单独保留**。异星生态、特瑞与莺相处都需要完整空间 | 少拍实验准备、多拍进入绿洲和生态行为 |
| E08《门外的灯》 | **已经合并过两集**，内容偏密，但完整的开门决定和互让滤芯都值得保留 | 进一步缩短开闸后重复收尾，把开门与次日决定作为一次24小时事件呈现 |
| E09《一个人的黑暗》 | **单独保留**。整季对特瑞心理弱点最完整的一次行动考验；与E03虽同在井下，却承担不同人物意义 | 精简地形重复描写与报点次数，不能删除“安静才能听见”及上面有人等待的交叉剪辑 |
| E10原能源实验＋防卫 | **已合并**。实验A线保证科学发现，凯恩的遭窃追查是中途短暂打断，不独立发展连续敌人 | 保持防卫戏紧凑，不能吞掉生物电池第一次点亮的重心 |
| E11原醒巢石＋船票 | **已合并**。叫船、到港、舍票本来就是同一件事的因果链 | “旧公司有人使用”作为背景阴影，结尾以玛塔姨恢复和杰西卡的情绪结束 |
| E12—E14季末 | **暂时各留一集**。风塔首次发电是工业高潮、封沙月是自然与生活考验、选择留下是情感尾声 | 如果将来片长极短，可以把E14变成E13的尾声，收束成13集；但目前不急于挤掉长夜与特瑞选择的呼吸感 |

## 四、核心人物及连续性

- **特瑞／866：** E01坏腿和低电量、E03隔离检修、E07限速短途试车、E09井下坐另一辆同轨距矿车、E10防卫搭基地运输车；直到E11才最终通过长途与受力验收，E14门卫允许他自愿外出，他选择返回。E04小七从徐世嵘手里交付后仍是无法自主行动的头部残机。
- **莺／植物：** E06有三枚小土豆，仅一枚疑似存活；E07生态观察出于自身好奇；E08救助病人使菌料报废；E10普通工业匣稳定实验和生物电池隔离取电互不混同，土豆芽眼略有变化；E13温室需持续补光，E14才清楚出现小绿芽。特瑞与莺仅有自然互相欣赏，不提前确认关系。
- **矿井与虫群：** E03矿车翻在七号门深处废巷，三人困在靠电梯的损坏接轨桥；E09从更深的旧横巷回收一袋，七号门旁主巷卷闸异常落下，绕行路线仍是同轨距。虫子不是故意要消灭人类的恶徒。
- **玛塔姨／阿坤：** E08开门救人并相让滤芯，医疗精滤芯只有一只新件，莺给阿坤；利用温室上游粗滤保护玛塔姨旧精滤芯、菌料损失。E11补给带来新滤芯，玛塔姨换上，一只另存备用；E13送特瑞补过的枕布，E14床头才出现这块布。
- **杰西卡／旧公司：** E05真船票仍有效，酒吧发光晶体来自多年前的游商；E11她拒绝掮客要井段资料，只用旧维护号码叫船，旧公司自动记下「有人使用」；老船长接受她那唯一一张真票补足三箱药与两只医疗精滤芯。E14以旧回执对照世嵘旧卡号，世嵘主动具名提交旧案，特瑞本人写申请；**直到轨道探测器的最后一镜，不提前出现旧公司星际侦测场面**。
- **风塔／电力：** 日常太阳能、小风电、同位素机和旧储能始终供能；主风塔原来低速空转不能向储能母线发电。E04检查、E05换得需改造备件、E10小型监测箱被盗后防护，E11补给，E12才安全并网；风汛高效发电后E13封沙月必须停机，E14长夜季仍有节能压力。
- **本季未解：** 两袋普通矿石、七号门真相、曜晶深部矿源、生物电池活体供养、旧公司后续动作、身份审核。这些不是本季必须一口气全部结清的悬疑清单。

## 五、下一轮创作关注

现在再打磨时，优先看**每集有没有一个真正能吸引观众的场面**，而不是继续往表格里增加事件。特别关注 E08（合并后的叙事负载）、E09（井下路线的清晰程度）和 E14（制度性收尾的台词长度）；这几处更适合压场面与剪辑节奏，不急着再合并新集数。
