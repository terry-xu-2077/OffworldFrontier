# 第一季短剧 · 季度设计与分集一览

> **本文件与同目录所有单集剧本均为「提案」。** 情节、次要人物、具体数字尚未并入人物或世界专题，确认后才成为正典。
> 单集时长与前 10 秒钩子是本次委托的**制作格式约束**（导演确认的当前制作决定），不构成对世界专题的改写，也不要求后续作品沿用固定分集数量或片长。

## 一、格式约束（本季节奏规范）

| 项 | 规定 |
|---|---|
| 画幅 | 首选 **9:16 竖屏**（主井垂直深度、电梯铅笔头舱体、矿道纵深天然适合竖向构图）；16:9 可作为备选，需在分镜阶段重排巨物镜头 |
| 单集时长 | **≤ 3 分钟**，成片按 2:45–3:00 控制 |
| 节拍 | 0:00–0:10 冲突钩子 → 0:10–2:20 主冲突（≤2 个场景）→ 2:20–2:45 反转与代价 → 2:45–3:00 卡尾钩子 |
| 台词量 | 每集口白 **300–470 字**（按 4.5 字/秒计约 67–104 秒），其余 76–113 秒交给动作、静场与环境声；短句优先，不用网络流行语 |
| 场景 | 每集 **≤ 2 处**主场景（维修棚 / 主井平台 / 生活仓连廊 / 食堂舱 / 外闸段 / 医疗角 / 浅横巷 / 入库台 / 酒吧吧台 / 防线外圈 / 温室） |

| 钩子检验 | 陌生观众在 10 秒内能否回答：谁要什么、不给会怎样 |
| 幽默 | 来自性格与职业细节（小七过分正式、维克托骂机器、马克的记账口吻），不用网络流行语，不连续贫嘴；每场一两个有效笑点 |

## 二、季度前提（提案）

主井避难所是旧公司撤离时被降级成"低价值残余资产"的废井旁聚落。一次补重量的下矿带回一撮自发光的细尘，一次为了让无名少年上工的权限改写，两条动作在第十集汇成同一件事：**这座本来没人管的基地，被系统重新看见了。**

季度引擎由三根计时器驱动，全部来自既有机制，不额外发明制度：

1. **库存终端只答"还能撑几天"**（世界专题 · 经济与游商）：每集片尾天数往下掉。
2. **交易窗口**：船来之前必须凑够可换重量；船会晚到、会被风暴或巡查改道。
3. **远程秩序阶梯**（旧公司与供应商专题）：本季只走到第 1–3 阶——资产锁定与代币批次登记 → 代理人与游商探路 → 测绘核验。**不进入第 4 阶武力收回**，留给第二季。

**双风险线严格分开**：追矿、破岩、爆破、横巷扩张惊扰地下虫群；旧核心装置短暂启动留下回波、引来与重力异常有关的未知生命体。本季 E1–E7 只走虫群线，季终最后一镜才第一次启动核心。

## 四、代价延续链（跨集不许清零）

- E1 急停 → E2 三袋矿 → E2 起 交易重量缺口 → E6 滤芯只有一只 → E7 单人下井动机 → E9 掠夺者知道基地缺电。

## 五、人物弧（本季可执行部分）

- **特瑞**：换电就走 → 在黑暗里守住约定、把报点变成可执行信息。每次成长只加一个动作：报点 → 标记 → 计时 → 复述退路 → 独自守点。
- **莺**：先看见能力，再命名情绪；她的盲点（被眼前生命拉住而错过窗口）必须在 E6 造成实际损失，不能被原谅掉。
- **徐世嵘**：只给部分风险 → 第一次在记录上签名（E5）→ 用自己的名字签后果（E10）。他不说"别怕"。
- **维克托**：先骂设备再救设备；每次改装都要报代价。与特瑞通过同一台 866 演进：开坏—拖回—挨骂—一起拆。
- **马克**：刻薄必须有具体对象；危机中只做调度，不实时报损；救命处舍得开柜，对自己最抠。
- **杰西卡**：多说几句都要有收获；E8 她犯的错必须真实（交出回波），压力来临时先收掉笑。
- **凯恩**：日常能正常聊天、有干幽默；危险后句子变短，只处理站位、威胁、出口、弹药、撤离。"资产优先/可处理资产"触发他压回箱盖。
- **小七**：只能被携带；每场一两个有效笑点；在错误时间泄露半块拼图，缺页时答非所问。

## 六、边界（写作时不可越线）

- 特瑞只读自然低频（地面、岩体、井壁、虫群移动、矿层应力、塌陷、沙暴远震）；不诊断门禁、风塔、电梯、配电、信标、接口或公司系统。
- 设备与能量取舍归维克托；医疗、生态、伦理归莺；库存、配给、估价归马克；防线、站位、火力纪律归凯恩；最终集体裁决归徐世嵘。小七只检测、播报、接入，不做决定、不自行移动。
- 荒原、聚落、旧维护路线上可裸脸说话干活；需要成套呼吸装备的只有沙暴核心、紫霜雾、深井气体、封闭残骸等。
- 土豆罐头是熟食、不能发芽；可发芽冷封土豆块是作物源，不是食物，两者不得混用。
- 曜晶名词分层：档案与合同用"曜晶矿源"，日常用"曜晶石"，样本封装用"曜晶体"，特瑞与老矿工忌讳地叫"醒巢石"。稳定曜晶体只自发柔光、给金属边缘漂亮辉边，可作临时标记；核心装置是封闭厚壳工业黑匣，不是发光水晶棒。
- 旧矿工只能接入、旁路、降功率、压回保护状态，不能手搓或复制旧核心。
- 玛塔姨固定为井下门闸与井口闸控出身，肺病与关节变形来自回井矿尘、气密门泄漏与事故尘雾，**不能写成下井采矿女工**。

## 八、复用场景与道具（成本控制）

- **主景五处，全部可搭**：维修棚、主井站台与调度角（含机械翻牌与绿色磷光屏）、生活仓登记角／食堂舱／医务站收费口（同一舱段换角度）、外闸段（外闸—隔离段—内闸）、浅横巷（一段窄巷＋矿机＋支架即可复用到 E2、E7）。
- **道具复用率高**：手写标签与手写库存卡（几乎每集）、旧圆子与圆子盒、扎带与手写合金名牌、记号笔与秒表与路线图（02→07→09 三集同一组）、能量匣与"撤离备用"标签、旧消费终端 UI-CV12、小七。
- **必须实拍特写的三件核心道具**：机械翻牌（权限事件可视化）、绿色磷光屏（状态与字段）、自发光曜晶体（只给柔和体积光与金属边缘辉边，不做光效魔法）。
- **不出现**：扫码／手机支付／数字钱包、全息屏、激光枪与弹壳、发光水晶棒式核心、角色当场造出或复制旧核心。
