> **来自导演的两条格式要求：** 每集成片不超过 **3 分钟**；前 **10 秒**让第一次接触作品的观众明白具体冲突，并有理由往下看。

## 一、本季讲什么

**一个只想修好车继续走的荒星少年，意外在一处旧深井聚落找到愿意留下的理由。**

- **人物入口：** 前几分钟先认识特瑞是怎样的人——机灵、爱表现、会在危险面前迅速判断，也怕安静。不要先用权限、合同和旧公司资料解释世界。
- **生活关系：** 他在修车、帮工、吃饭、分床、闲聊中与维克托、马克、莺、世嵘及其他人慢慢形成联系。人物偶尔做错事，但不让他连续十集充当事故源。
- **生存与冒险：** 这座家园靠矿、电、药、滤芯撑着；下井会惊扰既有生态，通风与医疗又必须消耗真实物资。好心、守原则、冒险和保护都可能让别人付代价。
- **更大的风险：** 有人为了药和离开的机会，把旧井的信息送出去了。基地过去因“没有价值”被遗忘，现在却因仍在运转和疑似曜晶矿源再次被旧秩序注意。
- **情感收束：** 特瑞原本只想给 866 换一块电池就离开，后来愿意自己写下名字；徐世嵘从隐瞒旧身份，到用本名承担旧案风险。**这是一季人物关系的开始，不是旧公司故事的完结。**

### 每集的开场钩子究竟要达到什么

- **看得懂：** 先有物件、危险、具体人物目标，例如空饭碗、锁住的药、拍门的人、正在故障的车。
- **想知道：** 观众想看“他能不能逃”“门会不会开”“谁会得到滤芯”“他为什么要签名”。
- **看完记住谁：** 视觉悬念负责留住第一秒，人物的选择负责让下一集还有人想看。
- **不追求每集连续爆炸式升级：** 04 是生活喜剧，03 是身份与归属，07 是个人惊险，05 和 06 是两难，08—10 才逐步走向外部威胁。

## 三、人物线，不把角色当成制度岗位

**特瑞**：01 用荒星经验保命；02 用低频直觉救人；03 接受自己的床位；04 学会先问维克托再动旧电路；07 没人回应时仍坚持标记与撤退；10 自己写下名字。这不是“反复闯祸—赎罪”的成长模板。

**维克托**：从觉得少年和破车都很麻烦，到用维修、递工具、放手让他判断的方式建立默契。866 不只是载具，也是这段关系的可见物件。

**马克**：不是只会念仓库数字的人。他亲自核对每一份物资、给人分饭，也愿意拿出自己留着的份额；不同意莺，也会递上一杯水。

**莺**：有判断力也有盲区。05 她坚持先救门外活人，06 自己做出拆温室预滤组件的选择并公开承担菌料损失；不靠单句温柔台词定义她。

**徐世嵘**：02 根据特瑞的报警组织救援；03 用旧卡报上特瑞姓名，机器记下他的卡号；05 在开闸救人的记录本上签名；10 交出当年的撤离命令和自己修改过的门闸记录。并不把旧公司全部真相一次解释完。

**凯恩**：05 面对陌生人不敢立即开门；09 经核实后及时开闸，依然被现实危险逼出代价。旧安保创伤体现在动作和选择，不循环使用一句口头禅。

**杰西卡**：04 是酒吧里有趣的观察者；08 因为药与真正能离开的机会作出有风险的交易；10 把尚可兑现的两席船位作价换药。她仍然可以向往离开，没有被道德口号“治好”。

**小七**：严格由人携带；是碎片播报和幽默陪伴，不是能解锁任何设备的万能侦探。七号门、身份、矿样的解释需要其他人的经验和证据。

## 五、世界规则与连续性边界

- 特瑞感知的是岩体、地层、虫群的**自然低频**；不能隔着钢板读出门锁授权或设备维修报告。
- 虫群有生态动机：E01 护卫赶走侵入采集路线的震动载具，越过地缝后回撤；E09 浅层爬子追随热管、湿痕与扰动。不把虫群写成受曜晶核心召唤的追兵。
- **矿源 ≠ 核心装置。** 稳定曜晶体柔和自发光，可作样本与临时标记；不直接释放可用电，也不会自行制造大规模重力异常。
- E05 的**进风粗滤网**、E06 的**医疗精滤芯**、温室的**精密防尘预滤组件**是三类不同物件；温室组件仅作为旧医疗滤芯的短时前级预滤，不能替代医疗精滤功能。
- 圆子是实体代币，E04 两枚硬币在“被卡住→取出归还→再次投入→人工确认已收”之间流转，屏幕没有让硬币表面自动浮出文字。
- 徐世嵘靠旧权限卡签字领到了药，不代表旧公司不再追究他；他往公共档案通信线路发送旧案证据，也不代表特瑞已经获得正式身份。公司的设备清查与公共部门的身份审查是两件不同的事。
- 小七无行动能力。玛塔姨是旧闸控人员，不是深井采矿工。旧核心和与重力异常有关的生命体可留待后续故事，不必为“季终奇观”强行启动。

### 运矿运输统一规则

**主井只有一台大型磁悬浮电梯。** 日常矿车使用可充电、可更换的标准能量匣驱动车轴旁的电机，沿横巷矿轨低速自行行驶。矿工用有线控制柄操纵车辆；完整轨道可按标记点缓慢自动通行，损坏轨道与岔口需要人手动确认。到了井口，接轨对齐后矿车靠自身动力驶入电梯，拉下驻车制动、扣牢车轮；矿工站在安全区同舱升井，到地表后再把矿车开上地磅。采矿机和维修设备也能使用同一电梯，没有单独运矿货梯。牵引耗电且电机会保护停机；遇到断轨，靠车载小型电动绞盘或检修牵引缆回收矿物，不能凭空越过断轨，也不让矿工长距离推满载重车。E02 是矿车遇断轨停机后翻进支巷；E07 特瑞带充过电的空矿车下去，在安全位置停稳，用绞盘只拖回一袋矿石。

### 抽象词与含糊简称的处理

| 容易造成误解的说法 | 具体所指 / 剧本应怎样表达 |
|---|---|
| “重量”“交易重量”“补重量” | 为了换药、滤芯还缺的**普通矿石**；可写“矿车里那三袋矿石”“再挖一车矿” |
| “交易矿”“补矿” | 准备拿去跟游商交换物资的矿石；人物谈实物时直接说“矿石”“那几袋矿” |
| “交易窗口”“换货机会” | **下一艘游商船抵达的时间**，错过就得等下一船 |
| “本地账”“工分出不了账” | 马克的手写劳动记录、配给簿；正式系统不承认特瑞的身份，无法自动发配给条 |
| “留痕”“旧权限留痕” | 徐世嵘刷旧权限卡后，终端记录了他的卡号和操作时间 |
| “终端唤醒”“旧系统醒了” | 原本停用的旧公司计费盒重新亮灯、尝试联网或锁住出餐机构；动作描写先给具体变化 |
| “资产核验”“待核验” | 旧公司正在**重新核对主井设备归属与人员名单**；屏幕字段可保留正式说法，人物说清后果 |
| “回传”“报回外环” | 旧设备通过数据线把编号、记录或位置发给旧公司的系统 |
| “货运预留”“船位担保” | 游商暂时答应留药和船上座位，尚未真正交货或取得登船资格 |
| “责任主体”“接收资格” | 需要一位旧系统承认身份、愿意签字承担责任的人，药箱才会放行 |
| “接驳” | 矿井里指**横巷轨道接上电梯舱短轨**；货运场景则指**飞船停靠和货物交付平台**，不能混淆 |

这些用语不是全剧禁词：专业人员在工作时可以使用简称，系统界面也可以保留正式术语；关键是同一场戏里观众应知道它具体指的是什么、发生了什么。人物有意隐瞒、卖关子时的含糊表达，仍可保留。

### 剧本物件与画面可执行性（本季执行原则）

- **先画得出来，再写术语。** 第一次出现陌生道具，应以一两个可见特征交代它的外形和位置，说明是谁碰了哪个部件、发生了什么变化；以后可沿用简称。正常易懂的物件不必重复解释。
- **状态信息使用琥珀色点阵 LED。** 主井平台、外闸和货物交收台的旧设备状态屏，统一为厚金属框内的低分辨率琥珀色点阵 LED 屏；短字、数字逐行点亮，允许灯点缺损。**不使用机场或火车站式机械翻牌装置。** 井深、波形、档案等细项留给绿色磷光诊断屏。
- **控制机构与信息屏分开。** 开门、锁止、供电、收货和紧急停止由手轮、实体按钮、机械锁扣或电气插头触发；屏幕只反馈信息，不能用“屏幕唤醒”“权限回写”等抽象句替代可见的操作与结果。
- **一次只传达关键状态。** 观众需要看懂的是“药箱没放行”“旧公司在重新查人”，不是记住全部数据库字段。正式术语可以存在于设备细项和设定文档，角色日常台词尽量用生活语言解释后果。
- **道具流向与空间必须连续。** 包括 E01 电匣插在车的哪个接口、E02 电动矿车为何停机侧翻、E05 双闸传递仓怎样用、E06 两类滤芯是否互换、E07 电动矿车停在断轨前、绞盘拖回矿石再驶进同一电梯、E10 两道货门何时开。

## 六、改写后的拍摄与剪辑判断

本次文本提供的是**可继续进入分镜阶段的剧本提案**，场景时间区间是预估表演和镜头容量，不是硬性秒表。分镜时优先检验：前 10 秒无需字幕解说能否读懂矛盾；场面动作与出入画能否在真实镜头时长内完成；同一矿袋、滤芯、电匣、手写牌能否连续跟踪；台词是否符合演员说话节奏；不同集的节奏和视觉空间是否有变化。

**画幅由实际发行平台和导演决定。** 荒原追逐、巨型风塔与主井纵深既可以横幅电影化表现，也可以重新设计竖屏构图；本文件不再替导演预设 9:16。
