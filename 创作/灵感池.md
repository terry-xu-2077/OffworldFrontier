## IDEA-001｜生物电池的异常波动与行为影响

**记录：** 2026-10-19  
**标签：** 生物电池 / 异星生命 / 电磁干扰 / 行为 / 悬疑  
**状态：** 未定案；仅保存创意，不赋予电池已确定的新能力。

### 保留的创意核心（按现行设定筛选）

生物电池内部的**低阶无意识生命**受活化刺激后，可能释放某种非意识电磁、电化学或其他未知波动，影响相连电子设备的读数或运行，甚至使附近的人短暂感到兴奋、焦躁或更容易冲动。内部生物的微光丝束和运动形态可能随刺激强度变得更加激烈。这些异常影响的存在与机制**尚未确认**，也不能据此推导出电池有自我意识、人格或读心能力。

### 可能呈现的现象（待验证的故事假设）

- 密封反应舱中原本缓慢舒展的微型生物群，活化增强后变得激烈、伸展、快速闪烁或重新排列；**“形态张狂”是镜头观感，不代表愤怒或有意图**。
- 与电池接线的旧终端出现读数飘移、杂波、灯光闪烁或控制器偶发异常；可从**沿导线传播的干扰**先写，再考虑未接线设备受影响的边界。
- 使用者或近距离接触者出现短暂烦躁、兴奋、急躁、冒险欲增强或克制力下降的感觉；也可能只是紧张、辐射热、电气噪声、药物暴露、环境危险或人物原本性格的结果。**不写成无条件人格控制或“电池决定人类行动”**。
- 电池活化越强，内部变化、设备异常和人物冲动似乎越同步；这种时间相关性可以推动人物去观察、断电、隔离、对照、怀疑，而不是自动构成因果证据。

### 关键开放问题

1. 是**沿线路传递的电磁/电化学扰动**，还是能短距离扩散的非意识波动？两者强弱是否不同？
2. 影响人体的机制是神经系统受刺激、其他可检测环境因素，还是暂时无法解释？需要多强、多久、离多近？
3. 这种效应是本来就存在，还是在超频、过热、受损、开壳或接错设备时才出现？
4. 影响会不会随离开、断线、屏蔽而减弱？是否具有累积损害或不可逆后果？
5. 如果电池看似“回应”使用者，如何提供**复杂本能与环境反馈**的解释，而不立即把它写成有意识的器灵？

### 已确认、不得误写的边界（引用正典，不在这里重复定稿）

- [能源系统与曜晶矿源](../设定/世界设定/04_能源系统与曜晶矿源.md)：这种活体电池极其罕见，和常规能量匣、曜晶核心不是一回事；活化不代表完成充电。
- [地表生态与食物链](../设定/世界设定/08_地表生态与食物链.md)：荒星低阶生命按无意识本能型处理；高阶原生生命虽可能表现出有意图的行为，却由于缺少活体实验室研究，**是否具有意识未知**。
- 本条的“影响人体和电子设备”仍是**可能性**，尚未并入电池确定性能。并且不把第一集的虫群追击改成受生物电池召唤。

## IDEA-002｜从仙侠法宝借机制，转译成科幻技术

**记录：** 2026-10-19  
**标签：** 灵感方法 / 仙侠 / 法宝 / 武器 / 生物技术 / 工业设计  
**状态：** 开放方法；不是现行世界新增了一套修炼或灵力体系。

### 最初发散（来自本次讨论）

> “以后找灵感是否可以从仙侠体系里参考道具武器设计，进行转换到科幻世界？”

**思路：借功能逻辑，不借表面外观和无条件超能力。** 把法宝的使用条件、养护、反噬、成长和与使用者的关系，转换为能拍出来、会损耗、存在供应链的工业或生物科技。

| 仙侠的功能原型 | 可以尝试的科幻转译 | 保留的戏剧价值 |
|---|---|---|
| 灵石、灵力耗尽 | 能量电池、可消耗化学燃料、特殊反应物 | 续航、补充、谁先使用 |
| 法宝温养、祭炼 | 生物材料培育、微型反应舱保育、维护和校准 | 需要照顾、可能休眠或衰亡 |
| 法宝认主 | 旧权限、生物特征匹配、神经接口或生态共生适配 | 捡到装备不等于会用；技术可能拒绝使用者 |
| 器灵 | 自适应控制器、群体反馈、模糊的类意图行为 | 器物像有性格，但不必真有意识 |
| 灵气灌注、秘法催动 | 高负荷供能、催化刺激、短时超频 | 立即获得能力，付出寿命、损伤或失控风险 |
| 反噬、走火入魔 | 神经副作用、电磁干扰、材料过热、污染和不兼容 | 使用者可能被装备拖累 |
| 护身符、符箓 | 一次性微反应膜、定向传感贴片、智能材料 | 小型、易携带、有限次数的实用技术 |
| 飞剑、御器 | 受通信、导航、能源限制的自主小型武器或无人机 | 远程控制、失联、回收与误判 |

### 转译时的六个问题

**能做什么 → 物理/生物机制是什么 → 谁能制造或维修 → 消耗什么 → 如何损坏/失控 → 会怎样改变人物及社会。**

不必每个条目一次回答完；没有答案的部分应标为待研究。不能因为仙侠里某种法宝“认主”，就在现行正典中直接给异星生物安排有意识的忠诚关系。

### 美术方向候选

冰冷、厚重、可维修的旧工业外壳，内部却运行陌生的微生态和活体材料。**“表面是工业机器、内部是异星生命系统”**可作为探索中的视觉母题，不要求今后的全部装备都如此。

## IDEA-003｜生物电池是技术，也是活体资源

**记录：** 2026-10-19  
**标签：** 产业 / 社会关系 / 伦理 / 生物能源  
**状态：** 由生物电池讨论延伸的提问，未定案。

- 如果能源核心中封装的是**仍然活着的生物**，它的维护是否类似照顾微型生态？饲料、活化液、温度、污染控制和休眠条件是否成为新的供应链？
- 长期不用时可能休眠，也可能死亡；一旦内部生物全部死亡，是否只能更换培养舱，无法简单地“修电池”？
- 过量激活、超频取电可能导致活体衰败、积热、产气、密封破裂，特定条件下还可能爆燃；技术进步与使用者贪心之间能出现选择。
- 活体样本来自自然采集、人工培育还是旧公司控制的专利库？稀有性是技术复杂、供应困难、法律封锁还是生态代价造成？
- 若某些生命能被工业性地收集、培育、耗尽乃至处理，是否产生资源保护、企业垄断和使用者对待生命的态度冲突？**这些是人物塑造的材料，不要求作品立即变成伦理说教。**

已有正典中“罕见生物电池”“普通电池技术”“低阶生命无意识”的部分仍按各自专题执行；本条只是把未来可能出现的世界影响留住。

### IDEA-004｜同一个签名，逐渐暴露旧公司回收网络

**来源：** 旧灵感总表的「回收专员·柯尔」与旧十集规划的游商报价、风塔查询。**状态：角色姓名、身份与出现方式均未被新正典确认。**

一名从不现身的旧公司回收专员，反复通过药品报价单的签名、风塔远程维护记录、设备报价、短促通信条件接近基地。观众先发现熟悉的签章，人物后来才察觉几次看似无关的交易背后有人在摸清他们。这个人未必是恶意军官，也可能只按合同执行回收手续。

**待探索：** 他是具体人、共享机构签名还是冒用身份？各种资料真正如何传输？不自动复活旧剧集的反派位置。

### IDEA-005｜便宜的药可能是在买更贵的坐标

**来源：** 旧十集规划《坏消息也要中间人》。

掮客提出熟人价药、滤芯、旧电池，表面收矿样，附带要求降落平台坐标、风塔是否运转、井区资产编号。杰西卡判断最贵的是运营情报，选择只交一段已停用的公共航标频段，先用普通矿石和废零件试单，既试探对方有没有货，也不立刻透露基地的位置。

**待探索：** 对方如何证明有货？交出旧航标会不会误导无辜商船？保留为可选商业博弈，不要求杰西卡每次这样谈价。

### IDEA-006｜一座风塔修好了，另一处设备却更危险

**来源：** 旧十集规划《风塔前哨站》。

基地靠备用电池熬过风塔故障；徐世嵘负责前哨门禁，维克托远程指导线路，特瑞贴掌判断地层风险。风塔恢复部分供电，但接回主网时老化电闸阵列过载，立刻需要绝缘材料和检修工作。维护记录还可能露出陌生查询签名，或与特瑞旧地图某个废井号一致的编号。

**待探索：** 哪个具体零件过载、如何有可见故障？编号相同是否仅是巧合？一次抢修不等于证实曜晶矿源。

### IDEA-007｜高处的灯：失联不需要靠说教克服

**来源：** 旧十集规划《高处的灯》。

莺和特瑞在能看见主井、温室和风塔的高处检修平台，做一分钟不使用无线电的练习。特瑞需要留下「方向、人数、返程点」三个标记，复述实际撤退路线。莺没有替他分析创伤，只从远处亮起一盏检修灯确认有人看到了标记。特瑞没有被治好，只是多掌握一个失联时可以执行的动作。

**待探索：** 灯光如何区别于真正求救信号？这个场面不是某一集之前必须完成的训练。

### IDEA-008｜心理创伤也可能使平凡工作出错

**来源：** 旧十集规划《电闸阵列》。

普通检修中短暂的无人回应与金属冷响，让特瑞想起旧聚落灾难；他在等待切换指令时走神，造成局部停机、轻伤或材料损失。重点是看见他如何面对错误、进行复盘、学习求助，而不是戏剧性地制造大灾难。

**谨慎使用：** 当前人物方向不希望特瑞反复扮演事故源。此条只是一次性人物测试，不能变成每集闯祸的固定模板。

### IDEA-009｜救人使用的旧药剂，意外留下公司追踪线索

**来源：** 旧十集规划《电闸阵列》，维塔克斯药品项目。

有人受伤，药柜仅存一支旧公司封存急救药。莺认为救人要紧，凯恩担心旧药安全和来历，马克则知道这支药本来能换其他救命物资。人救回来之后，原本不起眼的生产批号被医务终端记录，甚至通过旧数据线路传了出去，一次合理选择带来新风险。

**待探索：** 批号需要怎样被扫描、上报或联网？纸标签不能凭空向公司发送信息。

### IDEA-010｜放弃整片昂贵生态，只取够救命的量

**来源：** 旧十集规划《绿洲的价码》。

采集工在绿洲被滤材和隐蔽的岩壳卷膜困住，莺先带人撤离，只采回修电闸真正需要的少量纤维、胶质和体液，不去切割高价值成熟覆膜支脉。队伍退走，风暴前的覆膜林在身后缓慢合拢。基地少了能跟游商谈价的矿外筹码，留下的绿洲仍能继续生长。

**待探索：** 真实所需材料和采集工具，不能靠“神奇生态材料”轻松修任何设备。

### IDEA-011｜酒吧一盏暖灯，变成危机里的救援灯

**来源：** 旧十集规划《最后的避难所》。

马克把药、滤芯、撤离电池与旧病号的两套不完美分配方案公开，让居民明白资源不够的具体后果；杰西卡把最舍不得关的一盏酒吧暖灯拆下来接到临时避难区，顺手取出自动贩卖柜里的罐头发给避难者。有人共同承担得失，基地才不是只有仓库的一座工作营地。

**边界：** 只保留「公开抉择与道具用途改变」的场面，不把旧季终围攻或旧核心启动规定搬进新剧本。

### IDEA-012｜旧终端的陪伴与身份噪声碰巧出现

**来源：** 旧十集规划《窗台上的小七》和旧前三条短视频拆分。

**已经采用的部分：** 当前[第五集《床头名牌》](剧本/第一季/05_床头名牌.md)中，小七原本在基地，由世嵘借给特瑞完成实际的离线日志读取任务；特瑞归还后，世嵘主动将它和充电线送给他，作为无须明说的信任和关照。

**仍可发展：** 特瑞把小七摆到起居室的窗台，用废布堵住窗缝，小七播报「本机不是室内装饰物」。夜里特瑞碎碎念，旧屏幕偶然闪过残缺身份码或转运记录，随后恢复正常。小七不能替他解释旧案，甚至可能不知道刚刚读到了什么。

**待探索：** 额外的身份码线索来自本机残存存储，还是插着某个旧公司接口？不得因此让小七具备万能读取或自主移动能力。身份噪声尚未编入正式剧情，也不应替代第三集末尾世嵘主动补报姓名留下旧卡号的既有情节。

### IDEA-013｜遥远新闻传到荒星，已经被好几只手剪过

**来源：** 旧十集规划《坏消息也要中间人》。

几光年外的事故新闻先被长航线监听链截获，途中经过走私船、游商和海盗频道的多次转录、延迟复播、删改；同一事件到了杰西卡酒吧竟出现几个矛盾版本。她要判断哪个版本影响真实船期、药价和航线安全，而不能当成全知新闻播报。

**去重：** 远距离通信要中继的基本事实已经进入人物与世界设定；这里只保留多版本新闻造成实际判断冲突的场景。

### IDEA-014｜值钱矿样，不一定就是曜晶秘密

**来源：** 旧十集规划《窗台上的小七》。

矿工在安全侧浅孔带回一盒比普通矿石更值钱、却明显未达到曜晶等级的矿样。马克称重、检查裂面、封样待检，不急着宣称发现星球能源奇迹；采矿任务的真正收获反而是危险矿段无人伤亡。

**待探索：** 具体矿种、实际报价和检测特征；不让“稀有矿样”四字取代可拍物件。

### IDEA-015｜一句模糊的易象师话术，在很久后才有回响

**来源：** 旧剧情大纲、旧十集规划《绿洲的价码》。

游商身边一位短暂停留的易象师／地脉先生，看了特瑞一眼，说「别急。名字会来的」。特瑞当时以为只是江湖套话；后来如果有人向公共档案中心提交了他的姓名，这句话会突然产生另一层情绪，却依然不能证实有人预见未来。

**去重：** 易象师的职业已经是现行世界设定；这里只迁移一次偶遇、悬念式台词及其可能的回响，不强制使用原句。

### IDEA-016｜酒吧第一次亮灯，是聚落拥有公共生活的时刻

废船壳和旧生活仓门板拼出吧台，杰西卡坚持装上一盏暖灯；有人用旧杯子喝温室苦叶茶，一台投圆子的娱乐终端通电，卡币后被杯勺敲了两下才吐出票。酒价与滤芯价写在同一块黑板，人们坐下并不总为了工作，有时只是想等同伴回来。

**去重：** 酒吧、实体代币和旧消费终端均已有世界设定；新增保留的是这个具体生活场面。

### IDEA-017｜短片信息预算与五行创作卡

**来源：** 旧《单集节奏与信息预算》和旧前三条短视频拆分。

**边界：** 这只是可选的制作工具，不恢复旧稿精确秒数、每集必须只讲一条规则、固定分集结构或全员短句等硬性限制。

## IDEA-018｜两套生存经验，不是两支互相敌对的队伍

**原始日期：** 2026-06-05  
**来源：** 2026-06-05 的早期用户构思，已按当前角色经历与关系筛选。
**状态：** 可用的关系戏创意，未指定剧情与人物阵营。

**保留的创意核心：** 在同一座基地里，有人做判断时先关注维修规程、设备寿命、配给和风险，有人先留意现场异常、伤员状态、生态样本及人与人的信任。两种思路可能冲突，也能共同解决问题；**具体由谁代表哪一方，取决于当场任务和人物经历**，不能把角色固定划成旧公司派与非旧公司派。

**可发展的戏剧机制（非确认剧情）：** 同一场抢修或伤员救援，前一组人担心停机、超载、坏掉最后一块备用件；后一组人提出从现场观察或人的实际需要改变方案。最后可能是工程师用规矩守住生命，也可能是拾荒少年用经验纠正错误的表格。人物不必永远站在同一边，**两种方法是能力与经验差异，不应写成好人与坏人的阵营对抗**。

**与现行设定的关系：** 各角色的专业分工、经历与性格仍以人物专题为准；本条只保留不同判断方式可以引发关系戏的机制，不指定谁必然对、谁必然错。

## IDEA-019｜一个外人看懂了这座基地有多不寻常

**原始日期：** 2026-06-10  
**来源：** 2026-06-10 的早期用户场景构思，经现行技术设定筛选。  
**状态：** 未采用；老秦是否出场、身份是否沿用尚未确认。

**保留的场景核心：** 一位来做交易的商队技术员，暂称**老秦**，曾接触旧公司工业装备。他检查一件带有维修记录的旧设备，看到仪表上的实际运行参数和经过修补的供电线路，发现它的状态出乎意料，停下来认真查看，然后说：

> “真有你们的，竟然能把旧公司设备运转起来。”

基地的人笑笑，回一句“运气好”。老秦没有接话，而是看向控制台后面的人。由他对**具体设备状况与维修手艺**的反应，提示观众基地里可能藏着经验丰富的人；不由一句台词推导出所有旧公司设备都需要内部密钥才能启动。

**吸引力：** 不需要隐藏高手自己解释身份，也不用旁白炫耀基地技术。一句外来专业人士的判断，就足以让观众意识到：这地方能活下来，可能不仅因为拼命修补，**还有人掌握了别人没有的经验或权限**。

**待探索：** 哪项具体读数或修复痕迹引起他的注意？老秦也可能误判；人物不因此获得凭空识别旧权限的能力。**不提前揭示徐世嵘身份，也不把此桥段规定为必须出现。**

## IDEA-021｜生物电池与旧矿场大型机甲：迟来的技术回报

**记录：** 2026-10-23  
**标签：** 生物电池 / 旧公司矿业 / 工程机甲 / 技术解锁 / 维克托 / 莺 / 长线剧情  
**状态：** 导演提出的新故事构思，尚未确定具体机体、启动时间和技术原理；暂不改为正式世界设定。

**导演提出的创意核心：**

- 第一集特瑞捡走生物电池，首先是受现实生存压力驱动，认为这件稀有物品可能换到大量物资；好奇研究不如生存需要迫切。
- 观众可以自然期待它是主角的强力神器，但最终不走“捡到就直接开挂”的路线，也不能让观众的期待毫无回报。
- 生物电池最初就是旧公司为矿场大型作业机甲研发的特殊供能技术；设想的优势是远超常规能源模块的极长续航与高能量密度，**“类似小型可控核聚变”是性能层面的类比**，是否涉及真实核聚变机制尚未确定。
- 特瑞在第一集获得的是一个尚不可实用的核心。剧情发展到某个阶段，维克托和莺等人通过跨学科研究、实验和维修，逐渐让生物电池真正稳定运行，最终可以用于驱动旧矿场大型作业机甲，并在重要事件中发挥实质作用。

**与现行设定的衔接和待解决事项：**

- 现行[能源设定](../设定/世界设定/04_能源系统与曜晶矿源.md)对生物电池的暂定机理是低阶微型生命参与**消耗反应原料的电化学能量转换**，不是无中生有的能源，也不属于曜晶核心。未来如果确认机甲级高功率、超长续航，必须合理交代能量来源、反应物补给、输出功率、寿命、热管理和代谢损耗；现阶段不直接用本构思覆盖该设定。
- 维克托负责工程动力、接口、控制和安全；莺负责活体核心及其持续活性、反应环境与污染风险。两人都需要有真实贡献，不能靠一句技术口令瞬间解锁。具体研究路径和失败成本未定。
- 使用哪一台旧矿场机甲、当前机体是否存在、何时修复、最终用于采矿／救援／防御／其他任务、可能产生什么新风险，均留待导演后续决定。
- 本条与[IDEA-020（现已采用的E14小七临时试机喜剧）](#idea-020)属于**两条不同故事线**；E14使用普通维修测试能源，不等同于本条尚未确认的生物电池高功率技术，也不据此认定两者是同一台机甲。
- 不改写第一集导演已完成的分镜；只记录后续故事可兑现的长期承诺。

## IDEA-022｜「那就让他们知道」：世嵘用全名为特瑞担保

**记录：** 2026-10-26  
**标签：** 徐世嵘 / 特瑞 / 身份 / 旧公司 / 代价 / 长线剧情  
**状态：** 导演明确保留这一场；**第一季剧本不用**，留给以后特瑞真正取得**被旧公司系统承认的身份**时使用（不是避难所居民身份，也不是基地内部临住担保）。

**来源：** 原E12《一张船票》第三场「今天谁来签」，后因删除旧公司放货门而移出（见提交 `3e5e2a9`、`505338e`），现行第一季中已不存在。

**原场面的可用核心：**

- 一件事必须由旧公司系统认得的人当面署名才能通过；世嵘掏出那张磨得发亮的旧公司卡，凯恩看见卡的瞬间手指收紧。
- 有人提醒他：签了全名，旧公司就知道是你了。
- **徐世嵘**：那就让他们知道。他一笔一画写下「徐世嵘」，插卡，门（或系统）放行。
- 特瑞在这一刻意识到，一直有人在暗中替他担着。

**导演保留的理由：** 如果世嵘只是为了一船补给就主动暴露自己，代价和收益不对等，观众会觉得角色明知后果还去做，像是降智。只有当签名换来的东西**只能靠这一步拿到、而且值得他赌上自己**时，这一刻才成立；特瑞获得被旧公司承认的真实身份正是这样的时刻。

**讨论中延伸出来的建议（未经导演确认）：**

- 「那就让他们知道」从无奈让步变成世嵘主动替特瑞扛下这件事；也是他第一次自己把藏了很久的旧身份拿出来用，而且是为了别人。
- 特瑞拿到身份的同一刻，世嵘被旧公司重新看见；好事和麻烦同时发生，可以作为下一段故事的起点。
- 原版用来揭示「是谁替特瑞补报」的E06补报纸条已不在现行剧情中；若要保留这一层，需要在之前的剧情里另埋一个小道具。

**待定：** 发生在第几季哪一集、身份通过什么正规或半正规途径办理、世嵘旧案与这次署名的关系、旧公司之后的反应，均未确定。
