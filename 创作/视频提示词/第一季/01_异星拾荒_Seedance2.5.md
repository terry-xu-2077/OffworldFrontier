## 批次1

[导演说明]

本批次的核心戏剧意图是“从狭窄压迫的异星自然峡谷冲入辽阔未知的危险荒原”。前段通过紧贴866载具的FPV镜头建立极强的高速穿梭临场感，中段切入主角特瑞的主观视角（POV）强化驾驶操控与空间转换，尾段以固定大远景展现异星地貌的孤寂与壮阔，并在结尾以低空FPV带出主线世界观元素（天空中的环带星球）。镜头节奏由高速紧迫过渡到沉静空旷，为全剧奠定写实、壮丽且带有工业废土感与奇幻异星风貌的视觉基调。

特瑞状态： 身穿黄色磨损斗篷与灰色工装连体力靴，双手把控866方向盘，金色头发被强风往后吹得疯狂摆动。

866状态： 处于行进模式（Scheme A-1: Stowed for Transit），双翼收拢于车身两侧[cite: 3, 4]。车载能量匣尚在维持，仪表盘呈橙色低能量闪烁警报。
环境状态： 日间干燥旧路，无明水水坑，空气中弥漫紫灰色沙尘。


[视觉基调]
摄影器材： ARRI Alexa Mini LF 搭配 ARRI Signature Prime 电影级定焦镜头（焦段使用 18mm / 35mm / 85mm 转换）。
画质质感： 真人实景电影质感，写实且富有物理重量感。真实皮肤纹理、砂砾摩擦、机械悬挂真实震动与气流带起紫灰沙尘的细微动态。
摄影风格： 高速 FPV 穿梭手持微幅呼吸感与固定大远景的对比，具备极致的空间临场感与画面呼吸感。



[色彩光影]
环境日光： 异星高空散射日光，配合天空紫色环带的柔和反射光。
色调倾向： 峡谷内以阴影紫黑与紫色巨伞菌盖的高光交织；冲出峡谷后转为开阔的黄紫灰色调沙尘与蓝灰色岩石对比。
实用灯光： 866 车头双圆大灯发出温暖黄光，仪表盘橙色低能量警报灯周期性微弱闪烁[cite: 1, 3, 4]。

[分镜脚本]

镜头01｜[0–6.0s]（连贯一镜到底）
景别 / 焦段： 特写 → 大全景 → 近景（连贯变焦与动态景别演化）/ 18mm 超广角
运镜 / 视角： 一镜头到底的连续高难度 FPV 流体运镜（Continuous FPV Sweep）。
画面描述： 画面起笔于极贴近 866 载具右后轮的低角度特写（0-0.5s），越野轮胎在高速旋转中猛烈碾碎干燥地表，将粉紫色的砂砾与沙尘直接甩向镜头（0.5-1.5s），展示出粗犷的悬挂起伏与机械物理重量感；紧接着 FPV 摄影机顺势垂直升空拉高，在半空中展开广角俯拍，将 866 穿梭于高耸岩壁与上方交错覆盖的巨大紫红色菌伞峡道的壮丽空间全貌一览无遗（1.5-3.0s）；在升至最高点的瞬间，镜头顺着载具前进轨迹在空中做半弧形急速环绕平移（Arc Orbit）切至载具前方，随即顺势俯冲猛扎向下，贴近 866 的黄色防滚架与前挡风区域，最终精准停留在正对/侧对驾驶员特瑞的近景位置（3.0-5.0s）——清晰捕捉到他带着护目镜专注、抿紧嘴唇的驾驶神情，以及双手对方向盘的微调控制。
声音 / Foley： 起笔时暴烈的轮胎碾碎碎石与飞砂击打声 → 升空与空中环绕时高亢迎面吹过的狂风呼啸声 → 俯冲接近车头时低沉强劲的电驱动电机轰鸣与特瑞带喘息感的粗重呼吸声。

镜头02｜[6.0–12.0s]
景别 / 焦段： 特写至中景 / 25mm 广角（车内 POV）
运镜 / 视角： 特瑞驾驶位主观视角（POV），带微幅晃动。
画面描述： 前方仪表盘橙色低能量灯闪烁。特瑞猛打方向绕过峡谷最后一道弯。刺眼异星日光瞬间涌入，遮幅产生透镜炫光，眼前骤然呈现辽阔荒原。
声音 / Foley： 仪表盘嘀嘀提示音、底盘扭转机械声、光线涌入时的环境音变化。
