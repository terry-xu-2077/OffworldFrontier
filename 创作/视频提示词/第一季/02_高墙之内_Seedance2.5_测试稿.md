## 批次1｜风塔下·坏腿仍往前走（建议17s）

[导演说明]
本批让观众在一片沉静荒原中看见866付出跳跃代价后仍努力赶路；摄影机像远处真正看到它的观察者，先展示孤独，再靠近机械故障。情绪由荒凉转向一丝到达的希望。

[全局参考]
蚂蚱载具.jpg固定单座866车架、四轮、右后长行程机械腿；00_特瑞_Terry.jpg固定主角披覆外层；荒星地貌.jpg固定蓝灰矿岩及粉紫色尘雾。

[连续性状态]
紧接E01末尾，866右后机械腿外撇，仪表红色低电警报持续；工具袋里包好的生物电池没有给车供电；只有特瑞一人驾驶。

[视觉基调]
ARRI Alexa Mini LF搭配ARRI Signature Prime的低反差写实质感。35mm固定大远景让风塔占据空旷地平线，85mm近距离观察偏载腿与地面的摩擦，25mm驾驶POV保留真实震动，避免任何机械平稳悬浮移动。

[色彩光影]
傍晚斜侧自然光擦亮蓝灰岩层和沙色旧车壳，阴影偏冷紫，远处大风塔叶轮缓慢被暮光照出浅色边；车舱红灯在金属边缘忽明忽暗。

[分镜脚本]

镜头01｜[0.0–6.0s]
景别 / 焦段：大远景 / 35mm
运镜 / 视角：低岩坡旁固定观察，866由画面左下方慢慢驶进，镜头晚半拍小幅摇向风塔。
画面描述：巨大旧风塔的风轮在粉紫暮色里缓慢转动，866在通往塔的老旧维护路上艰难挪行，右后车体一次次下坠、扶正；沙地出现一长条断断续续的车辙，比周围空荡岩原显得格外微小。
声音 / Foley：傍晚荒原横风、远处大叶轮低沉轴承声、车身断续的关节刮擦。

镜头02｜[6.0–11.0s]
景别 / 焦段：极近景 / 85mm
运镜 / 视角：低位侧跟拍右后腿，摄影机因踩踏坑洼轻微颠簸。
画面描述：右后机械关节向外斜着承重，旧液压管束随着车辆缓慢前行轻颤；轮胎压进碎岩缝时支架突然一歪，再靠相邻悬挂拉回，砂石被拖出扭曲小痕。
声音 / Foley：金属干涩摩擦、弹簧回弹、石粒弹击轮罩。

景别 / 焦段：驾驶位POV / 25mm
运镜 / 视角：单人驾驶座眼位，随着车头摆动自然而缓慢地观察前方路面。
画面描述：红色低电报警在视野下沿一闪一闪，特瑞仍握着操纵杆稳住行驶方向；路尽头出现一块旧指示牌，尘土后方若隐若现有新的轮胎印迹。
声音 / Foley：车舱电驱低鸣、红灯间歇嘀鸣、护风布在气流中扑动。

## 批次2｜有人修补的痕迹与高墙（建议18s）

[导演说明]
从一连串平凡维修痕迹逐步发现有人生活，再让高墙在转过岩坡时突然占满视野。比起宣布“这里有人”，让观众和特瑞自己发现。

[全局参考]
荒星地貌.jpg参考环境矿岩和天光；避难所-俯瞰.jpg只用于基地地表总体布局，外墙近景需要文末缺图方案确认；蚂蚱载具.jpg负责866比例。

[连续性状态]
866沿旧维护路低速连续前进，右后腿故障与红灯未恢复；特瑞刚在路面发现新轮迹，尚未到外闸。

[视觉基调]
35mm相对车头侧面的跟随镜头有自然手持起伏，85mm低角度定焦观察旧牌与新焊点，18mm宽幅展示高墙的巨大尺度。实景旧工业合金有连续磨痕，不用新品抛光质感。

[色彩光影]
粉紫日暮光给新焊痕投出极小银亮反射，墙体背光厚重；墙后透出一丝暖色生活照明而墙外仍偏冷。

[分镜脚本]

镜头01｜[0.0–5.0s]
景别 / 焦段：中近景 / 50mm
运镜 / 视角：靠在车架外侧，特瑞目光转向路旁时摄影机跟慢半拍才转焦。
画面描述：驶过旧标牌时，他注意到标牌被重新扶正，铁丝与新焊点还带着维修留下的痕迹；再往前，路边供电缆用不同年代的接头重新连接，护栏上刚补过一条短焊缝。
声音 / Foley：车身齿轮声起伏、路边松电缆轻碰护栏。

镜头02｜[5.0–12.0s]
景别 / 焦段：大全景 / 18mm
运镜 / 视角：低空自由摄像机沿866侧后随行，越过岩坡时缓慢拉高，抵达坡顶后停在车后侧观察。
画面描述：岩坡转过去，巨大的高耸工业围墙突然横在前方：厚圆角合金被不同来源的装甲板反复补强，墙顶有瞭望口，墙后旧风塔的叶片仍在缓慢旋转。仅有一个人的866在墙前显得很小。
声音 / Foley：风声被高墙切出低沉共鸣；墙里开始隐约传出金属撞击、机器和远远的人声。

镜头03｜[12.0–18.0s]
景别 / 焦段：人物中近景 / 50mm
运镜 / 视角：驾驶员斜前侧轻微手持，随着表情从瞠目到无奈短暂拉焦到坏腿。
画面描述：特瑞看了高墙一眼，原本疲惫的脸上冒出一点到达的轻松；坏腿又猛地歪了一下，他拍了拍操纵台，朝陪他走到这里的866说：「兄弟，咱都到门口了。你可别躺这儿。」说完又扶住方向继续向前。
声音 / Foley：特瑞低而带笑的普通话与操纵台拍击声、车底迟疑的机械擦响。

## 批次3｜探灯与炮塔拦停（建议17s）

[导演说明]
墙内传来的生活气刚带来希望，墙头却突然亮灯、武器停在警戒线前；让观众感到陌生外来者和守门人都谨慎，危险可读而不凭空升级。

[全局参考]
00_特瑞_Terry.jpg约束人物脸和衣服；蚂蚱载具.jpg约束单人载具及红灯；避难所-俯瞰.jpg只指示高墙与风塔在基地的大体关系，炮塔需从已确认防御设定约束。

[连续性状态]
特瑞驶下墙外坡道，尚未越过警戒线；866损坏与红色低电报警持续。守门人此刻只通过墙头扩音器说话。

[视觉基调]
85mm远摄压缩巨大墙面与小车的比例，24mm墙头边缘机位展示冷白探灯的照射路线；人物用50mm紧贴车舱观察。演员先被光照中才抬头，摄影机不提前等待表情。

[色彩光影]
冷白高亮探灯扫进粉紫薄尘，光束外仍是傍晚蓝灰阴影；炮塔厚重枪管只占据真实瞭望位尺度，车头旧黄沙色涂装在探灯下失去暖色。

[分镜脚本]

镜头01｜[0.0–5.0s]
景别 / 焦段：远景 / 85mm
运镜 / 视角：墙外警戒线斜向固定构图，866由远处驶来，探灯突然擦过镜头一侧。
画面描述：866慢慢驶下斜坡，车头刚进入外闸射界，墙顶探灯骤然把白色光锥打在它面前；炮塔从墙头阴影里缓慢转过来，炮口最后稳稳压在车前不远的硬地警戒线上。
声音 / Foley：探照灯伺服电机、远处炮塔沉重缓转的齿轮声。

镜头02｜[5.0–12.0s]
景别 / 焦段：车舱中景 / 50mm
运镜 / 视角：手持摄像机从车侧贴近，轻微重新寻找驾驶员的眼神与仪表位置。
画面描述：墙头扩音器发出略带压缩失真的男声：「停在线外。熄火。车斗打开。」特瑞先看一眼红色报警，再抬头确认炮口朝向，脚下收慢车速，手指握住刹车与电机关闭控制，车身带余动才终于停住。
声音 / Foley：扩音器声从墙头传来，坏腿在制动时重重一下顶地，电驱声逐渐降下。

镜头03｜[12.0–17.0s]
景别 / 焦段：中近景 / 35mm
运镜 / 视角：从车头侧低机位向上看人物与墙顶的真实高度差，轻微手持观察。
画面描述：866完全停在警戒线外，特瑞把手从操纵杆抬起，在探灯光里做出听见了的示意；他没有把工具袋里的贵重生物电池暴露给上方陌生人。
声音 / Foley：引擎低频逐渐停下，风声与墙上扩音器的短暂静电余响变得清晰。

## 批次4｜开车斗检查与一点玩笑（建议20s）

[导演说明]
建立警戒程序下的人情反差：墙上有人担心破车惹事，特瑞不急着解释身世，用成熟、冷静的举动应对陌生检查。

[全局参考]
00_特瑞_Terry.jpg约束特瑞脸和沙棕旧披覆外层；蚂蚱载具.jpg提供866结构与故障；生物电池.jpeg只作为工具袋内被包好的隐含道具，暂不出画。

[连续性状态]
866已熄火、停在外警戒线，特瑞下车打开原有车斗；车斗里的旧接头、废零件与坏掉的普通备用能量匣是随车存货，圆子与断角工牌在腰袋，生物电池藏在工具袋。

[视觉基调]
50mm肩侧跟拍人物绕到车尾，85mm观察车斗里的损坏零件和备用能量匣，35mm静止机位连住高处扩音器的声源。摄影机像靠近接受检查的旁观者，带真实呼吸感。

[色彩光影]
墙头探灯从斜上方照进车斗，黄黑磨损的旧合金与灰尘泛冷；护栏后的暖光仍很远，不把墙外拍成灯火通明。

[分镜脚本]

镜头01｜[0.0–6.0s]
景别 / 焦段：半身中景 / 35mm
运镜 / 视角：摄影机位于警戒线边缘，侧向跟着特瑞由单人驾驶位走向车尾。
画面描述：特瑞从车上下来，工作靴踩入细沙后往车尾走，衣摆随风折回；墙头一名矿工盯着这台散架似的车忍不住嚷：「靠，别让破车进来炸门啊。」特瑞抬头看了一眼，但脚步没有停。
声音 / Foley：矿工的喊声自高处传来，靴底踩沙声与空车架轻微嗒响。

镜头02｜[6.0–13.0s]
景别 / 焦段：车斗俯视近景 / 50mm
运镜 / 视角：从特瑞身后探入车斗上方，随着手臂动作自然微倾。
画面描述：他打开车斗，里面只有磨损旧接头、备用工具、几块废零件与车斗底部那只电量窗全黑的普通备用能量匣。特瑞把车斗盖扶在手边，朝墙头平静回一句：「已经熄火了。你们慢慢检查。」探灯在金属板上一寸寸掠过。
声音 / Foley：金属车斗锁扣嗒地弹开、扩音器余噪、特瑞说话时轻吹起的尘土。

镜头03｜[13.0–20.0s]
景别 / 焦段：双层视线中远景 / 85mm
运镜 / 视角：摄影机从车尾低处顺着探灯摇向高墙观察口，保持两者方向连贯。
画面描述：守门人从观察窗后扫视车斗与特瑞手腕，画面先停在磨旧腕部设备，再仰到窗里模糊的人影；他问：「刚从残骸区出来？」特瑞还没急着为自己辩解，眼睛先扫过高墙上的警戒灯。
声音 / Foley：墙上扩音器略失真的问话、风从瞭望窗口挤出的气流声。

## 批次5｜外来者的身份疑问（建议22s）

[导演说明]
身份差异不用屏幕解说，而由守门人审视和特瑞的反应呈现；观众看到他的笑在某句话之后淡下去，理解他不是常规转运而来的外来者。

[全局参考]
00_特瑞_Terry.jpg 与00_特瑞_Terry.png保持面容和皮肤细节；蚂蚱载具.jpg保持866仍有损伤；高墙环境母图待制作，不假定已有探灯平台图。

[连续性状态]
特瑞站在已经打开的车斗旁；车子熄火，守门人通过墙上观察窗与扩音器询问；外闸未打开、炮口仍压着地面警戒线。

[视觉基调]
50mm和75mm给双方可信距离，保持特瑞与墙头眼神匹配；摄影机靠在车斗一侧，手持的微小换重心随人物的回答发生，不为每句台词机械切镜。

[色彩光影]
侧上方白色探灯在人物肩部造成硬边，面部另一侧靠粉紫天光微弱补亮；墙头窗内是更冷的深灰，不对称的明暗让双方距离更明显。

[分镜脚本]

镜头01｜[0.0–7.0s]
景别 / 焦段：人物中近景 / 50mm
运镜 / 视角：从车斗斜前方随人物轻微移动，焦点在脸部和墙上警戒线间短暂游移。
画面描述：特瑞略仰头，留给守门人一个不完全信任的笑，说：「路过。」高处马上接话：「残骸区不会让人干干净净路过。」特瑞垂眼看了看自己的衣袖，用手拍下一阵细灰，让一句反驳变成可见的玩笑。
声音 / Foley：一阵手掌拍工装的布面扑响，墙头男声通过扩音器较远而带电噪。

镜头02｜[7.0–17.0s]
景别 / 焦段：观察窗与车尾中远景 / 85mm
运镜 / 视角：固定在守门侧视线轴线内，特瑞站在画面下方，窗位在高处。
画面描述：守门人隔着窗慢慢扫过他的手腕，问：「没游商牌，没监管章，也没流放腕码。你是哪批转运下来的？」特瑞脸上原本带点玩笑的笑意逐渐收住；他抬头看炮口仍停在警戒线前，肩膀没有后退。
声音 / Foley：扩音器里完整的质询，铁丝在风里轻颤；特瑞不插话。

镜头03｜[17.0–22.0s]
景别 / 焦段：人物近景 / 50mm
运镜 / 视角：更低一点的肩侧手持，镜头留给特瑞视线转移的时间。
画面描述：特瑞从炮口移回守门人的观察窗，平稳地说：「你先把炮口压低点。」他没有冲向车斗，更没有主动翻出工具袋里的珍贵装置。
声音 / Foley：低沉自然的特瑞对白、墙头炮塔驱动器持续待机嗡声。

## 批次6｜荒星出生者与凯恩到场（建议22s）

[导演说明]
这一批揭开特瑞的身份，却不给他悲情独白；“荒星生的”让观察窗内短暂安静，随后用凯恩的专业判断把紧张关系向实际解决推进。

[全局参考]

让两个刚收工矿工在自己的晚饭里聊风塔与资源，观众顺带理解旧公司的烂线、基地修理工作和风汛前的准备。谈话被热糊、咸菜和真实抢话打散，技术信息不能压过人物。

[全局参考]
避难所_公共厨房与食堂舱.jpg、避难所-俯瞰.jpg分别锁内景与远处风塔地标；00_特瑞_Terry.jpg锁旁听的主角。

[连续性状态]
特瑞正在吃饭，阿岚已播完短沙提醒；隔壁桌两名刚收工矿工袖口、手背有灰，长期在基地日常生产活动。特瑞只旁听，没有替他们答问题。

[视觉基调]
50mm在桌边中近景让矿工们同时在擦手、夹菜、喝汤，35mm含特瑞在后景旁听；75mm拍眼神看向窗外的风塔。摄像机像同桌第三个人，不做刻意全套正反打。

[色彩光影]
暖灯照亮人们手背和带矿灰的袖口，窗外转动风塔是蓝紫黑剪影，蒸汽在灯下形成少量真实空气颗粒。

[分镜脚本]

镜头01｜[0.0–8.0s]
景别 / 焦段：两人中景 / 50mm
运镜 / 视角：相机站在长桌另一侧略高于碗沿的位置，视线随先说话者自然转移。
画面描述：矿工甲抹掉袖口残灰，朝高窗外扬扬下巴说：「老维又在风塔那边挖沟？」矿工乙手背都是矿粉，正夹着菜，没停下嘴里的咀嚼便答：「挖出半截公司留下的烂线，白忙一天。人家走了，倒把修不完的活留给咱们。」
声音 / Foley：两名矿工清楚口语和餐具摩擦声，背后其他桌聊天不因他们说话而停。

镜头02｜[8.0–16.0s]
景别 / 焦段：窗边中远景 / 75mm
运镜 / 视角：先用固定长焦留住窗外风塔的剪影，再缓缓回到桌边。
画面描述：矿工甲顺着窗外风塔转动的叶片看了一眼，说：「可这塔还能转啊。等风汛来了，指不定能多攒点电。」这是一句干活人的期待，窗外风轮稳定而缓慢，镜头没借机拍成神奇全城亮灯的奇观。
声音 / Foley：矿工甲远一点的说话声、窗框微微振动、风塔极弱低频机械声。

镜头03｜[16.0–26.0s]
景别 / 焦段：三人错位中景 / 35mm
运镜 / 视角：从特瑞侧后方观察隔壁桌，前景一只碗短暂遮住矿工乙的手，摄影机微幅调整。
画面描述：矿工乙把咸菜碟往自己面前移了半寸，先撇嘴回一句：「你先别替老维打包票。你们下井那批矿明天出不出？我的接头还等着换呢。」矿工甲瞥向对面已经伸过去的筷子，两人的话题毫无仪式感地从风塔切到明天的矿和今晚的菜。特瑞在后面慢慢吃，听懂的地方稍微笑一下。
声音 / Foley：矿工乙自然的长句、筷子点陶瓷碟的微响、邻桌压低的笑声。

## 批次24｜隔壁桌·咸菜比风塔更着急（建议20s）

[导演说明]
把刚才关于供电与矿的讨论落回晚饭：他们要争的是最后一碟咸菜，人物之间的熟悉和斗嘴压过术语。特瑞终于主动加入这种闲话，但没人为了他特别让出资源。

[全局参考]
避难所_公共厨房与食堂舱.jpg锁长桌与餐具；00_特瑞_Terry.jpg锁特瑞面部与旧工装；没有新稀缺道具。

[连续性状态]
两名矿工刚聊完风塔、下井矿料与接头；特瑞在旁桌端着热糊，能听见他们的话。桌上还剩小碟咸菜、少许调味粉，所有人仍在晚饭时段。

[视觉基调]
50mm普通家庭饭桌般真实中景，85mm低角度拍手争调味粉，35mm让特瑞在同一空间被自然带入；轻微手持迟滞增加现场感，不刻意夸张笑点。

[色彩光影]
灯光低暖、陶瓷碟有磨旧反射；人物手上细微矿灰与汗印清楚，桌子边缘比背景阴影暖很多。

[分镜脚本]

镜头01｜[0.0–7.0s]
景别 / 焦段：双人中景 / 50mm
运镜 / 视角：摄影机留在两名矿工之间，不为换台词频繁切轴。
画面描述：矿工甲把筷子伸向最后一小碟咸菜，回：「出。你别又趁我下井，把最后一碟咸菜吃了。」矿工乙赶紧把碟子护住一点，随口说：「行行行。先把盐递过来。」两人说完还盯着调味粉，像这小碟东西真值得争。
声音 / Foley：完整中文对白、筷子敲小碟的清脆声音、周围零星笑气。

镜头02｜[7.0–14.0s]
景别 / 焦段：手部近景 / 85mm
运镜 / 视角：低于桌面视线，从特瑞碗边自然横移到另一端的小包调味粉。
画面描述：同桌两人又为最后一点调味粉争起来，一个说自己昨天带的，另一个说早就分完；两只手在桌面边缘短促碰了一下又收回。特瑞在一旁听了半会儿，慢慢把自己的碗挪到桌子中间。
声音 / Foley：纸袋摩擦、盐粒落桌、两人随口拌嘴的现场人声。

镜头03｜[14.0–20.0s]
景别 / 焦段：三人中景 / 35mm
运镜 / 视角：从特瑞肩后略侧开，镜头在他开口时才把两名矿工一起收入景深。
画面描述：特瑞带着一点笑意问他们那味道是不是很厉害，两人看他一眼都笑了，却谁也没有把那撮调味粉让出来；特瑞很自然地继续抱着自己的碗坐在旁边，没有委屈或夸张尴尬表演。
声音 / Foley：矿工短促笑声、特瑞轻松的普通话、长桌上碗底摩擦木板声。

## 批次25｜你的大蚂蚱也有人认识了（建议19s）

[导演说明]
通过一个人的玩笑把外来人带进聊天，不靠“欢迎加入”的仪式。那个矿工自己膝盖上也有旧固定带，他的一句“坏腿的多了”同时指车、指人，轻轻地把特瑞拉进人群。

[全局参考]
00_特瑞_Terry.jpg锁定特瑞的沙棕披覆层与脸；蚂蚱载具.jpg只提供外面停着的866造型与右后腿损伤，室内不需要把载具硬拍进画面；食堂舱原资产锁定生活背景。

[连续性状态]
特瑞已经吃上一碗热糊、同桌开始闲谈；866仍在外面维修棚前尚未修好，具体故障未拆检；矿工护膝上有旧固定带，但仅是生活磨损。

[视觉基调]
50mm双人视线匹配，85mm自然找到手拍旧固定带的动作，35mm稍宽把餐桌其他人带入环境；摄影机像坐在桌边，不提前等人说金句。

[色彩光影]
暖色食堂实用灯在餐具与旧固定带上形成低亮反射；高窗冷色暮夜和室内烟汽使背景层次充分。

[分镜脚本]

镜头01｜[0.0–7.0s]
景别 / 焦段：中景 / 50mm
运镜 / 视角：从桌尾轻微向特瑞侧移，一位矿工在后景忽然出声时摄影机才转向他。
画面描述：有人看见维修棚门外停着的866，朝特瑞扬扬下巴问：「那只大蚂蚱你的？」特瑞抬起头，顺着对方下巴方向看了一眼窗外，又转回那人，答：「我的。就是现在腿不太听话。」他提到坏腿时嘴角带一点无奈。
声音 / Foley：矿工随意的问话、特瑞带笑的自然回答、食堂嘈杂人声仍在。

镜头02｜[7.0–13.0s]
景别 / 焦段：矿工膝部到半身近景 / 85mm
运镜 / 视角：摄影机因矿工手掌突然拍膝盖，顺势向下倾再抬回他的脸。
画面描述：矿工边说边拍了拍自己缠着旧固定带的膝盖：「这儿坏腿的多了，先吃饭吧。」说完他低头继续吃，不等特瑞做郑重回应。特瑞听出其中的双关，忍不住笑出一声。
声音 / Foley：拍护膝的短闷响、矿工随口一句、特瑞笑出声、勺子碰碗。

镜头03｜[13.0–19.0s]
景别 / 焦段：特瑞近景 / 50mm
运镜 / 视角：相机固定在桌侧，远处别人说话时焦点没有强行每次都跟过去。
画面描述：特瑞终于放心地喝下一大口热糊，表情从先前疲惫戒备变成认真尝味道的样子。他偶尔听不懂旁人说的维修行话，只靠手势和眼神猜一猜，没人特意停下来解释。
声音 / Foley：细小呼气与吞咽、餐具相碰、四周自发的收工闲谈。

## 批次26｜高墙之内·终于能加入一句玩笑（建议14s）

[导演说明]
以生活而非硬悬念收尾。866还坏着，但特瑞已经在一张普通餐桌上参与争论；墙外风塔与墙内人声共同证明这里可以暂时停下来。最后一镜把距离从一人一碗饭拉到一个有灯火的据点。

[全局参考]
避难所_公共厨房与食堂舱.jpg锁食堂桌面与灯光；避难所-俯瞰.jpg锁墙内风塔和主井的位置；蚂蚱载具.jpg锁866损坏状态；00_特瑞_Terry.jpg锁人物。

[连续性状态]
特瑞还没有正式居民身份，车也没修好；普通能量匣仍低电、右后腿外撇。圆子已用于吃饭，断角工牌与银灰生物电池仍随身保存。特瑞先是旁听者，结尾开始和居民一起争论车名。

[视觉基调]
35mm桌边真实轻手持让谈笑自然发生，最后35mm或50mm固定宽幅让暖窗与外面暗色形成关系。声画平缓收束，不从餐桌硬切陌生威胁，不添独白或解释性镜头。

[色彩光影]
夜间食堂长灯温暖但不柔化所有皱纹与尘土；窗外蓝紫夜色把维修棚前的866和更远的风塔压成深色轮廓，远处偶有旧工业警示小灯。

[分镜脚本]

镜头01｜[0.0–7.0s]
景别 / 焦段：长桌中景 / 35mm
运镜 / 视角：摄影机在人群一侧轻微摇摄，几位矿工交谈时视线自然追随手势。
画面描述：有人指着窗外那台歪腿的866提议叫它“大蚂蚱”，有人说不如“跳跳”，另一人摇头说等腿修好了再起名才吉利；特瑞最初在旁边看他们比划，后来看出争论越说越离谱，直接插话加入，脸上终于不再像门外接受检查的陌生人。
声音 / Foley：一桌人带笑的闲聊、碗勺声，特瑞加入讨论的一句自然人声，不添加剧本外完整新台词。

镜头02｜[7.0–14.0s]
景别 / 焦段：窗边中远景 / 35mm
运镜 / 视角：从食堂内固定望向窗外，桌上暖色人影在玻璃边缘留微弱反光。
画面描述：镜头透过高窗看见维修棚前歪着右后腿的866停在冷紫夜色里，车没有奇迹般修好；越过棚顶的远方，巨型风塔仍缓缓转动。餐桌的笑声从镜头背后持续传来，墙外的寂静与墙内的热闹终于并置。
声音 / Foley：食堂里聊天和轻笑形成柔和L-Cut，远风、风塔的极轻机械低鸣，只保留真实场景声音。
