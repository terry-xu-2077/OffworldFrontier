# 《异星边境》Agent 设定速查索引

> **这是路由目录，不是设定汇编。** 本页不重复维护人物、世界或美术事实；每项事实只以链接中的专题正文为准。当前用户明确决定优先，其次是专题事实；第一季剧本、角色关系实验和旧电影草稿不是跨作品正典。

## 使用步骤（按需读，严禁一口气读取全部）

1. **常驻最小上下文：** `创作/创作方向.md` + 本页。不要默认读取 `设定/` 全目录，也不要把第一季十集放入新作品上下文。
2. **确定相关主题：** 运行 `python scripts/canon_lookup.py route "特瑞 矿车 失联"`，先得到最多四个专题路径及匹配原因。
3. **只看标题：** `python scripts/canon_lookup.py headings "设定/世界设定/03_地下矿道与采矿流程.md"`，找到恰当小节。
4. **按节取正文：** `python scripts/canon_lookup.py read "设定/世界设定/03_地下矿道与采矿流程.md" "采矿机与下矿流程"`。默认限制输出字符数，若截断，进一步缩小小节或检索关键词。
5. **不知道在哪：** `python scripts/canon_lookup.py search "能量匣"` 只返回少量路径、行号与命中片段，不倾倒整篇。需要查询已经写过的剧情，才明确加 `--scope proposals`。
6. **通常只精读 1–3 份相关专题**；涉及跨领域矛盾再增查，而不是为了“掌握世界观”通读所有文件。完成写作后运行 `python scripts/check_canon.py`。

## 重要分界（避免把提案误当事实）

- 人物专题 / 世界专题 / 美术专题：用于核对已确认的常态、能力、技术与视觉规范。
- [人物关系与冲突](../创作/人物关系与冲突.md)、[生活事件实验库](../创作/人物生活事件实验库.md)、[灵感池](../创作/灵感池.md)：**创作提案／零碎发散**，可用于构思，但不能推断某个事件已经发生、某种技术已经存在。早期笔记仅将符合现行设定的创意提炼入灵感池，过时或冲突的原文不保存。需要找灵感时才使用 `search "关键词" --scope proposals`。
- [第一季剧本](../创作/剧本/第一季/00_季度设计与分集一览.md)：暂排**十三集**，E01 正式剧本和分镜、E06《一箱土豆》正式剧本 V1.0，其余待审；E06 分镜尚未定稿。仅在创作或修改本季时读取，不默认约束其他作品。
- 文档中的示例对白、镜头示例、角色标志性动作不自动成为每次都要执行的剧情。
- 仓库内的图片链接可能指向未检入的本地资产；检索到路径不代表图片已读或可用。需验证实际文件存在。
